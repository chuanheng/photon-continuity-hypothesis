# v0.22：吸收—再发射、量子态复现与原始光子身份

**方向 A：原始光子永远存在。仍是待检验的公设。**

## 1. 物理模型

使用共振、单模、闭合的 Jaynes–Cummings 模型，在单激发子空间选择基底 |g,1⟩ 和 |e,0⟩。相互作用表象下取 ℏ=1，哈密顿量为 H=[[0,g],[g,0]]，其中 g≥0 是耦合强度。初态 |ψ(0)⟩=|g,1⟩。

演化为 |ψ(t)⟩=cos(gt)|g,1⟩−i sin(gt)|e,0⟩。

因此 P_(g,1)=cos²(gt)，P_(e,0)=sin²(gt)，两者之和为 1。光场光子数期望为 cos²(gt)，总激发数 N=a†a+σ₊σ₋ 的期望恒为 1。

## 2. 完整吸收与复现

gt=π/2 时，系统处于 |e,0⟩（相差整体相位），光场真空概率为 1。gt=π 时，系统回到 −|g,1⟩，与初态的保真度为 1。

这叫单模闭合系统中的 Rabi 振荡与量子态复现，不等于开放自由空间中自发辐射的不可逆吸收—发射。真实原子与环境、多个辐射模式耦合后，通常不能期待这种完美复现。

## 3. 与方向 A 的冲突

该标准模型允许光场中光子数从 1 变为 0，再变回 1。它守恒的是**总激发数**，不是光子数。若方向 A 认为原始光子在光场真空阶段仍然存在，必须定义新自由度或新观测量，并说明为何现有测量不能发现它。

最终态与初始态相同，仅表示量子态复现；标准相同粒子量子理论没有永久的逐粒子身份编号，不能从复现推出“原始光子一直存在”。

## 4. 可操作性与实验判别

可测量的量包括时间分辨原子激发概率、腔内平均光子数、输出场的关联函数以及输入输出模式的量子态保真度。但这些量本身都不构成原始光子身份连续性的证明。

如果方向 A 只重新解释相同实验统计，而不给出新预测，则属于解释层面的主张。如果提出额外的隐藏光子自由度，必须说明其耦合、能量动量、态空间与可证伪效应。

## 5. 限制

- 本轮是闭合共振单模模型，忽略失谐、耗散、环境与自由空间连续谱。
- 未计算真实原子自发发射寿命、谱线宽度或探测器响应。
- 不是证明所有可能的隐藏变量理论不成立。
- 代码复现了标准模型，并未为方向 A 建立新动力学。
