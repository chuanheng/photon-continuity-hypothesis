# v0.6：背景校准精度与额外信号的可识别性

**研究性质：纯合成统计演示；不是实际 X 射线测量，也不是光子连续存在的证据。**

## 1. 统计模型

假设能量分箱 i 的期望计数为 μ_i=βB_i+AT_i。B_i>0 是人为构造的标准背景，T_i≥0 且 ΣT_i=1 是人为构造的额外信号形状，A≥0 是额外可探测计数，β 是背景归一化参数。

外部校准给 β 施加高斯约束 β~N(1,σ_β²)。这只是简化的系统误差模型。

## 2. 推导

在 A=0、β=1 附近，Fisher 信息矩阵元素：

I_AA=ΣT_i²/B_i；
I_Aβ=ΣT_i；
I_ββ=ΣB_i+1/σ_β²。

轮廓化 β 后：

**I_eff=ΣT_i²/B_i−(ΣT_i)²/(ΣB_i+1/σ_β²)。**

当背景归一化完全自由时，去掉 1/σ_β² 项。若 T_i 与 B_i 成正比，则 I_eff=0：额外信号与背景缩放完全简并。若外部校准约束 β，则可部分打破这种简并，但推断依赖校准可信度。

A_proxy=z/√I_eff 只是局部高斯信息近似下的灵敏度代理指标，**不是经过校准的发现阈值、排除上限或 p 值**；没有处理 A≥0 的边界效应、复杂系统误差或多重检验。

## 3. 人造数据结果

B=(80,110,170,300,550,2400)，T=(0.28,0.32,0.24,0.11,0.04,0.01)，z=3。

| 背景归一化约束 | I_eff | A_proxy（额外计数） |
|---|---:|---:|
| 完全自由 | 0.002016008 | 66.82 |
| 10% | 0.002023475 | 66.69 |
| 3% | 0.002081202 | 65.76 |
| 1% | 0.002219541 | 63.68 |
| 0.1% | 0.002292020 | 62.66 |

所有数值均取决于人为选择的形状，不代表真实仪器灵敏度。

## 4. 研究意义与下一步

可检测额外计数与“原始光子在吸收后仍持续存在”是两个不同命题。当前还没有从微观假说导出具有材料依赖性的 T_i，也没有经过验证的完整标准谱 B_i。

下一步需要固定材料截面与实验几何、探测器响应，独立推导额外信号形状，建立包含系统误差的模拟和统计检验。不能事后调整 T_i 来拟合数据。
