# 束缚体系与晶格参与时的严格前向非弹性过程（v0.3）

**关键结论：** 守恒定律本身**不禁止**光子严格前向传播、同时激发一个具有内部自由度的目标体系；但**运动学允许 ≠ 过程实际发生 ≠ 存在新的光子生存机制**。

## 1. 系统定义

考虑理想化封闭两体过程：

光子 (E, +E/c) + 初始静止目标 T(M) → 光子 (E−Δ, +(E−Δ)/c) + 激发目标 T*(M*)。

目标的初始静质量为 M，激发后的不变静质量为 M* = M + U/c²；U>0 是目标**静止系的内部激发能**，不是实验室系的总能量变化。这里把晶格/原子整体视作一个具有内部态的复合目标；不能直接把它等同于真实无限大晶体。

## 2. 四动量精确推导

以能量单位 R=Mc² 书写。目标获得的总能量为 Δ，动量为 Δ/c，因此末态目标的四动量不变量满足：

(R+Δ)²−Δ² = (R+U)²。

解得

**Δ = U + U²/(2R)**。

末态光子能量 E' = E−Δ，要求 E>Δ。目标在实验室系的总能量增加 Δ，其中内部激发 U、反冲动能 Δ−U=U²/(2R)。

特别地：

- **弹性情况 U=0：Δ=0。** 静止自由电子的严格前向康普顿散射不降能。
- **非弹性情况 U>0：Δ>0 在运动学上允许。** 例如原子/分子的内部激发或某些集体模式，具体选择定则与散射截面必须另算。
- 大质量极限 R≫U：Δ≈U；反冲很小，但不是零。

若将整个固体作为目标，实际还要处理边界、晶体动量、声子、电子激发、相干性和材料的动态结构因子 S(q,ω)。

## 3. 数值演示（不是铝的真实跃迁）

假设 R=质子静能约 938272 keV、U=1 eV=0.001 keV，则 Δ≈1.000000000533 eV，反冲约 5.33×10⁻¹⁰ eV。这里质子质量仅是方便的质量尺度，**不代表自由质子有一个 1 eV 内部激发态**。

## 4. 与现有物理的关系

拉曼散射、非弹性 X 射线散射、声子激发等都可以涉及能量转移与近前向传播；其发生不支持“所有入射光子永不被吸收”。对真实晶体，动态结构因子、相互作用矩阵元和仪器角分辨率决定可观测强度。

对于无相互作用的前向透射、弹性相干前向散射、非弹性近前向散射，应区分不同的量子态和探测通道。光子是不可区分的量子场激发，不能依赖不可观测的个人身份标签。

## 5. 对原假说的影响

原先“严格前向降能绝不可能”的广义结论不成立；正确的范围是“**初始静止自由电子、严格前向、只有一个末态电子和一个末态光子的弹性两体过程不允许非零能量损失**”。

但要将此类非弹性运动学作为新理论，需要：

1. 提出不同于标准非弹性散射的、**预先确定**的微观跃迁机制。
2. 推导能量/角度微分截面，和现有数据比较。
3. 指出标准物理模型之外、不能被荧光/康普顿/拉曼/声子等过程解释的可测差异。
4. 明确哪些观测能否定参数化模型；不可探测的无限弱残余光子不能构成可证伪预测。
