# v0.97：HOM 独立标定失准的灵敏度与置信区间覆盖率

**研究定位：合成数据模拟，未进行实际光学实验，不构成“原始光子永久存在”的证据。** GitHub 这份是对本地完整报告的概要归档；原始逐次数据、精确本地测试代码及图像在 photon_v097_complete.zip。

## 一、研究问题

v0.96 要求三个苛刻的独立校准条件：真实的五分类光子数分辨源监测、与主实验完全匹配的触发电子噪声参考以及无噪声的完整环境相位轨迹。v0.97 令这三个校准渠道分别失准，但仍用 v0.96 的理想似然/反演和模型内 Bootstrap 处理计数。

真实光学过程沿用 \(|2,1\rangle\) Fock 三玻色子在 50:50 分束器的输出概率 \((3/8,1/8,1/8,3/8)\)，阈值探测器点击 \(Q_j(n)=1-(1-d_j)(1-\eta_j)^n\)。真实固有重叠 \(M_0=.72\)，三光子源比例 \(f=.065\)，实时触发共同点击 \(q=.014\)。40个环境相位块的标准差步长为.095，时间变化的普通模式重叠是 \(M_t=M_0e^{-|u_t|}\)。

## 二、标定渠道错设

1. **相位读出误差：** \(\widetilde u_t=u_t+b+\epsilon_t\)，\(\epsilon_t\sim N(0,\sigma_\phi^2)\)。拟合错误地把 \(\widetilde u_t\) 当作真实轨迹。测试读出标准差 .05 和 .15。真实期内平均重叠 \(\bar M=M_0 A_{\rm true}\)，估计固有参数 \(\hat M_0=\hat{\bar M}/A_{\rm reported}\)。
2. **光子数分辨误分类：** 五类源事件 \((1,1),(2,0),(0,2),(0,0),(2,1)\) 按行随机混淆矩阵 \(C_{ij}=P(\text{reported}=j|\text{true}=i)\) 生成报告。本轮主审计只令三光子事件的10%或30%报告为普通一对光子，而拟合假设 C 为单位阵。
3. **参考触发电子环境错配：** 线上共同点击概率 \(q=.014\)，校准参考实测 \(q_{\rm ref}=q+\delta_q\)，其中 \(\delta_q=\pm.004\)。这个校准需要额外匹配触发的参考，不能被普通挡光暗帧取代。

## 三、实际有限样本模拟

每情景60次独立模拟，每次近、远延迟各25000个门控；源监测50000次、触发电子监测60000次、挡光暗帧50000次、单探测效率测量50000次；每次79次模型内参数 Bootstrap。

**总计：8×60=480个外层合成数据集，480×79=37920份重新抽样记录。**

| 情景 | \(\hat M_0\) 均值 | 真值0.72的偏差 | 95%CI覆盖 M0 | 覆盖真实测量期平均重叠 |
|---|---:|---:|---:|---:|
| 无错设 | .71136 | -.00864 | 54/60（90.0%） | 54/60 |
| 相位噪声标准差 .05 | .71839 | -.00161 | 56/60（93.3%） | 56/60 |
| 相位噪声标准差 .15 | .73661 | +.01661 | 44/60（73.3%） | 57/60 |
| 三光子误报10% | .73034 | +.01034 | 56/60（93.3%） | 56/60 |
| 三光子误报30% | .74800 | +.02800 | 44/60（73.3%） | 44/60 |
| 电子参考偏低 .004 | .71190 | -.00810 | 57/60（95.0%） | 57/60 |
| 电子参考偏高 .004 | .72706 | +.00706 | 56/60（93.3%） | 56/60 |
| 三种错设叠加 | .75690 | +.03690 | **36/60（60.0%）** | 52/60 |

正确校准自身经验覆盖率也仅54/60，不能推断所有低于名义95%的差距均来自设备错设。60次外层抽样对应较大的二项 Monte Carlo 误差；情景种子不同，行间差异还包含随机路径和计数波动。

## 四、抽样噪声趋零时的条件偏差

固定环境随机轨迹种子9719、令光学及校准计数无限精确，并以 Gauss–Hermite 积分计算高斯相位读出误差的条件平均：

| 模型错设 | 极限 \(\hat M_0\) | 偏差 |
|---|---:|---:|
| 无错设 | .720000 | 0 |
| 相位读数标准差 .05 | .720312 | +.000312 |
| 相位读数标准差 .15 | .723533 | +.003533 |
| 三光子误报10% | .728194 | +.008194 |
| 三光子误报30% | .744207 | +.024207 |
| 电子参考低 .004 | .716531 | -.003469 |
| 电子参考高 .004 | .723497 | +.003497 |
| 三种错设叠加 | .744452 | +.024452 |

该数值为**固定相位轨迹条件下**的总体测量精度极限，不是对所有环境漂移的无条件平均。相位读出误差可能主要影响由平均模式重叠反算的固有 \(M_0\)，而对直接估计实验期 \(\bar M\) 的影响较小。必须预先声明目标 estimand。

## 五、科研结论和限制

重复在错误模型里做 Bootstrap 无法识别没写入生成模型的系统性误分类、相位读数误差或参考触发错配。极窄的区间也不保证覆盖真实的固有光学重叠。

本轮未测真实量子器件，没有将“永久光子身份”写入新的可辨识动力学，也没有独立于普通 HOM 模式不纯与仪器误差的预测。下一步 v0.98 可加入联合估计混淆矩阵/相位传感器噪声/匹配电子监测误差的自校准模型，测试偏差、覆盖率和校准成本的三方权衡。

**本地完整包：** 44/44 Python unittest，17个研究文件逐一 SHA-256 校验、详细报告、原始480组区间、两张 PNG。GitHub 对应源码及22项回归测试为独立整理版本，远程 CI 未确认执行。
