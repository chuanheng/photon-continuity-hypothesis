# 能量与动量守恒检验（v0.2）

**研究状态：** 这是对假说的必要约束，不是实验支持。

## 1. 严格前向降能的动量账本

入射光子能量 E、动量 (E/c) n；假设出射的“原始光子”能量 E'=E-Δ，方向 n 不变，且 0<Δ<E。

则物质必须获得

- 能量 Δ；
- 沿 n 方向的动量 Δ/c。

**不能只写能量转移，忽略动量转移。**

## 2. 静止自由电子：此类两体过程不可能

设质量为 m 的自由电子最初静止，光子严格前向降能，且只有这一个电子接收能量和动量。

电子末态动量 p=Δ/c。由相对论质能关系，电子动能

T = sqrt((mc²)²+Δ²) - mc²。

能量守恒要求 T=Δ。平方后：

(mc²+Δ)²=(mc²)²+Δ²，

故 2mc²Δ=0，即 Δ=0。

因此 **对初始静止的自由电子，严格前向、非零降能、仅两体末态的过程被能量-动量守恒排除。** 这不等于排除与束缚电子、晶格、其他粒子或外场的所有相互作用。

## 3. 材料内部激发可以承担能量

若材料初态静止，且有内部激发能 U，并整体反冲，近似守恒条件为

Δ ≈ U + Δ²/(2Mc²)

其中 M 为反冲系统的有效质量。更准确地说，末态系统的静质量可能因激发增加，须使用完整四动量关系。**仅有“电子拿走 Δ”仍不够；必须指定材料末态及其相互作用矩阵元。**

进一步的**精确复合目标推导**见 [束缚体系与晶格参与的运动学](bound_target_kinematics_zh.md)：若目标内部激发能为 U，初始静能 R=Mc²，则严格前向非弹性过程满足 Δ=U+U²/(2R)。这是运动学许可，不代表该过程必然发生，更不证明光子身份持续存在。

## 4. 单次事件的能量账本

E_in + E_background,in + E_matter,in =
E_original,out + E_background,out + E_matter,out。

相应三维动量也必须逐项守恒。若电子把能量转给背景光子，必须计入其动量、方向和相位，不能重复计算能量。

## 5. 对模型的直接约束

当前 Python 泊松模型只生成统计分布，不包含满足四动量守恒的微观跃迁。其 λ、α 尚不能解释为真实材料参数。

下一步：建立含晶格反冲和内部激发的单次散射过程，再由其截面或跃迁率推导 λ(E,material) 与能量损失分布；否则不能把模拟当作完整物理理论。

## 6. 可检验性

“所有原始光子仍存在，但均降到任意低且不可探测的能区”若无最低通量、谱形或相关性预测，无法用有限灵敏度实验排除。可证伪的必须是**预先给定参数**的模型，而非任意调整参数的叙述。
