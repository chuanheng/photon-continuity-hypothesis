# v1.06 中文研究报告：连续环境超先验与受限三光子部分可区分性

**全部为标准量子光学合成数据，没有真实光子实验，没有验证原始光子的永久历史身份。**

## 物理定义

两个相同内部模式 phi 的光子进入一个分束器输入端口，第三个内部模式 psi 的光子进入另一端口，定义 rho=|<phi|psi>|²。这是严格限定的 |2_phi,1_psi> 输入，不是一般三光子 Gram 矩阵模型。理想 50:50 分束器、输出探测不分辨内部模式时，A端口有0至3个光子的分布为：

P(rho) = rho * (3,1,1,3)/8 + (1-rho) * (1,3,3,1)/8。

远延迟使用可区分极限。阈值探测概率 Q_j(k)=1-(1-d_j)(1-eta_j)^k。三光子污染占 f，代替原本一对光子输入的部分权重；普通双单光子 HOM 重叠是 M0 * A(u)，A(u)=平均 exp(-|u_t|)。只有近远符合率而无内部态参考时，(M0,rho) 的观测 Jacobian 秩仅为1，不能同时独立辨识。

## 连续环境模型

24个时间块；相位随机游走增量 N(0,sw²)，每块两次相位读数 N(u_t+b,sr²)，40次零点参考。连续变换参数先验为 log(sw)∈(log .045,log .22)，log(sr)∈(log .08,log .28)，b∈(-.06,.06)。在MLE附近用Hessian构造高斯重要性提议，按传感器似然重加权160个粒子，每粒子生成条件高斯相位路径。源端PNR误分类、三光子污染、探测效率、暗计数及触发相关背景分别经参考数据与 v1.05 模型校准，合并进入光学近远二项似然。输出是贝叶斯等尾95%可信区间，不能自动保证固定真值的95%频率学覆盖。

真实固有 M0=0.72，每情景100组，43/43项本地Python unittest通过。

错设与正确rho情景使用配对相同生成随机种子和相同真实条件，只有rho拟合假设不同。正确rho是假设外部实验精确测得rho的**oracle对照**，本轮没有实现rho标定实验，也没有传播rho误差。环境超先验组的真值(sw,sr,b)=(.31,.32,.11)，全部超出先验支持；覆盖仍94/100但区间更宽且ESS明显下降，因此不能宣称鲁棒。固定真值覆盖是数值审计，**不是正式联合先验SBC**。96/100的精确二项95%区间约[.901,.989]，4/100约[.011,.099]。

## 主要发现与后续

本轮最强的数值信号是普通量子光学三玻色子内部模式错设导致非常显著的M0估计偏差，而不是任何新的光子历史身份效应。只有near/far符合计数不足以区分rho与M0。下一版v1.07需要独立可操作的rho测量参考组，在后验中传播rho的校准不确定性，并向一般三光子Gram矩阵及联合先验SBC扩展。
