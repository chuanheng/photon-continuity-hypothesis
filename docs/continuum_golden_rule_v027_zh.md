# v0.27：连续谱、费米黄金定则与后继光子通道

**方向 A：每个原始光子永久存在。仍属未经实验证实的假说。**

## 1. 研究动机

v0.26 是离散三态封闭系统；真实电离的末态电子具有连续动能和角分布。费米黄金定则在弱耦合、足够长时间且适当连续谱条件下给出跃迁速率：

Γ=(2π/ℏ)|V_fi|²ρ(E_f)。

对于不同末态通道，需要对各自连续末态求和或积分；|V|²ρ 仅代表矩阵元近似不随末态变化时的简化表达。

## 2. 两个通道

定义 S：存在后继光子的末态；A：没有后继光子的吸收末态。

Γ_S=(2π/ℏ)|V_S|²ρ_S；
Γ_A=(2π/ℏ)|V_A|²ρ_A。

假设仅有这两个互斥通道且速率非负，条件分支比为

B_S=Γ_S/(Γ_S+Γ_A)，B_A=Γ_A/(Γ_S+Γ_A)。

若总速率为零，则没有跃迁，分支比不具有物理条件概率意义；程序在此返回 (0,0) 作为数值约定。

方向 A 要求零光子吸收通道在全部相关条件下严格消失，即 Γ_A=0；这是对候选模型的额外限制，不是已经推导出的自然定律。若存在多个独立吸收末态，则要求所有相关通道总速率为零。

## 3. 态密度示例

使用非相对论三维自由粒子的示意态密度 ρ(K)=C√K，K≥0。实际光电电离截面还依赖连续态波函数、离子反冲、角动量选择定则、光子偏振与微观矩阵元。不能将 √K 单独当作真实电离截面。

## 4. 发射时间和探测

在常数总速率的马尔可夫近似下：

P_transition(t)=1−exp[−(Γ_S+Γ_A)t]。

若后继光子全部高于探测阈值，且探测效率 η，忽略暗计数：

P_click(t)=η B_S [1−exp(−(Γ_S+Γ_A)t)]。

该公式是现象学模型，不是标准 QED 的定量对照。标准 QED 本身可有辐射电离末态，观察到额外光子并不能证明“原始光子身份连续”。

## 5. 理论缺口

1. 尚未由微观电磁相互作用计算 V_S、V_A。
2. 尚未加入完整三体相空间、电子/离子反冲、能量动量守恒和辐射红外处理。
3. 尚未为逐粒子原始身份提供可操作的观测量。
4. 尚未计算标准 QED 对同一实验设置的包容性截面，因此不能声称模型已优于 QED。
