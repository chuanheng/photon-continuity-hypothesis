# v0.39：失谐 JC 模型与普适身份守恒量

**方向 A“原始光子永远存在”仍未经证实。**

在 {|g,1⟩,|e,0⟩} 单激发子空间，去除公共能量、令 ℏ=1，H(Δ,g)=gσx+(Δ/2)σz。一般厄米荷 Q=aI+bσx+cσy+dσz。

对易子为 [H,Q]=2i[−(Δc/2)σx+(Δb/2−gd)σy+gcσz]。对于非零 H，严格守恒当且仅当 c=0 且 Δb=2gd，因此 Q=aI+λH，守恒空间维数为 2。对于 Δ=g=0，维数为 4。

对于多个 H_i，若存在两组参数满足 g_iΔ_j−g_jΔ_i≠0，则共同厄米守恒量仅为 Q=aI，维数为 1。若所有非零 H_i 平行，则维数为 2；零哈密顿量不施加限制。

本轮没有发现跨越不同耦合和失谐条件、同时区分两个 JC 基态的固定身份荷。I 的守恒是平凡的，不能证明光子永久身份。结论只适用于二维子空间、封闭 JC 旋波近似及指定哈密顿量族，不能排除额外场或更大空间中的其他守恒量。
