# v0.31：光电电离中后继光子的能量预算

**研究方向 A（原始光子永远存在）仍是未经验证的假说。**

## 1. 修复 v0.30 的物理缺口

v0.30 的玩具模型把后继光子独立加到标准软光子辐射上，但没有扣除它占用的末态能量。这不能直接代表真实的能量守恒散射过程。

对于初始静止氢原子，在非相对论近似下，设入射光子能量 Eγ、电离能 I、电子动能 Ke、质子反冲动能 Kp、后继光子能量 ε>0、其他辐射总能量 Erad≥0，则必要的能量关系为：

Eγ = I + Ke + Kp + ε + Erad。

所以 Ke + Kp = Eγ − I − ε − Erad ≥ 0。

例如 Eγ=20 eV，I=13.606 eV，ε=2 eV，Erad=0，则 Ke+Kp=4.394 eV。若另有 1 eV 辐射，剩余为 3.394 eV。不能在保留原先全部电子动能的同时凭空增加正能量光子。

## 2. 必要条件不等于充分条件

程序检查的是标量能量预算。真实散射还必须满足三维动量守恒：

pγ + pH = pe + pp + pγ' + Σprad。

完整分析应使用相对论四动量守恒、原子质量和电离能对应的束缚态质量差，并在允许的末态相空间上积分。尤其在阈值附近，动量约束会影响实际可达末态。

## 3. 实验设计

建议联合测量入射光子能量、电子动能及方向、离子反冲动量，以及额外辐射的能谱和角度。剩余能量可能来自普通 QED 伴随辐射、未收集粒子或系统误差，不能单凭“缺失能量”证明后继光子的身份连续性。

如果方向 A1 认为每次吸收都产生一个正能量后继光子，需要给出微观相互作用、能谱和联合分布，并与包含标准辐射修正的 QED 基准比较。若原始身份不可观测，则仍缺少可证伪预测。
