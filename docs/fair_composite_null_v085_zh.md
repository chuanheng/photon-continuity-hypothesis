# v0.85 — 公平复合零假设与永久身份相位的严格不可辨识性

> 本文件是数学与统计研究，不是光子 QED 的新动力学模型。研究仅证明指定观测模型下的操作性等价，不证明所有可能的“原始光子永久存在”理论都错误。

## 1. 公平模型

本轮针对 v0.84 中受检零模型遗漏普通环境机制的问题，在普通量子记忆模型中允许平稳 AR(1)、非平稳随机游走和分段突变漂移，并允许实验组存在普通相位偏置 \(b\)。假想的永久身份模型再添加一个身份相位 \(\delta\)。

每个时间点 \(t\)、校准/实验组 \(g\in\{0,1\}\)、正交相位 \(q\in\{0,\pi/2\}\) 和检测端口 \(\pm\) 有一个泊松计数：

\[
Y_{t,g,q,\pm}\sim\mathrm{Poisson}(\mu_{t,g,q,\pm}),\quad
\mu_{t,g,q,\pm}=\frac{N\eta}{2}[1\pm V\cos(\beta+q+g(u_t+b+\delta))]+d.
\]

其中 \(u_t\) 是普通差分环境漂移；\(N,\eta,V,d\) 是平均入射曝光、效率、可见度和暗计数参数。模型是简化的计数统计，不是由完整 QED 的吸收—再发射过程推导。

## 2. 精确重参数化定理

对任何身份模型参数 \(b,\delta\)，令普通零模型取 \(b'=b+\delta,\delta'=0\)。则所有 \(t,g,q,\pm\) 都有：

\[
\mu^{\rm identity}_{t,g,q,\pm}(b,\delta,u)
=\mu^{\rm ordinary}_{t,g,q,\pm}(b',0,u).
\]

每个泊松因子的均值相等，因此所有计数的联合概率分布相等。这个结论对**任意固定环境漂移轨迹**成立，所以对任何共同的漂移先验做边缘积分仍相等。只观测 \(u_t\) 的独立校准传感器无法进一步分开 \(b\) 和 \(\delta\)。

于是没有任何样本量、统计检验、MLE 或 Bootstrap 能在本模型的可观测量集合中分辨两个解释。它们的 KL 散度严格为0；浮点实验中有约1e−14的舍入误差。

## 3. Fisher 信息矩阵

令 \(J>0\) 为所有独立泊松计数对组合相位 \(b+\delta\) 的 Fisher 信息，则：

\[
I_{b,\delta}=J
\begin{pmatrix}1&1\\1&1\end{pmatrix},
\qquad \operatorname{rank}I=1.
\]

零信息方向为 \((1,-1)\)，增加数据只会放大非零特征值，无法使这个零方向变得可识别。

若**有真正独立且不受身份效应影响**的偏置校准 \(Y_b\sim N(b,\sigma_b^2)\)，则 \(I_{bb}\) 增加 \(1/\sigma_b^2\)，参数可以在数学上局部辨识。但这项独立校准的物理可实现性必须另行证明。

## 4. 实际计算

本地真实执行 31 项 Python unittest，全部通过，用时 0.009 秒。24 时间点，2组×2正交设置×2端口，总计192个泊松计数变量。取 \(b=0.11\) rad、\(\delta=0.20\) rad。

| 普通漂移过程 | 最大泊松均值差 | 模型 KL 散度 | 同一计数样本对数似然差 |
|---|---:|---:|---:|
| AR(1) | 1.421e-14 | 0 | 1.137e-13 |
| 随机游走 | 2.132e-14 | 1.421e-14 | 0 |
| 分段跳变 | 0 | 0 | 0 |

Fisher \((b,\delta)\) 在无独立偏置校准时的特征值约为 \([0,5576.958]\)；偏置校准 SD=.05 rad 时变为 \([192.837,5784.121]\)。这里是指定参数下的示例数值，而不是物理常数。

## 5. 变换型签名的条件性可辨识

假设额外效应带预先指定的变化签名 \(s_t\)，其相位为 \(b+\delta s_t\)。若普通偏置被限制为常数，并且 \(s_t\) 不恒定，那么 \(\mathbf1\) 与 \(s\) 线性独立，参数在设计层面可能可识别。但若普通模型合理地允许时间相关组别偏置 \(b_t\)，则选取 \(b_t'=b_t+\delta s_t\) 继续完全复制全部观测预测。

所以必须从独立物理机制推出 \(s_t\) 及允许的普通环境约束；不能人为设计“光子身份开关”就声称发现了新的物理自由度。

## 6. 预注册研究终止标准

1. 公平普通零模型在看数据之前必须包含合理的组别偏置与漂移机制，不能事后删减。
2. 如果身份模型的概率族与普通模型相同，应报告“操作性不可辨识”，不进行假身份效应发现宣称。
3. 只有建立满足玻色对称性、局域性、Lorentz 协变性和 QED 规范要求的独立身份动力学，并得出不能被普通模型复现的定量预测，才进入新的物理假说检验。
4. 若持续无法完成第3项，研究更适合定位为**量子可辨识性与数学等价性**，而不是关于“永恒个体光子”的经验定律。

## 7. 局限与 v0.86

本轮没有证明所有可能的隐藏标签都属于规范冗余，更没有建立自然界所有环境噪声的完整模型；它只是针对额外常数相位提供严格的参数冗余证明。

**v0.86：** 建议进行历史版本科研审计，归纳 v0.50—v0.85 的有效结论、未证明假设、实验可检验性与限制，修复缺失的 GitHub 历史文件，并建立仓库统一测试入口和论文草稿。
