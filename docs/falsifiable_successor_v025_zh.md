# v0.25：方向 A 的最小可证伪候选模型

## 研究目标
方向 A 主张每个原始光子永久存在；这仍是未经证实的假说。本轮从 v0.16 的竞争通道哈密顿量出发，增加有限探测效率、探测能量阈值和二项统计检验。**并非从 QED 推导出新的物理定律。**

## 1. 三态竞争通道
基底为 |I⟩=|g,1_H,0_L⟩、|S⟩=|e,0_H,1_L⟩、|A⟩=|e,0_H,0_L⟩。形式哈密顿量 H=[[0,κ,g],[κ,0,0],[g,0,0]]，取 ℏ=1。初态 |I⟩，Ω=sqrt(κ²+g²)。有

P_I=cos²(Ωt)，P_S=(κ²/Ω²)sin²(Ωt)，P_A=(g²/Ω²)sin²(Ωt)。

在首次最大转移时刻 t*=π/(2Ω)，P_S=κ²/(κ²+g²)，P_A=g²/(κ²+g²)。

在这个形式模型中，要求所有时刻严格禁止零光子末态，等价于 g=0；但该条件是额外施加的动力学假设，并非从永久身份公设推导出的定理。

## 2. 观测模型
设后继光子能量 ε>0，探测器能量阈值 Δ≥0，探测效率 η∈[0,1]，不考虑暗计数与其他辐射。在 t* 的一次试验中，

p_click=η κ²/(κ²+g²) 当 ε≥Δ，否则 p_click=0。

N 次独立试验的点击数 K 服从 Binomial(N,p_click)。对两个事先固定的模型概率 p_A 和 p_ref，使用对数似然比 log L_A(K)−log L_ref(K) 比较统计支持程度。未探测到后继光子不等于证明吸收发生，可能是探测效率或阈值导致的漏检。

示意参数 κ=1、η=0.8、ε=2、Δ=1：
- 方向 A：g=0，p_click=0.8；
- 允许吸收的对照：g=1，p_click=0.4。

这些数字是人为指定的模型示例，不是标准 QED 对真实实验的预测。

## 3. 关键物理缺口
形式三态模型把 |S⟩ 和 |A⟩ 写成相同对角能量，却假设它们有相同的原子激发态，而 |S⟩ 还包含正能量后继光子。这在真实无外部能量源的物理系统中**不能同时作为严格能量本征态**。必须引入不同物质末态、失谐项、连续谱或外部驱动，并重新检查四动量守恒。

此外，“原始光子身份”没有可操作定义；若后继能量永远低于任何可达探测阈值，模型也可能无法被现有实验区分。标准 QED 本身允许辐射末态，因此有额外点击并不自动支持方向 A。真正对照应使用完整标准 QED 对同一可观测量的预测，而不是任意选择 g>0。

## 4. 本轮贡献与下一步
本轮在既有三态模型基础上，首次给出明确的探测点击概率和二项似然检验，实现了一个**原则上可证伪的有效模型**，但尚未实现完整物理自洽性。

下一轮优先修复能量守恒缺口：引入失谐和不同物质末态，检查哈密顿量是否具有合理的微观来源，再与标准 QED 包容性预测对照。
