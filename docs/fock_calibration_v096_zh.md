# v0.96 科研审计：真实三玻色子 Fock 分束与独立监测下的可辨识性

**研究状态：完全合成量子光学数学模型，未进行真实光子实验；没有独立证明历史光子永久存在。**

## I. 玻色量子干涉不是独立粒子的经典分束

50:50 无损分束器的产生算符取
\[
a^\dagger\mapsto(c^\dagger+d^\dagger)/\sqrt2,\qquad
b^\dagger\mapsto(c^\dagger-d^\dagger)/\sqrt2.
\]

对 \(|2,1\rangle=(a^\dagger)^2b^\dagger|0\rangle/\sqrt2\) 做对称化展开，输出 \(|0,3\rangle,|1,2\rangle,|2,1\rangle,|3,0\rangle\) 的概率分别为

\[
(3/8,\ 1/8,\ 1/8,\ 3/8).
\]

当三光子相互完全可区分时，对应的是独立二项分束 \((1/8,3/8,3/8,1/8)\)。两种情况给出不同的阈值符合计数，差异源于玻色子交换干涉，并不是永久历史身份的证据。相同入射口的两个光子加另一个**充分时间分离**的光子，其输出数量可由二光子二项分布与独立单光子分布卷积，恰为此处选择的远延迟二项结果。任意部分可区分三光子不必满足这两个极限之一。

## II. 明确的前向概率

探测端口 j 的 n 光子阈值点击模型为
\[
Q_j(n)=1-(1-d_j)(1-\eta_j)^n.
\]
三光子污染的 near/far 双点击概率是相应 Fock/二项分布加权的 \(\sum_k P_k Q_A(k)Q_B(3-k)\)。

将传统四种源输入 \((1,1),(2,0),(0,2),(0,0)\) 扩充一个 \((2,1)\) 事件，所占比例 \(f=.065\) 从原来的 \(w_{11}=.90\) 中扣除。经过独立触发相关电子伪符合概率 \(q=.014\) 后，实际线上双点击概率是
\(C=C^0+q(1-C^0)\)。
其中电子伪符合为**特定匹配光学触发条件**的构造，不是所有相关暗计数的通用公式。

## III. 明确两个不同 estimands

预注册的无漂移固有模式重叠 \(M_0=.72\)；40 时间块普通环境扰动满足 \(u_t=u_{t-1}+\epsilon_t,\ \epsilon_t\sim N(0,.095^2)\)，各时刻 \(M_t=M_0 e^{-|u_t|}\)。因而实验期间平均 \(\bar M=M_0\cdot 40^{-1}\sum_t e^{-|u_t|}\) 与 \(M_0\) 不同。

**本轮强依赖三项独立标定假设：** 理想五分类光子数分辨源监测（能独立区分三光子事件），与主实验电子环境完全匹配的触发式光学挡光监测（测 q），以及**零读出误差、可观测全程 u(t) 的 oracle 相位监测**。普通阈值计数器或现实仪器不自动满足这些假设。

反解两路原始观测 \(C_{\rm near},C_{\rm far}\) 之前，先通过监测结果修正 \(C^0=(C-q)/(1-q)\)；在本轮明确的概率模型下：

\[
\widehat{\bar M}=
\frac{C^0_{\rm far}-C^0_{\rm near}+
\hat f(T_{\rm near}-T_{\rm far})}
{(\hat w_{11}-\hat f)[R_{11}(0)-R_{11}(1)]},
\qquad
\widehat M_0=\widehat{\bar M}/A.
\]

其中 \(A\) 是由理想相位监测获得的已知期间衰减因子。只有近、远两项光学符合概率，却同时试图自由估计 \(\bar M,f,q\)，Jacobian 是 \(2\times3\)，具有零信息方向；独立标定不是可选装饰。

## IV. 已实际运行的本地统计试验

本地原始源码 **44/44 单元测试通过**。一个固定随机种子案例中：
- 真实固有重叠 \(M_0=.7200\)
- 期间真实 \(\bar M=.556640\)
- 校正的 \(\widehat{\bar M}=.552545\)
- 校正的 \(\widehat M_0=.714703\)
- 旧 v0.95 错设估计 \(=.539120\)
- \(\hat f=.065220,\ \hat q=.014578\)
- 单次99轮完整重校准 Bootstrap 的 \(M_0\) 95% 百分位区间为 [0.661720, 0.760642]。

**60 组独立外层数据，每组99次参数 Bootstrap，共5,940次内层模拟**，其中每次重新生成源类别、探测效率、暗计数、匹配触发 q 等标定数据，但**严格条件化在每组已知的真实相位轨迹**：

| 指标 | 结果 |
|---|---:|
| 均值 \(\widehat M_0\) | 0.722060 |
| 均值旧模型重叠估计 | 0.531165 |
| 均值真实 \(\bar M\) | 0.545122 |
| 均值校正 \(\widehat{\bar M}\) | 0.545680 |
| 针对 \(M_0\) 的标称95% CI覆盖 | 57/60 |
| 针对逐次真实 \(\bar M\) 的CI覆盖 | 57/60 |

57/60 的精确二项95%区间约为[86.08%,98.96%]，不能以小样本下恰好95%的经验频率宣称正式证明标称覆盖率。

## V. 科学意义、局限与后续

本轮检验了额外普通物理污染与电子背景，在**独立且有效的外部标定 + 正确前向模型**下，可以恢复固有及期间平均 HOM 模式重叠的估计。它没有排除未知物理误差，也没有提供跨吸收与再发射的永久光子个体编号。

尚未解决：相位监测误差、五分类源监测误判矩阵、匹配触发条件失真、部分可区分三玻色子、空间/频率相关探测器效率、超过三个光子及非平稳仪器噪声。

**v0.97：** 对这三类外部监测自身的模型错设做灵敏度曲线，检查准确度与覆盖率边界。若新增“身份因子”只改变普通的总 HOM 重叠，它仍可由一般混合光场模式重参数化复制。

完整已执行源码、44项测试、60组原始逐次记录、图及SHA-256 清单位于本轮可下载的 photon_v096_complete.zip；GitHub 对应源码独立整理、远程 CI 结果尚未核实。
