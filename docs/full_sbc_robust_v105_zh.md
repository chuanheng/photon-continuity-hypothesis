# v1.05 多参数 HOM 联合先验 SBC 与重尾传感器预测

**全部为合成量子光学与统计模拟，没有真实光子实验，也没有“原始光子永久存在”的独立可检验预测。**

## 研究动机与 SBC 定义

v1.04 仅完成一维可解析 HOM 光学子模型的正式 SBC。按照 [Stan Simulation-Based Calibration](https://mc-stan.org/docs/stan-users-guide/simulation-based-calibration.html)，正确的 SBC 必须先从**与推断所使用的同一联合先验**抽取参数，继而从同一观测模型抽取数据，再计算该参数在后验样本中的秩。固定一个物理参数反复仿真，只能进行固定真值覆盖率审查，不是完整的先验SBC。

v1.05 使用带三玻色子分束、PNR污染与误分类、两台阈值探测器、匹配触发电子背景和潜在相位的**受限但参数相互耦合的联合模型**。此模型专门为了验证推断闭环，并不是全面模拟真实光学设备。

## 生成过程与观测机制

50:50分束器内 \(|2,1\rangle\) 三个不可区分玻色子的近延迟输出数分布为 \((3,1,1,3)/8\)，远延迟完全可区分极限为 \((1,3,3,1)/8\)。使用五类输入事件 11、20、02、00、21，11+21合计0.90，20、02各0.04、00为0.02。令三光子比例 \(f=0.9r\)，而近远光学有效双单光子模式重叠为 \(M\,24^{-1}\sum_t e^{-|u_t|}\)。

采样的独立先验及校准观测如下：

| 参数 | 联合先验 | 附加观测 |
|---|---|---|
| \(M\) | Uniform(0,1) | 近远符合（各1500次） |
| \(r\) | Beta(2,30) | 源端240次PNR报告 |
| \(\alpha=P(21\to11)\) | Beta(2,8) | 已知21标准250次 |
| \(\beta=P(11\to21)\) | Beta(1,45) | 已知11标准250次 |
| 在线伪符合 \(q\) | Beta(2,160) | 500次匹配电子参考 |
| 效率 \(\eta_A,\eta_B\) | Beta(25,8), Beta(23,10) | 各500次理想已知效率参考 |
| 暗点击 \(d_A,d_B\) | Beta(1,350), Beta(1,300) | 各900次挡光参考 |
| 游走标准差 \(\sigma_w\) | {0.07,0.11,0.17}等概率 | 24块相位序列 |
| 读数标准差 \(\sigma_r\) | {0.10,0.17,0.26}等概率 | 每块2次相位读数 |
| 零点 \(b\) | {-0.035,0,0.035}等概率 | 40次零点参考 |

\(u_0=0\) 已知，之后 \(u_t-u_{t-1}\sim N(0,\sigma_w^2)\)；读数 \(y_{tj}\sim N(u_t+b,\sigma_r^2)\)。

源监测**不直接观测真正的三光子比例**，而只观测分类器报告，报告概率 \(p_{\mathrm{21report}}=r(1-\alpha)+(1-r)\beta\)。因此 \(r,\alpha,\beta\) 经相同数据的似然联结；HOM读数又通过光学场与 \(M,r,q,\eta,d,u\) 耦合。前向模型基于标准量子光学、有效探测器以及特定理想参考假设，绝非独立的新光子身份机制。

## 推断与误差限制

对受标记参考制约的 \(\alpha,\beta,q,\eta,d\) 采用 Beta 后验采样；条件于两行PNR误分类率，通过151点的 \(r\) 网格计算源报告的二项条件后验，**同时将源报告边缘证据乘回到PNR参数权重**。对27点随机游走超参数利用完整相位似然求后验，从其条件精确高斯平滑后验抽取相位路径。对161点 \(M\) 网格计算near/far双点击二项似然并进行重要性粒子边缘化。

每次数据使用850个候选粒子，联合后验抽49个样本；离散超参数秩采用随机破同值方法。网格及粒子数使得后验是**近似**的，其SBC仍需审计，不能自动宣称“数学精确”。

## 实际先验 SBC（450次，12个参数）

- \(M\) 贝叶斯95%等尾可信区间覆盖 **428/450 = 95.111%**；Clopper–Pearson精确95%二项区间 **[92.691%, 96.911%]**。
- 850个校准—相位联合粒子ESS中位 **582.407**。
- 参数 \(M,r,\alpha,\beta,q,\eta_A,\eta_B,d_A,d_B,\sigma_w,\sigma_r,b\) 的10箱rank卡方检验p值分别是：**0.4771、0.6071、0.1761、0.6348、0.2423、0.5119、0.8285、0.6856、0.3992、0.3398、0.1255、0.0550**。这只能称“未检出显著偏离”，不是推断完美无误的证明。
- 此处是**先验平均**校准；若固定某个具体真值、使用错误真实先验或复杂噪声，SBC并不能保证相同覆盖。

## 稳健传感器：污染训练与留出两端

另在**零相位参考子模型**，每次训练100个、留出80个数据点；比较Gaussian位置尺度MLE与固定自由度4的Student-t位置尺度MLE。纯Gaussian为 \(N(0.015,0.15^2)\)；污染情景同时在训练/留出按8%概率增加标准差0.9的独立高斯扰动。每情景180次，比较平均**留出对数预测密度**。

| 情景 | Student-t胜出的配对组数 | Student-t − Gaussian平均评分差 |
|---|---:|---:|
| 纯Gaussian | 17/180 | −0.02406 |
| 训练与留出均有8%污染 | **180/180** | **+0.41872** |

这只证明在此**特定重尾生成过程**下Student-t有更高留出预测对数密度。没有在完整HOM状态空间中替换Gaussian为Student-t并重新执行正式SBC；本轮不声称做了此事。

## 科研结论与后续

本轮完成了**受限且明确生成机制的多参数模型**的正式SBC，改善了v1.04仅有子模型SBC的不足。但该模型依赖可制备的理想PNR标准、直接效率校准、匹配电子参考、最多三光子事件、两种极限可区分性和**27点离散相位超先验**。不等于任意真实光子实验均已得到可靠后验。

下一轮 v1.06 应考虑连续相位超先验与部分可区分三光子，并开展先验错设、传感器异常和稳定性变更下的**模型外**覆盖率审查。即使SBC良好，也不能把HOM模式重叠当作跨吸收和再发射的永久光子历史编号；仍需给出标准QED+环境模型不能复制的独立物理预测。
