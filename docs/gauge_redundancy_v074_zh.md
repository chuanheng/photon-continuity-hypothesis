# v0.74 规范冗余、Gauss 约束与物理 Hilbert 空间

**范围：** 三量子比特、单规范连接、两端物质比特的 Z₂ 格点规范玩具模型；不是光子 QED，也不证明永久身份存在。

## 1. 局域生成元与约束

扩展 Hilbert 空间 H_ext=C²_L⊗C²_link⊗C²_R，维数 8。

G_L=Z_L⊗X_link⊗I_R，G_R=I_L⊗X_link⊗Z_R；[G_L,G_R]=0，G_i²=I。

选择 Gauss 约束 G_L|ψ>=G_R|ψ>=|ψ>，对应 P=(I+G_L)(I+G_R)/4。计算可得 P²=P、rank(P)=2。物理空间基为 |0,+,0>、|1,-,1>，其中 X|±>=±|±>。

## 2. 规范不变算符与物理逻辑比特

O_Z=Z_L⊗I⊗I，O_X=X_L⊗Z_link⊗X_R，均与 G_L、G_R 对易。若 B 的列向量为上述两个物理基态，则 B†O_ZB=σ_z、B†O_XB=σ_x；物理态并非彼此不可区分。

## 3. 群平均与 Gauss 投影不相同

T(ρ)=1/4 Σ_{g∈{I,G_L,G_R,G_LG_R}}gρg† 是完全正保迹的群平均，使输出对群变换不变，却不保证约束 G_i=+1。

ρ_phys=PρP/Tr(Pρ) 是条件投影，不是所有输入都确定成功的信道。

对 |000><000|，物理扇区权重为 0.5；群平均之后仍是 0.5；群平均态与归一化投影态间 Frobenius 距离为 0.7071067812。两种方法不能混用。

## 4. 身份量子比特不是自动的规范自由度

对 ρ_S⊗|0><0|_H 和 ρ_S⊗|1><1|_H，在仅允许 A_S⊗I_H 的测量时，二者等价。但 I_S⊗Z_H 可以完全区分二者，且这个算符仍与原有扩展 Gauss 生成元 G_L⊗I_H、G_R⊗I_H 对易。

因此，**不可访问辅助变量并不自动等于规范冗余**。要把永久身份定义为规范变量，需要独立指定作用于它的规范群、约束和全部允许的可观测算符。

## 5. 与光子连续存在假说的关系

增加身份编号作为数学变量是可行的；然而它可能是描述冗余、受限制的不可访问辅助自由度，也可能是具有独立耦合的真实自由度。要从概念变成可检验的光子物理理论，还需与玻色对称化、局域性、QED 规范结构、守恒定律和独立观测预测一致。

**实测：** 本地 Python 33 项 unittest 全部通过。所有数值为有限维模型的矩阵运算结果，不能外推为真实光子的实验发现。
