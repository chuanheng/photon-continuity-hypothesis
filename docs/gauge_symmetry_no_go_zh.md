# v0.13：方向 A 的光子数对称性与规范相容性检验

**研究承诺：** 保留“每个原始光子永久存在”作为核心待证公设；以下是约束与反例分析，不是对该公设的验证。

## 1. 不要混淆三种守恒

- QED 的电磁 U(1) 规范对称性关联电荷守恒；光子电荷为零。
- 假设的光子数 U(1) 要求光子湮灭算符 a_k 在全局相位变换下取得相位；若是精确对称性，则对应的光子数算符必须与完整哈密顿量对易。
- “每个原始光子的永久身份”比总光子数守恒更强；不可区分的玻色子并无标准的逐粒子身份标签。

## 2. 最小两能级原子检验

令 N=a†a，H_int=ℏg(a σ_+ + a† σ_−)。

[N,a]=−a，[N,a†]=a†，因此

[N,H_int]=ℏg(−a σ_+ + a† σ_−) ≠ 0。

标准 JC 模型守恒 C=N+σ_+σ_−，而不守恒 N。即使给原子激发赋予抵消的荷，也只会恢复 C 的守恒，允许 |g,1⟩→|e,0⟩；不能证明光子永存。

## 3. 全局相位对称性与电磁规范对称性不同

形式上设 a_k→e^{iθ}a_k，a†_k→e^{−iθ}a†_k。光子数守恒的相互作用通常要求每项中产生和湮灭算符数量相等。这个假设的相位对称性**不是** QED 的局域规范变换 A_μ→A_μ+∂_μχ。

对于厄米实电磁四势 A_μ，直接施加普通复相位 A_μ→e^{iθ}A_μ 一般破坏厄米性，不能把它当成合法的普遍光子数规范对称性。

自由电磁场具有与电磁对偶相关的特殊结构，但在有电荷的相互作用理论中不能简单等同于普遍的“每个光子身份守恒”。

## 4. 选择定则的代价

若强制 [H,N]=0，单光子完全吸收末态 |e,0⟩ 不可由 |g,1⟩ 产生。这与标准原子吸收、光电电离和探测理论的非零吸收振幅直接形成冲突。要让方向 A 成立，必须提供新的微观理论，重新计算所有相关可观测量，不能只是删去吸收通道。

## 5. 可能的研究路径及判定标准

A. 新的物理自由度：原始光子的身份对应新量子数或隐藏场。但必须说明为何它不破坏已知电磁现象，并推导非零、可检测的效应。

B. 软光子后继：每次相互作用都伴随正能量的低能光子。必须推导产生概率、红外安全的包容性预测和截止依赖，并说明其为何是“原始”而非普通辐射。

C. 仅附加不可观测身份标签：若不改变任何实验概率，属于目前无法实证的本体论解释，而不是新的可证伪物理理论。

**结论：** 仅靠新增光子数 U(1) 对称性，无法同时保留标准吸收相互作用与方向 A 的逐光子永存要求。此为在所列假设下的限制性结论，不是涵盖一切可能新理论的普遍不可能性定理。
