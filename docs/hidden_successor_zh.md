# v0.14 方向 A：隐藏后继光子的最小有效模型

**研究状态：假设性模型，非实验发现。** 保留“每一个原始光子永远存在”的研究公设，但不将其视为已证实的规律。

## 1. 三类末态与能量账本

定义初态 |H⟩（一个高能光子与基态物质），候选末态 |L⟩（物质激发并存在低能后继光子）及 |A⟩（物质激发且没有光子）。忽略反冲、辐射和其他激发时，若入射能量 E，物质获得 Δ，则低能后继 ε=E−Δ>0。只要 ε>0，就不能宣称物质在同一事件中获得全部 E。

若后继是自由无质量粒子，需满足 ε=pc（不是只指定能量而不指定动量）。若后继有非零质量 m，则必须满足 ε²=p²c²+m²c⁴，且 ε≥mc²。称其为“光子”需解释自旋、规范结构和与标准电磁场的关系；不能将任意隐藏粒子直接等同于原始光子。

## 2. 有效哈密顿量

取基底 (|H⟩,|L⟩,|A⟩)，设

H_eff = [[E_H,κ,g],[κ*,E_L,η],[g*,η*,E_A]]。

- κ：高能态与低能后继态之间的耦合。
- g：直接完全吸收通道。
- η：低能后继与零光子末态的耦合。

只有人为施加 g=η=0 才能确保 |A⟩ 对所有时间严格不可达。这种选择不是由隐藏后继的存在自动推导出来的。

## 3. 与标准实验的一致性

若 g 或 η 非零，方向 A 的严格版本可能被违反。若它们被强制为零，必须重新解释光电吸收、原子跃迁与光子探测器的工作机制，并给出与已知截面和能谱相符的计算。

“后继低于探测阈值”不等于“后继存在”。需要事先给定 ε 的分布、产生概率和耦合强度，并计算探测器响应。把所有未探测事件都归为隐藏后继会使假说失去可证伪性。

## 4. 隐藏状态与原始身份的区别

|L⟩ 中存在一个后继粒子，不证明它就是入射的“同一个”光子。量子场论的不可区分性要求方向 A 另行定义身份连续性的可操作量。即使定义了新守恒荷，也必须展示它如何与可测量结果关联。

## 5. 一个重要的不可判别性结论

若所谓隐藏后继不改变任何可访问系统的约化密度矩阵、任何测量概率或关联，则所有可执行实验对“有后继”和“无后继”的预测完全相同。此时方向 A 是额外本体论解释，而不是已获实验支持的独立理论。

若它改变可访问系统的能量、反冲、退相干、符合计数或缺失能量分布，则可以建立实验上可比较的模型，但必须区分标准背景与新效应。

## 6. 这轮代码的范围

models/hidden_successor_budget.py 仅检查能量、无质量后继动量及可探测阈值的数学关系；不计算耦合振幅、概率或真实物理截面。测试通过与否只验证这些数学关系。

## 7. 下一步

检验隐藏后继是否能同时满足：（1）严格正能量；（2）四动量守恒；（3）概率归一化；（4）已知光电吸收现象；（5）独立可检验预测。优先建立一个包含物质反冲的两体/三体运动学模型，而不是继续增加不可测自由参数。
