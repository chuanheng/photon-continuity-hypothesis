# v0.29：氢原子 1s 光电电离的库仑连续态截面

**方向 A：原始光子永远存在，仍是未经验证的假说。**

## 研究目标
v0.28 采用平面波末态；本轮改用包含末态库仑相互作用的非相对论氢原子 1s 电偶极总截面解析公式。

## 公式
固定原子核、非相对论、长波长 E1 近似。入射能量 ω，电离能 I，精细结构常数 α，玻尔半径 a0：

σ(ω)=(512π²/3)αa0²(I/ω)^4 exp[-4η arctan(1/η)]/[1−exp(−2πη)]，η=sqrt[I/(ω−I)]，ω>I。

阈值极限 σ(I+)=(512π²/3)αa0² exp(−4)≈6.304318×10⁻¹⁸ cm²=6.304318 Mb。

本公式不是完整相对论 QED 结果；未包含有限核质量、反冲、相对论及辐射修正。

## 对方向 A 的约束
标准吸收通道具有非零且可量化的截面。方向 A 若要求每次电离后都留下正能量后继光子，必须明确能量动量守恒机制，并计算额外光子的能谱、角关联和探测概率，与标准 QED 的辐射修正区分。若身份标签不可观测且不影响任何观测量，则不是独立可证伪的理论。
