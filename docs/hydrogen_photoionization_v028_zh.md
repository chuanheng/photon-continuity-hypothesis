# v0.28：氢原子 1s 光电电离的非零电偶极跃迁矩阵元

**研究方向 A：原始光子永远存在，仍为未经验证的物理假说。**

## 1. 模型和近似

氢原子 1s 初态 ψ_1s(r)=exp(−r/a0)/sqrt(πa0³)。在原子单位制 ℏ=m_e=e=a0=1，初态 ψ_1s(r)=exp(−r)/sqrt(π)。

为得到解析结果，将电离电子末态近似为 (2π)^(−3/2) exp(i p·r)。这不是库仑连续态的精确解。采用长波长电偶极近似和沿 z 方向的线偏振，研究长度规范矩阵元 M(p)=⟨p|z|1s⟩。忽略离子反冲、相对论效应、末态库仑畸变和完整截面归一化。

## 2. 解析计算

按 (2π)^(−3/2) 傅里叶变换约定：

φ_1s(p)=(2√2/π)/(1+p²)²。

因为 ⟨p|z|1s⟩=i ∂φ_1s(p)/∂p_z，

M(p)=−i(8√2/π)p_z/(1+p²)³，

|M(p)|²=(128/π²)p_z²/(1+p²)^6。

固定 p=|p| 的角度积分：

∫dΩ |M(p)|²=(4π/3)(8√2/π)² p²/(1+p²)^6。

对于 p>0，该积分严格为正，表明在此近似下存在非零的标准零后继光子电偶极跃迁强度。p_z=0 的特殊方向矩阵元为零，不代表整个通道被禁止。

忽略反冲时，氢 1s 的电离阈值为 0.5 Hartree，出射动量 p=sqrt[2(ω−0.5)]（ω≥0.5）。**这些公式不直接给出绝对光电电离截面**；需要能量壳态密度、光场耦合和正确的库仑连续态等。

## 3. 对方向 A 的意义

方向 A 在此前有效模型中通过设置零光子吸收耦合 g=0 或 Γ_A=0 来实现永久后继光子要求。本轮表明：标准电偶极耦合对氢原子 1s 光电电离的零后继光子末态具有一般非零的跃迁矩阵元。不能把 g=0 当作无需论证的普适电磁规律。

然而，非零吸收矩阵元不能单独排除一个不改变任何观测量的隐藏“身份”解释。若方向 A 声称额外存在正能量后继光子，则必须计算完整能量动量守恒和与标准辐射修正的区别；若只保留不可观测标签，则必须提出可操作的实验区别，否则不构成独立可证伪理论。

## 4. 限制与后续

- 平面波末态不满足氢离子库仑势的精确散射边界条件，尤其在阈值附近可能产生明显偏差。
- 非相对论 E1、固定原子核、忽略光子动量与反冲。
- 尚未计算微分/总光电截面，也没有和实测数据定量拟合。
- 不应将本模型当作完整 QED 的数值验证。

v0.29 应改用库仑连续态或可信的标准氢原子光电电离截面，建立基准比较；同时明确方向 A 是否主张额外的可探测辐射。
