# 光子连续存在假说：假设清单（v0.1）

作者：Chuanheng Wang（王传恒）。**未验证、未经同行评审。**

- H1 原始入射光子即使与物质发生相互作用也持续存在；这是待检验假设，不是已知事实。
- H2 假定原始光子保持原传播方向，且以真空光速 c 传播。
- H3 光子可通过条件性的离散事件向物质转移能量；微观机制未知。
- H4 任意有限次能量转移后剩余能量严格大于零；在无限次极限下可趋近零。
- H5 物质可能将获得的能量再转移给假定存在的低能背景光子。
- H6 背景光子数量、频谱及各向同性是假设，尚无独立证据。
- H7 原始光子的相位、偏振、信息及“身份”如何定义或保留，尚未确定。

## 必须解决的问题

1. 与光电吸收、康普顿散射、相干光学实验的兼容性。
2. 能量与动量守恒、材料反冲和微观相互作用规律。
3. 量子场论中不可区分光子的身份定义。
4. 背景光子谱、有限能量密度与热力学约束。
5. 产生与现有模型不同、可定量证伪的预测。

**注意：** 比尔–朗伯定律描述理想窄束中未相互作用的光子通量衰减，不能证明单个光子持续降能；宇宙微波背景也不是本假说的证据。
