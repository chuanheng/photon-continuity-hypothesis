# v0.69 多条件 HOM 干涉的结构性不可辨识

定义 P=(1−V)/2。比较单参数 V_A(x)=exp(−λx) 与 V_B(x)=exp(−κx²)。当两个解释采用完全相同的 V(x) 时，所有测量的似然函数一致；任意样本量无法区分。

取 x=[0.2,0.4,0.7,1,1.5,2]，λ=0.7，以 A 为真。对 B 优化 κ≈0.8920229。每条件 n=100、1000、10000 次测量时，期望 2ΔlogL 分别为 22.74155、227.41553、2274.15530。单一 x>0 下，κ=λ/x 可以使两模型完全重合。

以上为现象学模型计算，不是 QED 推导，也不是永久光子身份的证据。若两模型仅对同一数学机制赋予不同解释，则不可辨识。现实实验还需要考虑损耗、暗计数和系统误差。
