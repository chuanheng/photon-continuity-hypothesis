# v0.79：永久身份相位的结构性不可辨识

本轮是有限维统计玩具模型，**不是 QED 的预言或永久光子身份的证据**。

## 分布
对存活率 η、可见度 V、均匀暗计数背景比例 d、扫描相位 x、普通相位 β、假定的额外身份相位 δ、干预 z：

\[
p=(1-d)(1-\eta,\eta[1+V\cos(x+\beta+z\delta)]/2,\eta[1-V\cos(x+\beta+z\delta)]/2)+d(1,1,1)/3.
\]

定义有效损失 L=(1-d)(1-η)+d/3、振幅 A=(1-d)ηV，概率只由 (L,A,β+zδ) 决定。故 η、V、d 不能仅凭此类实验分别识别，需独立标定。

## 无干预时的严格退化

若全部 z=1，则 (β,δ)→(β+c,δ−c) 保持所有概率。Fisher 信息矩阵中两列相同，(L,A,β,δ) 维度为4，秩最多3。允许 β 自由拟合时，δ 的 Profile Likelihood 严格平坦：任意 δ' 都取 β'=β+δ−δ' 即可。

## 假定存在差分操作时

若独立实现可控 z=0/1，且其本身不会引入未知普通组别相位偏置，四参数可局部识别。设置 η=.65,V=.8,d=.05,β=.13,δ=.2，四个扫描点 x=[.15,.8,1.7,2.5]，每条件1000次：

| 计算 | 仅z=1 | z=0和1 |
|---|---:|---:|
| Fisher秩 | 3/4 | 4/4 |
| 最小特征值 | 约1.08e-13 | 340.7729507 |
| nuisance校正后的δ条件信息 | 0 | 447.7120385 |
| 11个假设δ的最大Profile deviance | 5.13e-14 | 不适用 |

这个可控开关**只是为了显示可辨识性条件而设的数学假设**；真实光子身份不存在已验证的该类控制装置。如果 z 同时产生额外普通相位，身份退化会重新出现。

## 研究结论

如果“原始光子永久存在”只为普通量子记忆提供不可辨识的重命名，它没有独立实验预测。下一轮v0.80须给身份模型及普通记忆模型公平的nuisance参数，加入独立标定，提出能排除所有普通相位漂移解释的跨条件预测，并预先定义证伪标准。

参考：Rothenberg (1971), *Identification in Parametric Models*, Econometrica, https://doi.org/10.2307/1913267; van der Vaart, *Asymptotic Statistics* (1998).
