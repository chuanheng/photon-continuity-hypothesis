# v0.50：永久身份守恒量的最小模型与可观测性检验

## 研究地位
这是标准量子力学的双量子比特玩具模型，不是已建立的光子永久身份理论。模型中第二个量子比特只是一个附加自由度；将它命名为“原始光子身份”没有独立物理依据。

## 数学定义
取 ℏ=1，JC 单激发子空间作为第一个二维空间，身份辅助空间作为第二个二维空间。定义

- H₀=g σx⊗I；
- Hλ=g σx⊗I+λ σz⊗σz；
- Qid=I⊗σz。

两种哈密顿量均厄米，且 [H₀,Qid]=[Hλ,Qid]=0；因此 U(t)=exp(−iHt) 幺正且身份标签的 σz 守恒。

在身份 σz=±1 的子空间，H±=gσx±λσz，本征能量为 ±√(g²+λ²)。总四维模型中每个能量各有二重简并。

## 可观测性
若 λ=0，任何仅作用于 JC 系统的可观测量 O⊗I 都无法区分身份标签。对任意联合密度矩阵 ρ，Tr[ρ(O⊗I)]=Tr[(Trid ρ)O]。完全解耦标签是不可检验的解释性扩展。

若 λ≠0，从 JC 初态 |0⟩ 与固定身份本征态出发，翻转概率为

P(0→1;t)=g²/(g²+λ²) sin²(√(g²+λ²)t)。

该公式与身份 σz=±1 的符号无关，但不同于 λ=0 时的 sin²(gt)。它说明额外耦合**可以**改变动力学，不能说明额外自由度确实是永久光子身份；这完全可以解释为标准双量子比特耦合。

## 理论障碍
1. Qid 的守恒是模型构造时直接放入的，不能反向证明物理光子具有永久个体身份。
2. 该玩具模型没有定义多光子不可区分性、玻色对称化、规范不变性、局域性和相对论协变性；不构成完整 QED 扩展。
3. 新能谱取决于 λ，不能仅由“身份永久存在”公设推导出 λ 的数值或非零性。
4. 若 λ=0，H₁ 与标准模型的可观测预测相同，统计检验无能为力。
5. 即使 λ≠0 被测到，也不能自动归因于光子身份，必须排除普通辅助自由度和已知相互作用。
