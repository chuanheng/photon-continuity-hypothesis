# v0.36：永久身份标签的不可观测性与显式耦合

## 研究定位
方向 A“原始光子永远存在”仍是未经验证的假说。本轮研究完全解耦的身份辅助态与耦合辅助态之间的操作差别；这里的量子比特辅助态不是光子永久身份存在的证据，也不是 QED 的新场论。

## 1. 解耦标签的操作等价
令可观测系统空间 H_S，身份空间 H_I。若总哈密顿量 H=H_S⊗I+I⊗H_I，所有测量为 M_k⊗I，且身份从不通过相互作用耦合回系统，则观测概率 Tr[(M_k⊗I)ρ_SI]=Tr[M_k Tr_I(ρ_SI)]。在初态约化密度矩阵相同的前提下，任意身份态的改变都不影响可观测测量统计。

这个结论是带有假设的操作等价，而不是“任何不可观测标签在任何理论中都无意义”的无条件断言。若允许系统—身份耦合或测量身份，结论不再适用。

## 2. 最简耦合模型
取 H=g σ_z^(S)⊗σ_z^(I)，初态 |+⟩_S|+⟩_I，U(t)=exp(−iHt/ℏ)。迹掉身份后，系统约化密度矩阵为

ρ_S(t) = [[1/2, cos(2gt/ℏ)/2], [cos(2gt/ℏ)/2, 1/2]]。

因此干涉可见度 V=|cos(2gt/ℏ)|，纯度 Trρ²=(1+V²)/2，X 基底 |+⟩ 输出概率 P_+=(1+cos(2gt/ℏ))/2。

在 gt/ℏ=π/4 时 V=0、纯度=1/2；在 π/2 时 V=1、纯度=1。这是普通量子力学的纠缠与复相干现象，并非新的光子身份证据。

## 3. 尚未解决的物理问题
- 此模型没有处理光子吸收后的零光子 Fock 态，也没有建立可在该态中存续的正能量光子。
- “身份”是否代表新自由度，必须与偏振、频率、环境、物质态等标准自由度明确区分。
- 若提出新相互作用，需给出场论中的算符、对称性、守恒律与已有实验约束，不能把任意辅助量子比特解释为原始光子。
- 若所谓身份永远与可观测量解耦，则它不产生区别于标准理论的实验预测。
