# v0.35：光子身份连续性与可观测性的分界

## 核心问题
方向 A 声称“原始光子永远存在”，但没有独立可观测的个体身份定义。标准量子理论描述态演化与不可区分粒子统计，不为每个光子分配可实验读取的永久序列号。吸收—再发射中的状态相关性不等于个体身份保存。

## 两种候选方案
A0：引入完全不可观测、与所有相互作用解耦的身份标签。这类标签不改变可观测概率，不能区分于标准理论，也不能被实验确证。

A1：身份与可观测系统耦合，例如两条路径分别关联不同辅助态 |χ1⟩ 和 |χ2⟩。平衡双路径模型中，输出端口概率为 P+=(1+Re[e^{iφ}⟨χ1|χ2⟩])/2，理想可见度 V=|⟨χ1|χ2⟩|。两态正交时路径信息完全可区分，干涉消失；两态相同时可见度为一。

## 互补性
对等先验纯辅助态，最优 Helstrom 路径猜测成功率 Pguess=(1+sqrt(1−V²))/2，定义 D=2Pguess−1，得到 V²+D²=1。这些关系完全属于既有量子信息理论，不是新物理推导。

## 为什么还不能证明“永久身份”
1. 辅助态可能只是环境、偏振、频率或其他普通量子自由度；观测到退相干不意味着发现永久个体身份。
2. 完全不可观测的身份标签没有独立预测。若能耦合并被测量，必须给出新相互作用的哈密顿量、对称性和能量动量守恒，并接受已有干涉实验约束。
3. 在光子被吸收后的零光子 Fock 态中，不能直接把额外标签当作一个仍具有正能量的自由光子。那需要额外场、态空间或相互作用的明确动力学定义。
4. 仅添加一个张量积辅助态并不能推导吸收后的个体身份持续性。

## v0.36 建议
不应直接把“身份”当作新的粒子或额外辐射。首先构造两个严格不同的数学理论：纯标签且与观测完全解耦的理论，以及具有显式耦合哈密顿量的理论。证明前者在操作意义上与标准理论不可区分，并检验后者是否与已知 QED 的可观测量不同。
