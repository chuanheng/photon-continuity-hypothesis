# 光子连续存在假说 v0.67：内部自由度与玻色对称性

## 问题
能否引入内部标签而不违反玻色交换对称性？能，但这并不能证明原始光子永久存在。

## 数学结构
单粒子空间 H=H_mode⊗H_internal，多光子空间为 Sym^N(H)。双粒子交换算符 S|i,j⟩=|j,i⟩；对称投影 P+=(I+S)/2，维数 d(d+1)/2。集体占据数 N_i=P_i⊗I+I⊗P_i 与 S 对易；单槽位算符 P_i⊗I 通常不与 S 对易。

## 可观测内部标签
两光子从平衡分束器不同输入端入射，内部态为 |a⟩、|b⟩，探测器不分辨内部态时，HOM 符合概率 P_coinc=(1-|⟨a|b⟩|²)/2。相同态为0，正交态为1/2。内部态影响干涉，并不说明它是永久个体身份。

## 不可辨识性
只要初态、动力学、测量相同，把内部标签解释为“普通量子数”或“永久身份”给出完全相同的实验概率。纯粹更名没有新预测。

## 限制
该模型是固定粒子数的非相对论量子信息示例，未建立完整 QED 吸收理论。内部量子数守恒不等于原光子个体永存；要成为新理论，必须给出独立动力学与可证伪预测。
