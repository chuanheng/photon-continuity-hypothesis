# v0.10：方向 A 面对单光子吸收的量子动力学约束

**核心假说保持不变：每个原始光子永远存在。** 本文将其视为尚未验证的公设，而非标准理论事实。

## 1. 标准的最小模型

在旋波近似、单一场模式、封闭两能级原子、初态 |g,1⟩ 的 Jaynes–Cummings 模型中，单激发子空间的相互作用哈密顿量（ℏ=1）为

H_eff = [[0,g],[g,Δ]]，

其中 Δ 是原子与场的失谐量，g 是耦合强度。整体能量零点与符号约定不影响下述概率。

Ω = sqrt(Δ²+4g²)，

P(|e,0⟩,t) = (4g²/Ω²) sin²(Ωt/2)，

P(|g,1⟩,t) = 1−P(|e,0⟩,t)。

在共振 Δ=0 时，|ψ(t)⟩=cos(gt)|g,1⟩−i sin(gt)|e,0⟩（忽略整体相位）。在 t=π/(2g)，单模式的光子数严格为零、原子激发概率为 1；在 t=π/g 可回到初始状态。这是能量激发的可逆交换，不意味着“原始光子潜藏在原子内部”。

## 2. 对方向 A 的逻辑挑战

若 A 断言每个相互作用时刻必有至少一个后继光子，标准 JC 模型中的 |e,0⟩ 分量与 A 不兼容。即使非共振失谐使完全交换不发生，也不能从“某些参数下留有光子”推出“任何材料、任何事件中光子永不消失”。

更严格地，单模真空并不等于整个电磁场的全模式真空。方向 A 若提出后继光子进入其他模式或极低能模式，就必须明确其状态、能量动量、产生幅度以及与标准自发辐射或散射的区别。

## 3. 一个不成立的简单修补

“强制保留非零 P(|g,1⟩)”只能人为禁止完全激发；这不是一个推导出来的微观相互作用机制。若只令 g→0，原子不再吸收，无法解释已经观测到的吸收过程。若仅令 Δ≠0，某些失谐下光子存留概率大于零，但无法建立普适永存性。

## 4. 方向 A 的下一项理论任务

明确包含所有相关光场模式的希尔伯特空间，尝试定义满足规范不变性和概率守恒的相互作用，使所有允许的末态都包含至少一个具有正能量的后继光子。必须与真实光电吸收、原子激发和辐射截面相容，并提出可测的区别。由于光子不可区分，“同一光子”若仅为不可观测标签，则不能作为实验上独立可检验的断言。

## 5. 代码及局限

- models/jaynes_cummings.py：精确解析公式，单位 ℏ=1。
- tests/test_jaynes_cummings.py：检查概率归一化、共振完全交换、复现、失谐与边界。
- 此模型不描述铝晶格、开放系统耗散、光电电离、所有光场模式或探测器；不能据此对真实实验作数值断言。
