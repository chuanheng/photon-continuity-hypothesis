# v0.98：HOM 联合校准的样本成本与估计误差

**科学定位：** 全部为合成光学数据。该研究没有使用真实的光子实验，也不证明“历史个体光子永久存在”。这一 GitHub 报告是本地完整 ZIP 报告的摘要。

## 研究目标

v0.97 检查过三类校准错设：真实三光子 \((2,1)\) 有30%误报为 \((1,1)\)、相位传感器读出高斯标准差0.15、线上电子触发误差在旧参考中产生 \(q_{\mathrm{ref}}=q-0.004\)。光学参数仍为固有HOM模式重叠 \(M_0=0.72\)、三光子污染 \(f=0.065\)、线上触发双击概率 \(q=0.014\)。

如果只采集近远HOM两种计数，不可能同时识别全部混淆与背景参数。必须从主要实验之外增加可信参考：
1. 人工制备已知 \((1,1)\) 和 \((2,1)\) 类别各 \(n\) 个参考光子事件，估计五分类PNR矩阵的第0与第4行。其余三行在本轮先假设已知正确。随后利用 \(C^\mathsf T x=r\) 反演源类别占比；响应矩阵病态或出现负类别计数时不静默裁剪。
2. 已知零相位的外部参考 \(n\) 次估计读出偏置，实验每个40时间块重复 \(k\) 次读数。先减偏置再取时间块均值；**没有**完整地反卷积 \(\exp(-|u|)\) 的非线性噪声。
3. 每轮再加 \(10n\) 次与线上电子触发**真正匹配**但不含被测光子的独立参考，估计线上 \(q\)，而非继续依赖错设的离线电子参考。

上述已知真实标签、相位标准与电子条件匹配，均属强实验假设，不能单从HOM数据中得到。

## 300组配对模拟，实际执行结果

对于每个主实验种子，分别用三档校准预算重新采集外部参考；主光学计数及真实相位路径保持一致。数据全部合成。

| PNR每个类别参考数n | 额外参考次数13n | 每块相位重复k | 修正后M0均值 | 修正后偏差 | 修正后RMSE |
|---:|---:|---:|---:|---:|---:|
|100|1,300|1|0.737496|+0.017496|0.034274|
|1,000|13,000|2|0.729776|+0.009776|0.027264|
|10,000|130,000|20|0.722261|+0.002261|0.022658|

对照组不修正标定，300组配对样本中M0估计均值0.757653、偏差+0.037653、RMSE0.046791。**额外参考次数13n不含每次实验40k次相位重复测量，实际物理成本更高。**

三档数据各有300/300有效反演，没有发现数值奇异或负类别数量。这只说明本次参数设定稳定，不构成任何条件下都可逆的普适结论。

## 不得夸大的统计结论

本轮只计算点估计的偏差、RMSE、样本标准差，**没有**运行完整传播所有标定不确定性的联合Bootstrap，也没有验证“95%置信区间覆盖率已恢复”。要进行区间估计，必须同时模拟未知PNR响应矩阵、相位零点与噪声、电子匹配参考、主光学计数及潜在相位轨迹的估计误差。误用条件化在已知标定值上的Bootstrap将低估误差。

这项合成审计说明增加外部控制可在所设模型中减轻偏差；没有提供一个区别于普通量子光学/环境记忆的永久光子个体身份观测量。

下一步 v0.99：开发联合分层似然或覆盖率校准，考虑外部参考也有未知系统偏差，比较校准成本与有效信息量。
