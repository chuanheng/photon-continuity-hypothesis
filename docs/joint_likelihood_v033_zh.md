# v0.33：联合观测分布与似然比检验

**方向 A：原始光子永久存在，仍为未经验证的假说。**

## 研究目的
从 v0.32 的运动学允许性推进到可证伪的统计比较。H0 是标准 QED 的辐射电离预测；H1 是方向 A 额外指定了后继光子能谱、角分布和相互作用后的候选模型。当前没有计算真实 QED 振幅，也没有实验数据，因此本轮代码仅为通用统计框架。

## 观测量
可考虑 x=(电子能量、电子方向、额外光子能量、光子方向、质子反冲动量)。把联合分布离散成有限个区间，H0/H1 分别给出各区间概率 p0_i、p1_i。

真实探测器通过响应矩阵 R_ij 产生观测概率 q_i=Σ_j R_ij p_j。响应矩阵每一列求和为 1；漏检必须显式作为一个观测区间，否则需要重新考虑条件抽样和探测效率。

## 似然比
对互斥区间中的事件计数 n_i：
log Λ=Σ_i n_i log(q1_i/q0_i)。
结果为正仅表示在给定模型中数据更偏向 H1；不能直接解释为统计显著性。若两个假设都认为某个已观测区间不可能，程序报错。

D_KL(q1||q0)=Σ_i q1_i log(q1_i/q0_i)，其意义是在 H1 为真且独立同分布的条件下，每个事件的平均 log Λ。不能仅据此确定发现阈值、检验功效或样本量。

## 限制
- 不存在已输入的标准 QED 精确联合分布；任何任意指定的 p0/p1 都只能演示方法。
- 未考虑系统误差、背景、参数拟合、复合假设、事件选择偏差或试验次数效应。
- 观测到额外辐射光子不等于识别到原始光子身份。
- 若 H1 与 H0 的全部可观测分布相同，实验无法区分，KL 散度为零。
