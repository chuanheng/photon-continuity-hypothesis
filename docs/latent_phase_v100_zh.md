# v1.00：潜在环境相位高斯平滑与 HOM 似然的边缘化

**科学地位：** 普通量子光学的统计建模与合成数据，不是新 QED 预言，也未证明光子的永久历史个体身份。此为 Github 对应研究报告；真正执行的 27 项本地测试及全量结果在独立 ZIP。

## 1. 从 plug-in 状态估计到真实潜在状态积分

在 \(T=40\) 个时间块中，取 \(u_0=0\) 为已知，过程为
\[
u_t=u_{t-1}+\epsilon_t,\quad \epsilon_t\sim N(0,0.095^2).
\]
传感器每块重复 \(r\) 次：
\[
y_{tj}=u_t+b+\nu_{tj},\qquad b=0\ {\rm(已知)},\quad \nu_{tj}\sim N(0,0.15^2).
\]
这是一种**已知先验与传感器噪声参数的线性高斯状态空间模型**。全部相位路径的后验是精确多元正态。在 \(u_0=0\) 的边界下，非零路径的精度矩阵
\[
Q=D^{\mathsf T}D/\sigma_w^2+(r/\sigma_r^2)I
\]
是正定三对角矩阵。通过 Cholesky 分解求出后验均值与协方差，再抽样完整相位路径。该批量计算与线性高斯 Rauch–Tung–Striebel 平滑等价。

## 2. 保留 v0.96 三玻色子物理

在源污染、探测器损耗/暗计数、触发相关电子噪声和三玻色子 Fock 输出均**已精确标定**的条件下，使用前序物理模型计算得到：
\[
P_{\rm near}=c_0-c_1 M_0A(u),\qquad
A(u)=\frac1{40}\sum_te^{-|u_t|},
\]
其中 \(c_0=0.25303880423854,\quad c_1=0.20663755026313\)。近延迟光学实验每次25,000门控曝光；远延迟概率在此条件下与 \(M_0\) 无关，因此对已知 nuisance 参数不额外提供信息。设置 \(M_0\) 的先验为 Uniform(0,1)，在400余个规则网格点上用700条后验潜在路径近似积分：
\[
p(M_0|k,y)\propto\mathbf1_{(0,1)}(M_0)
\mathbb E_{u|y}\{\operatorname{Binom}[k\mid25,000,c_0-c_1M_0A(u)]\}.
\]
对照法则把平滑后验的均值路径 \(m_t\) 当成确切真实路径，即用单个 \(A(m)\) 计算同一光学似然。

这些区间是**贝叶斯等尾95%可信区间**。下文的“覆盖”是将其在固定合成真值下反复模拟的频率学经验覆盖率；不是对任意物理设备作出的置信保证。

## 3. 已实际运行的本地结果

本地 27/27 项 Python 单元测试通过，包括三对角精度矩阵正定性、后验抽样协方差、物理光学响应对照、概率归一、数值确定性与区间对比。

每档100个独立实验，三档共300组；每组700条相位后验路径。真值 \(M_0=0.72\)。

| 1 | 79/100 | **99/100** | .714234 | .719272 | .022481 | .021338 | .056967 / .080052 |

贝叶斯区间的经验覆盖率也有有限 Monte Carlo 不确定性。上面潜在边缘化的 99/100、94/100、97/100 对应的精确二项95%区间分别为 [94.55%,99.97%]、[87.40%,97.77%]、[91.48%,99.38%]。这些结果与名义95%相容，不能声称任意样本尺寸下完全准确。

## 4. 为什么这种改进不能直接与 v0.99 公平对比？

v0.99 的核心问题是**源类别、PNR响应、探测效率、相位传感器、电子学背景等都需要估计**。v1.00为了隔离潜在相位处理，把其他校准参数连同过程噪声标准差与相位读数误差标准差均视为**已知**。因此 v1.00 改进的是一个较窄的子问题：潜在环境状态的不确定性如何进入HOM似然，而非完整解决v0.99的联合校准问题。

其他边界包括：已知初始相位0、理想高斯随机游走、没有失效读数或异常跳变、Uniform(0,1)先验、有限后验路径蒙特卡洛积分和离散网格。无真实实验；无永久光子历史身份的独立可测信号。
