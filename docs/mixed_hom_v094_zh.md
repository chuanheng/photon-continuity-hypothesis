# v0.94：混合态 HOM、阈值探测器和独立校准下的可辨识性

**科学地位：** 本文是标准量子光学基础上的合成数据/统计模型研究，不是光子永久身份的独立证据；不是实际实验。完整原始代码、详细报告、两张 PNG、52 项已运行单元测试以及 14,400 次内层 bootstrap 的模拟结果保存在本轮本地 ZIP。

## 一、混合态光子干涉

对于独立的单光子输入态 \(\rho_1\otimes\rho_2\)，理想 50:50 分束器的双端口符合概率

\[
P_{\rm HOM}=\frac{1-\operatorname{Tr}(\rho_1\rho_2)}2.
\]

若两个源是相同的混合态，重叠等于纯度 \(\operatorname{Tr}(\rho^2)\)；对于不同源，只能称为它们的相互态重叠，不能当成其中一个源的纯度。真实内部偏振和时频自由度均可改变该值。

## 二、仪器前向模型

每门阈值探测器接到 n 个光子后，其点击概率为

\[
q_j(n)=1-(1-d_j)(1-\eta_j)^n,
\]

其中 \(\eta_j\) 为效率、\(d_j\) 为独立暗点击概率。输出两端口的双点击概率为 \(C_{nm}=q_A(n)q_B(m)\)。

输入 \((1,1)\) 两光子在 50:50 分束器上分离的概率为 \((1-M)/2\)，两光子一起从某端口输出的概率合计为 \((1+M)/2\)。因此

\[
R_{11}(M)=\frac{1-M}{2}C_{11}+
\frac{1+M}{4}(C_{20}+C_{02}).
\]

另两类双光子输入 \((2,0),(0,2)\) 各自的输出分离概率为 \(1/2\)，其双点击概率均为

\[
R_{20}=R_{02}=\frac12C_{11}+\frac14(C_{20}+C_{02}).
\]

真空双点击为 \(R_{00}=d_Ad_B\)。四类事件总概率：
\[
P_{\rm click}(M)=w_{11}R_{11}(M)+w_{20}R_{20}
+w_{02}R_{02}+w_{00}R_{00}.
\]
这些是 **0/1/2 光子类别、独立点击噪声和理想 50:50 分束器**的明确假设；没有建模死时间、探测串扰、非平稳噪声、三光子及以上污染和频率相关效率。

## 三、实际模拟参数与结果

设 \(M=.72\)，\(\eta_A=.74,\eta_B=.68\)，暗点击 \(d_A=.002,d_B=.003\)，\((w_{11},w_{20},w_{02},w_{00})=(.90,.04,.04,.02)\)。

- 模型近零延迟概率：**0.0855775488**。
- 模型远延迟概率：**0.2482151125**。
- 单次数据模拟：近远条件各 80,000 时间门、暗帧各 10,000、独立单光子效率试验各 10,000、源类别标定 20,000。
- 重叠估计 **0.7239956322**；独立源类别标定 \(w_{11}=.8994\)，由远延迟推断 \(w_{11}=.92626\)，二者存在有限抽样不一致。
- 如果无条件将原始观测代入理想 \(1-2P_{\rm click}\)，得到 **0.829275**，对真实 \(M=.72\) 有明显偏差。
- 一组真实模拟中的 500 次完整再校准 Bootstrap 百分位 95% CI：**[0.714096,0.733751]**，覆盖真值。

**覆盖率实验：** 对 120 组独立数据、每组 120 次 Bootstrap，再生成独立源类别、效率、暗计数标定资料并重新拟合，114 组区间覆盖 \(M=.72\)，经验覆盖 **95%**。该覆盖率本身的精确二项 95% 区间约 **[89.43%,98.14%]**；仅适用于完全正确指定的模拟生成机制，不能推断实际设备满足此覆盖。

## 四、可辨识性

如果只测一个近零延迟符合概率，而 \(M,w_{11}\) 都自由，Jacobian 是 1×2，秩至多1。增加远延迟测量后，由于 \(P_{\rm far}\) 只依赖 \(w_{11}\)、不依赖 \(M\)，在其余 nuisance 已校准时局部秩恢复为2。

当前模型还要求**独立且理想的光子数分辨源类别标定**；普通阈值探测器并不天然提供此信息。这是重要而非琐碎的实验限制。仅靠当前有限模型恢复秩，也不等于已排除真实环境中未建模的事件和仪器偏差。

## 五、历史光子身份仍然不可辨识

如果假想的历史身份可见度因素 \(q_{\rm id}\) 只使 HOM 有效重叠从 \(M_{\rm mode}\) 变为 \(M=q_{\rm id}M_{\rm mode}\)，那么任何这样的 \(M\in[0,1]\)，都可由普通混合单光子态

\[
\rho_1=|0\rangle\langle0|,\qquad \rho_2=\operatorname{diag}(M,1-M)
\]

得到 \(\operatorname{Tr}(\rho_1\rho_2)=M\)。故“额外身份效应”与普通模式不纯仍发生**精确操作性混淆**。这不排除真实可测光子内部态的存在，只排除仅靠该一个总重叠参数就声称证明永久历史身份。
