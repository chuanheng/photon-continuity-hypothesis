# v0.34：蒙特卡洛检验功效与探测器响应

**方向 A：原始光子永远存在，仍未经证实。本轮所有输入分布均为人为设定的统计示例，不是 QED 或方向 A 的微观预测。**

## 1. 假设与检验
固定简单假设 H0=(0.70,0.20,0.10)，H1=(0.60,0.25,0.15)，对每组 N 个独立事件计算 logΛ=Σ n_i log(p1_i/p0_i)。通过 H0 下 2000 次模拟校准单侧拒绝阈值（α=0.05），用独立 H1 下 2000 次模拟估计功效。随机种子固定为 2026，采用严格大于临界值以保守处理离散并列分数。

## 2. 探测器误分类
采用 R=[[0.8,0.1,0.1],[0.1,0.8,0.1],[0.1,0.1,0.8]]；每列对应真实区间，每行对应观测区间。若存在漏检，必须添加明确的“未检出”观测区间；否则只能理解为给定已记录事件的条件分布。

## 3. 实际模拟结果
| 有效事件数 | 理想探测器功效 | 误分类探测器功效 |
|---:|---:|---:|
| 30 | 30.45% | 未计算 |
| 100 | 71.00% | 40.60% |
| 300 | 98.10% | 81.35% |
| 1000 | 100.00% | 99.95% |

这些数字来自固定假设、有限重复次数的模拟；有蒙特卡洛误差，不能外推为真实实验样本量。真实显著性阈值、系统误差、背景、模型参数估计和多重检验尚未处理。

## 4. 研究结论
统计学能说明给定两个不同分布后需要多少数据，但不能凭空给出方向 A 与标准 QED 的差异。若所有可观测分布相同，则不可能从实验中识别“原始光子身份”。研究的首要物理缺口仍是方向 A 的独立微观相互作用与可证伪预测。
