# v0.19：真实光电电离中的零光子末态与后继光子阈值

**方向 A 保持不变：每个原始光子永远存在。这仍是待验证假说，不是已证实结论。**

## 1. 两个竞争末态

标准电离：γ(E)+A(M)→A⁺+e⁻。

方向 A 候选：γ(E)+A(M)→γ'(ε)+A⁺+e⁻，其中 ε>0。

两种过程的末态粒子数不同，不能因为第二个末态在运动学上可行，就断言第一个末态的跃迁振幅为零。标准 QED 允许电离吸收；带额外出射光子的辐射电离也可能作为不同阶次过程存在，不能自动当作新物理。

## 2. 相对论阈值

取 c=1，初始原子静止质量能量 M，离子和电子静止质量能量之和 W=M+I，I>0 为电离能。初态总四动量 P=(M+E,E n)。

对零光子末态，最终电子+离子系统的不变量至少为 W²。因此

M²+2ME≥W²，

即标准阈值

**E_th=(W²−M²)/(2M)=I+I²/(2M)。**

对指定能量 ε>0 的无质量出射后继 k'，要求 (P−k')²≥W²。展开得

M²+2M(E−ε)−2Eε(1−cosθ)≥W²。

最有利的角度为 θ=0，因此该指定 ε 的全局最低入射能量为

**E_th(ε)=E_th+ε。**

严格正能量后继要求 E>E_th；对于给定 ε>0，E≥E_th+ε。在阈值处电子和离子具有共同速度，达到最小不变量 W。

## 3. 判别力

若方向 A 允许 ε→0⁺，则其电离阈值的**下确界**与标准零光子末态一致。仅靠阈值位置无法保证区分两种理论。应进一步给出 ε 的分布、电子动能与离子反冲的联合谱，以及后继探测或缺失能量的可检验预测。

## 4. 局限与不可替代的动力学

本轮仅计算能量动量许可条件，不计算光电电离截面、矩阵元、红外软光子发射或任何真实材料实验。所谓“后继就是同一个原始光子”尚无可操作的身份判据。

尤其要注意：标准 QED 中存在软光子辐射和包容性观测量。发现极低能出射辐射并不足以区分方向 A 与标准理论；必须提供额外且可检验的差异。

## 5. 数值与测试

`models/photoionization_threshold.py` 使用因式分解计算阈值，避免大静止质量能量平方相减造成数值精度损失。示例参数是数学示例，不是对真实元素的精确质量表拟合。

`tests/test_photoionization_threshold.py` 包含 10 项测试。本轮在本地使用 `python -m unittest discover -s tests -v` 实际运行：10 项通过、0 项失败。未运行仓库其他版本的全量测试。
