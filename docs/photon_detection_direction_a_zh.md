# v0.24：光子探测效率、暗计数与二阶关联

**方向 A：原始光子永远存在。此公设尚未得到实验验证。**

## 1. 单次发射和有限探测效率

假设初始激发态原子无外驱动，理想首次发射时间服从指数分布，速率 Γ≥0。每个发射光子以独立概率 η∈[0,1] 被探测到，忽略重复激发、探测死时间、后脉冲和其他噪声。

截至 t≥0，真实信号点击概率为

P_signal(t)=η[1−exp(−Γt)]。

未探测到真实信号的概率为 1−P_signal(t)。即使 t→∞ 且 Γ>0，漏检概率也可以达到 1−η。

## 2. 暗计数

令独立暗计数为速率 d≥0 的泊松过程。区间 [0,t] 没有任何点击的概率：

P_0(t)=exp(−dt){1−η[1−exp(−Γt)]}。

至少一次点击的概率为 1−P_0(t)。该模型的首次真实信号点击概率密度为 ηΓexp(−Γt)，积分为 η（当 Γ>0）。

注意：当 d>0 且 t→∞，最终暗计数点击概率趋近于 1，不能把“任意点击”当作“真实发射已被探测”。

## 3. 二阶关联与反聚束

对于单模光场，零延迟正规序二阶关联为

g²(0)=⟨n(n−1)⟩/⟨n⟩²。

确定光子数 n>0 的 Fock 态满足 g²(0)=(n−1)/n，因此单光子态为 0，双光子态为 1/2。理想非真空相干态为 1，单模热态为 2。这个数值检验光场的计数统计，不是原始光子个体身份的观测量。

**限制：** 本轮仅实现固定光子数态的 g²(0) 公式，没有模拟真实连续驱动发射源的时间延迟关联 g²(τ)，也未建模探测器时间抖动、暗计数对 g² 的影响。

## 4. 对方向 A 的可证伪性要求

- 漏检可由 η<1 解释，不是隐藏后继光子的证据。
- 额外点击可能来自暗计数或标准 QED 辐射，不自动证明原始身份。
- 反聚束表征光场统计，不提供永久光子序列号。
- 若方向 A 预测额外后继辐射，应给出其能量、角度、时延和耦合，并与标准量子光学在同样探测效率及噪声条件下比较。
