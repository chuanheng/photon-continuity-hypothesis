# v0.21：光子的不可区分性与原始身份连续性

**方向 A：每个原始光子永久存在。仍属待验证公设。**

## 1. 光子态与身份标签不是一回事

标准玻色子 Fock 空间中，两个模式 a,b 的态 |1_a,1_b⟩=a†b†|0⟩。玻色产生算符交换，因此 a†b†|0⟩=b†a†|0⟩。交换虚构的粒子序列号不会生成新的物理态。

模式标签、可分辨的频率/偏振/空间波包，与所谓永久的逐粒子身份标签是不同概念。光子数守恒也不等于身份连续性。

## 2. 理想 HOM 模型

理想 50:50 分束器，两个输入端各有一个纯单光子，内部态分别为 |ψ_a⟩、|ψ_b⟩。若探测器不区分内部模式，且无损耗、无多光子污染，则两输出端符合计数概率

P_coin=(1−|⟨ψ_a|ψ_b⟩|²)/2。

定义模式重叠 S=|⟨ψ_a|ψ_b⟩|²∈[0,1]。S=1 时 P_coin=0；S=0 时 P_coin=1/2。聚束概率 P_bunch=1−P_coin。

示意性高斯时间模式采用 S(τ)=exp[−(τ/τ_c)²]，因此 P_coin(τ)=[1−exp(−(τ/τ_c)²)]/2。τ_c 是模型参数，具体波包定义可能采用不同宽度约定。

## 3. 对方向 A 的检验意义

HOM 实验检验的是两个光子的模式不可区分性和量子干涉，并不直接测量“同一原始光子是否一直存在”。如果方向 A 引入不可观测的永久身份标签而不改变任何测量统计，它可能只是一种解释，尚不是有独立预测的新理论。

若身份标签成为可被环境或探测器读取的 which-photon 信息，则通常降低模式不可区分性，可能改变 HOM 干涉可见度；必须给出明确的耦合与预测，不能直接声称所有隐藏标签必然降低干涉。

## 4. 研究局限

- 本模型使用标准量子光学公式，未推导新的光子动力学或原始身份算符。
- HOM 中的光子来自两个输入模式，不是在真实光电电离中追踪原始光子。
- 标准 QED 的相同粒子不可区分性不构成对所有可能隐藏变量理论的普遍不可能性定理。
- 下一步需要构造一个有操作性定义的身份连续性观测量，或证明方向 A 与 QED 对所有相关实验具有相同预测，并明确其解释性地位。
