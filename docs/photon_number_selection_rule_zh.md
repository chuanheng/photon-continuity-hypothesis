# v0.12 方向 A：光子数守恒选择定则的严格检验

**研究定位：坚持原始光子永久存在作为待检验公设；本阶段检验一种可能机制，不宣称其已被发现。**

## 1. 三态模型的守恒条件

取基底 |1⟩=|g,1_H,0_L⟩、|2⟩=|e,0_H,1_L⟩、|3⟩=|e,0_H,0_L⟩。设

H=[[E1,κ,a],[κ*,E2,b],[a*,b*,E3]]，Nγ=diag(1,1,0)。

矩阵元满足 [H,Nγ]ij=Hij(nj−ni)。因此 [H,Nγ]=0 当且仅当 a=b=0（假设 H 厄米）。此时光子数为 1 的子空间不与光子数为 0 的子空间混合。

**数学结果：** 初态位于 Nγ=1 子空间，若 [H,Nγ]=0，则所有时间的零光子态概率为零。该结论是给定哈密顿量的条件命题，不证明自然界中 [H,Nγ]=0。

## 2. 这条守恒定律与标准电磁相互作用的冲突

标准 Jaynes–Cummings 相互作用 H_int=ℏg(a σ_+ + a† σ_−) 不与光子数 Nγ=a†a 对易；却与总激发数 C=Nγ+σ_+σ_− 对易。它允许 |g,1⟩ ↔ |e,0⟩，即光子数由 1 变成 0。

更一般地，量子电动力学的相互作用允许光子产生和湮灭；光子数不是普遍的基本守恒荷。若方向 A 要求任何相互作用都守恒光子数，必须修改与光电吸收、探测、辐射过程相符的标准动力学。

## 3. 光子数守恒仍不足以证明“原始光子身份”

[H,Nγ]=0 只约束光子总数，不定义哪一个是“原始光子”。例如两个入射光子散射后，光子数不变，并不为不可区分的量子激发提供独立身份标签。

而且方向 A 要求的是**每一个原始光子**永久存在，强于“系统始终至少有一个光子”。对多光子态，单纯守恒总光子数并不蕴含可追踪的逐粒子身份。

## 4. 不能用普通的 U(1) 电荷守恒直接证明

电子电荷守恒源于规范对称性；光子不携带电荷。不能将电荷守恒直接套用于光子数守恒。若提出新的全局 U(1) 光子数荷，必须明确它对场的作用、与规范不变性及局域相互作用的兼容性，并给出实验后果；仅命名新守恒量不等于建立理论。

## 5. 强约束下的可证伪性

假设在真实物质中所有零光子末态都被禁止，则必须重算光电吸收截面、电子能谱、原子激发概率和低能出射辐射。若标准光电吸收的零光子末态仍被实验支持，则此版本方向 A 与实验冲突；不能通过定义“完全不可观测的剩余光子”消除可证伪性。

## 6. 本轮结论

- **已证明的条件数学结论：** 三态哈密顿量中 a=b=0 等价于光子数守恒。
- **尚未证明：** 这种守恒律适用于自然界中的所有光子—物质相互作用。
- **尚未解决：** 单个原始光子的身份定义、完全吸收实验的兼容性、规范一致的微观模型。
- **下一步：** 检查新增光子数 U(1) 对称性与最小电磁耦合的兼容性，并区分“光子数守恒”和“逐光子身份守恒”。
