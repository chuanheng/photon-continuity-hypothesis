# v0.8：光子身份、量子不可区分性与可观测关联

**研究状态：理论梳理与可复现的教学代码；无支持光子连续存在假说的新实验结果。**

## 1. 光子身份不是经典编号

量子场论中的光子是电磁场的量子激发。相同量子态的光子不可区分。“入射的这个光子是否还是出射的同一个”并非通常定义的量子可观测量。可计算和测量的是散射振幅、光子数、能量、动量、偏振、相位与关联。

特定单光子输入和输出的量子通道可测量保真度、透射概率及条件关联；这些是量子态或信息传递指标，不证明粒子的永久身份。

## 2. 二阶关联

单模光子数分布 P(n) 的零延迟二阶关联为

g²(0)=⟨n(n−1)⟩/⟨n⟩²。

数态 |n⟩ 的结果是 1−1/n (n≥1)；真空态 ⟨n⟩=0 时归一化 g² 不定义。理想单光子态 g²(0)=0；相干态为 1；单模热态为 2。这些是标准量子光学性质，不是光子永生的证据。

## 3. 跨通道条件关联

针对输入触发 H、材料激发 X、出射辐射 Y，比较 P(Y|H,X)、P(E_out|H,X)、时间延迟和角分布，并设置没有材料激发的控制组。须校正探测效率、暗计数、荧光、散射、辐射修正和探测器死时间。

本仓库 cross_covariance 函数只演示二元点击协方差，并非真实实验模型。

## 4. 可证伪的命题

H0：标准量子电动力学和材料响应给出的联合分布 P0(Y,X|H)。

H1：在预先指定的能量、角度和时间窗口中，出现由明确微观理论计算出的额外联合分布分量。

**必须存在一个 H0 无法通过已知背景与系统误差同样解释的可观测差异。** 如果只是宣称所有光子仍存在但永不可探测，而不改变任何可观测概率，则目前无法设计区分实验。

## 5. 研究路线

1. 指定光电吸收或非弹性散射后的新末态。
2. 提出符合四动量守恒、规范不变性和概率归一化的相互作用模型或 S 矩阵修正。
3. 推导联合概率分布，明确标准辐射背景。
4. 预注册效应大小、误差与否定标准。
5. 仅在合适的授权实验室开展辐射实验。
