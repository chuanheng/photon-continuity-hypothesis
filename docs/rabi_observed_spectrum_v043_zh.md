# v0.43：从 Rabi 跃迁强度到可观测吸收光谱

**研究状态：方向 A“原始光子永远存在”尚未获得独立实验证据。**

## 方法
以标准 Rabi 模型 H=ωa†a+(ω0/2)σz+g(a+a†)σx（ℏ=1）数值对角化，计算 S_ij=|⟨E_j|a+a†|E_i⟩|²。只取 E_j>E_i 的吸收跃迁，初态热布居 p_i∝exp(−E_i/T)，零温时取最低能级。跃迁权重 W_ij=p_i S_ij。

洛伦兹线型 L(x;x0,γ)=γ/[π((x−x0)²+γ²)]。仪器高斯响应 G(x;σ)=exp(−x²/(2σ²))/(σ√(2π))。观测吸收谱为 A_obs(x)=Σ_ij W_ij (L*G)(x;E_j−E_i)，即 Voigt 线型；通过 Gauss-Hermite 求积近似计算。γ>0，σ≥0。

## 可检验性
H0 为标准 Rabi 光谱。H1 如果仅添加完全不可观测、完全解耦的永久身份标签，则与 H0 给出相同光谱；无法凭实验光谱区分。若 H1 提出额外耦合，必须具体给出哈密顿量、能量预算、选择定则和参数，不能任意添加“新谱峰”作为证据。

## 局限
本模型是弱探针、现象学线宽的吸收谱 toy model，不是 Lindblad 主方程或完整 Kubo 响应；不包含饱和、相干驱动、详细平衡的净吸收修正、探测器计数统计及系统误差。有限 Fock 截断与数值求积需要收敛性检查。谱线位置及权重可随模型参数改变，但这不等于发现新物理。
