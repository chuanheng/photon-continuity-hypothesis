# v0.40：量子 Rabi 模型中的总激发数与宇称守恒

**研究状态：方向 A“原始光子永远存在”仍未经证实。**

## 1. 研究问题
前几轮研究 Jaynes–Cummings (JC) 模型的激发数守恒。本轮加入反旋波项，研究更一般的量子 Rabi 模型能否保留所谓的“身份数”。

## 2. 哈密顿量与守恒量
取 ℏ=1，原子基态满足 σz|g⟩=−|g⟩，激发态满足 σz|e⟩=+|e⟩：

H=ωa†a+(ω0/2)σz+g(a+a†)σx。

总激发数 N=a†a+σ+σ−。展开相互作用后，反旋波项为 g(aσ−+a†σ+)。因此

[H,N]=2g(aσ−−a†σ+) ≠0（一般 g≠0）。

定义宇称 Π=σz(−1)^(a†a)，则 Π²=I 且 [H,Π]=0。宇称为 ±1，描述离散 Z₂ 对称性，不是“原始光子个体数”。

例如 |g,1⟩、|e,0⟩、|g,3⟩、|e,2⟩ 都有 Π=+1；其激发数并不相同。反旋波跃迁 |g,0⟩↔|e,1⟩ 的激发数由 0 变成 2，但宇称均为 −1。

## 4. 理论边界
1. Rabi 模型是标准量子光学中的模型，不是新提出的光子连续存在理论。
2. Z₂ 宇称不能记录单个光子的永久身份；它仅把态空间分成两个对称性扇区。
3. 有限 Fock 截断会改变高激发态能谱和动力学；对易关系不受影响不代表所有截断结果都精确。
4. 本轮不涉及完整 QED、探测器测量、开放系统或光子个体的实验可追踪性。
5. 即使量子态在同一宇称扇区内连续演化，也不能据此认定原始光子始终存在。
