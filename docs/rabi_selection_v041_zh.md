# v0.41：量子 Rabi 模型中的宇称选择定则

**状态：方向 A“原始光子永远存在”仍未经验证。本轮所有结论均属于标准量子理论。**

## 1. 对称性与跃迁算符

Rabi 哈密顿量 H=ωa†a+(ω0/2)σz+g(a+a†)σx，宇称 Π=σz(−1)^(a†a)，满足 [H,Π]=0。

对于宇称本征态 Π|i⟩=p_i|i⟩、Π|f⟩=p_f|f⟩，若 ΠOΠ=s_O O，则

⟨f|O|i⟩=s_O p_f p_i ⟨f|O|i⟩。

非零矩阵元的必要条件为 p_f=s_O p_i。宇称偶算符连接相同宇称，宇称奇算符连接相反宇称。“允许”只是必要条件，不保证矩阵元非零。

## 2. 算符分类

光场正交分量 X=a+a† 和原子 σx 为宇称奇；光子数 n=a†a、σz 和 I 为宇称偶。自然时间演化 U=exp(−iHt) 保持宇称扇区；外加宇称奇驱动可以连接相反宇称扇区，并不矛盾。

原子基态 σz|g⟩=−|g⟩。|g,1⟩、|e,0⟩ 均为 +1 宇称；|g,0⟩、|e,1⟩ 均为 −1 宇称。反旋波耦合 ⟨e,1|H_int|g,0⟩=g 非零，但总激发数由 0 变成 2。另一方面，⟨e,0|X|g,1⟩=0，是因为 X 不翻转原子态，并非宇称禁戒。

## 3. 模型与测试

models/rabi_selection.py：裸态宇称、算符宇称、必要选择定则、裸态矩阵元和 Rabi 相互作用矩阵元。

tests/test_rabi_selection.py：35 项 unittest，本地实际执行全部通过（0.001 秒）；未运行全仓库测试。

本轮仅处理裸态基底和对称性规则，未对 Rabi 完整本征态进行数值对角化，也没有引入探测器噪声、耗散或完整 QED。

## 4. 物理意义

宇称选择定则不能证明原始光子永久存在。即使跃迁被禁止，也不能推断光子穿过物质或以不可观测形式存续。提出区别于标准 QED 的身份理论，仍须给出新动力学、守恒量及可测预测。
