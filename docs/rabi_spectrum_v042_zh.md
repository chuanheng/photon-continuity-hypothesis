# v0.42：Rabi 能量本征态中的宇称分辨跃迁谱

**研究状态：方向 A“原始光子永远存在”仍未经验证。以下为标准量子 Rabi 模型。**

## 1. 数值方法
H=ωa†a+(ω0/2)σz+g(a+a†)σx，ℏ=1，σz|g⟩=−|g⟩。保留 n=0,...,N−1 共 N 个 Fock 态，形成 2N×2N 实对称矩阵。采用 numpy.linalg.eigh 得到 E_j、|E_j⟩。

宇称 Π=σz(−1)^n，探测算符 X=a+a†。计算 p_j=⟨E_j|Π|E_j⟩，S_ij=|⟨E_j|X|E_i⟩|²。因为 ΠXΠ=−X，若 p_i=p_j=±1，则 S_ij=0。允许跃迁不保证非零强度。

## 2. 截断收敛
对多个 N 比较最低 k 个本征值，以最大截断 N_ref 作为数值参考，报告 δE_j(N)=|E_j(N)−E_j(N_ref)|。该差异只是相对于有限参考截断的误差估计，不能自动等同于无限维精确误差。靠近截断上边界的高激发态通常更不可靠。

注意简并：若不同宇称态能量完全简并，通用对角化器可能返回宇称混合的任意基；严谨计算需在简并子空间再次对角化 Π。本实现主要用于一般非简并参数，未处理此退化情况。

## 3. 代码
- models/rabi_spectrum.py：构建 H、Π、X；对角化；跃迁强度；截断误差。
- tests/test_rabi_spectrum.py：30 项测试，实际运行 30/30 通过（0.006 秒）。未执行全仓库测试。

## 4. 结论与边界
这些选择定则及谱线强度来自标准量子光学。它们不能验证原始光子的永久身份。实际光谱还取决于初态布居、驱动、耗散、线宽、温度和探测器响应，单独的矩阵元不等于实测光谱。
