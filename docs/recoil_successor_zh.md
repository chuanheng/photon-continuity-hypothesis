# v0.15 方向 A：包含原子反冲的严格相对论运动学

**研究前提：** 继续将“原始光子永远存在”作为待证公设。本文检验一个有出射光子的候选过程是否满足四动量守恒；不证明光子身份、非零散射振幅或普遍永存。

## 1. 过程与条件

γ(E)+A(M,静止)→γ(E',θ)+A*(M+U/c²)。

E、E'、U 均为能量；R=Mc² 为初始目标静止质量能量。目标最终内部激发使静止质量能量变为 R+U。取自然单位 c=1 推导。

## 2. 四动量守恒

入射总四动量 P_i=(R+E, E n_i)，出射光子 k'=(E',E' n_f)，目标末态 P_f=P_i−k'。由 P_f²=(R+U)² 得

(R+E−E')²−(E²+E'²−2EE'cosθ)=(R+U)²。

整理可得

**E'=[R(E−U)−U²/2]/[R+E(1−cosθ)]。**

在严格前向 θ=0 时，

**E'=E−U−U²/(2R)**。

正能量出射光子存在的必要条件为 **E>U+U²/(2R)**。对任意 θ∈[0,π]，分母为正，因此该条件也足以使该特定两体末态在运动学上有正能量解。原子反冲动能为 T_R=E−U−E'。

## 3. 数值示例

取 E=60 keV，U=40 keV，R=25,000,000 keV（示例值，不代表某种指定材料的实际跃迁）：

- θ=0°：E'=19.999968000 keV，T_R=0.000032000 keV（0.032 eV）。
- θ=90°：E'=19.999920000 keV，T_R=0.000080000 keV（0.080 eV）。
- θ=180°：E'≈19.999872001 keV，T_R≈0.000127999 keV（0.128 eV）。

程序对不变量残差使用因式分解，以减轻大质量尺度下浮点数相减造成的消去误差。

## 4. 不能从运动学推出什么

1. 正能量出射末态**运动学允许**，不代表其散射振幅或截面非零。
2. 该过程属于可在标准理论中讨论的非弹性散射类型，不能仅凭它宣称发现新物理。
3. 出射光子无法自动获得“与入射光子同一身份”的可观测标签。
4. 该公式不禁止光电吸收等没有出射光子的末态。
5. 不能据此推断任何光子都能穿过任何厚度、任何材料；还需动力学与探测预测。
