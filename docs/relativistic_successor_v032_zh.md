# v0.32：后继光子末态的相对论四动量守恒

**方向 A“原始光子永远存在”仍是未经验证的假说。**

## 目标
检验 γ+H(静止)→e⁻+p⁺+γ' 在给定后继光子能量和方向下是否运动学允许。此反应也可能属于标准 QED 的辐射电离通道；运动学允许不证明原始身份连续。

## 四动量与阈值
采用 c=1、能量单位 eV。令氢原子质量 M_H=m_e+m_p−I，I=13.5984345997 eV（精细电离能近似）。初始入射光子能量 E，后继光子能量 ε、夹角 θ。

电子—质子对总四动量 Q=P_initial−k'，不变质量平方

s_ep=M_H²+2M_H(E−ε)−2Eε(1−cosθ)。

自由电子—质子末态存在的条件 s_ep≥(m_e+m_p)²。给定 E,θ 后的后继光子最大能量

ε_max=[M_H²+2M_HE−(m_e+m_p)²]/[2(M_H+E(1−cosθ))]。

若 E 低于阈值 E_th=[(m_e+m_p)²−M_H²]/(2M_H)，无电离末态。

## 数值示例
E=20 eV 时：
- θ=0°，ε_max≈6.40156533 eV
- θ=90°，ε_max≈6.40156520 eV
- θ=180°，ε_max≈6.40156506 eV

ε=2 eV 在这些角度均允许；ε=7 eV 均不允许。

## 构造末态
在电子—质子质心系中构造相反的三动量，然后沿电子—质子总动量进行洛伦兹变换，检查四动量总和与各自质量壳。数值计算在阈值极近处可能受大质量平方的浮点抵消影响，测试选取远离阈值的参数。

## 科学限制
1. 本轮只证明末态相空间是否非空，不计算跃迁振幅或截面。
2. 氢原子质量由电子、质子质量与电离能近似组合；未包含精细的原子质量修正及完整辐射效应。
3. 标准 QED 同样允许带额外光子的辐射电离；不能把允许的 γ' 自动解释为“原始光子”。
4. 若方向 A 要成为可证伪的新理论，必须指定独立相互作用或与标准 QED 不同的联合可观测分布。
