## 3. 数学关键命题

### 3.1 系统可访问量的辅助空间独立性

对任何联合态 \(\rho_{SI}\)，若允许操作和测量限制为 \(\mathcal E_S\otimes \mathrm{id}_I\)、\(M_o\otimes I_I\)，则

\[
\Pr(o)=\mathrm{Tr}[(M_o\otimes I_I)(\mathcal E_S\otimes\mathrm{id}_I)(\rho_{SI})]
=\mathrm{Tr}[M_o\mathcal E_S(\mathrm{Tr}_I\rho_{SI})].
\]

此定理并不否定辅助自由度的本体论可能性；它只说明在此访问条件下无法识别它。

### 3.2 槽位编号不同于物理个体

对相同玻色子 \(\mathcal H_B^{(n)}=\mathrm{Sym}^n\mathcal H_1\)，张量因子的次序不是可测的逐粒子历史编号。若添加真实内部态 \(\mathcal K\)，也仍必须在 \(\mathrm{Sym}^n(\mathcal H_1\otimes\mathcal K)\) 中描述，并用独立动力学解释何为所谓“永久历史”。

### 3.3 精确的统计不可辨识性

若观测概率中的 test 组相位只有组合 \(b+\delta\)，普通模型允许组别偏置 \(b'\)，便可设 \(b'=b+\delta\)，使身份模型与普通模型逐项具有相同的计数期望与联合 Poisson 分布：

\[
P_{\mathrm{identity}}(Y\mid b,\delta)=P_{\mathrm{ordinary}}(Y\mid b+\delta).
\]

Fisher 信息的 \(b,\delta\) 块为 \(J\begin{pmatrix}1&1\\1&1\end{pmatrix}\)，具有零特征方向 \((1,-1)\)。更多样本、统计显著性和 Bootstrap 都不能单凭当前观测破除该精确退化。

## 4. 统计证据不能越界

v0.84 的平稳 AR(1)、随机游走与普通组间偏置模拟对应 4/120、69/120 和108/120 的零模型拒绝，后两种数据生成机制违背被检验的**受限**平稳零模型。它们说明**模型错设风险**，不是“无永久身份下的所有真实物理零假设都有 57.5% 或 90% 假阳性率”。

此外，v0.82—v0.83 的 bootstrap 曾使用惩罚化潜在态 MAP 而非完全边缘似然；v0.84 则改用从 Poisson 计数中提取相位的高斯近似 GLS。不能把不同检验方法的数值简单连成同一严格渐近证明。

## 5. 科学定位与论文路线

**建议论文标题：** *Operational Identifiability of Persistent Particle-Identity Labels: Symmetrization, Dilations, and Composite Null Models*.

合理定位为量子信息/数学物理/实验统计研究；对称化、Stinespring、Fisher 可辨识均是已知理论，不能把标准定理本身当成新的原创发现。要形成有新意的论文，需要更强联合定理、新的真实实验协议，或以前未发现的非平凡物理差异。

**明确的待证明缺口：** 尚无局域、Lorentz 协变、满足玻色统计和 QED 规范结构的持续身份动力学，且尚无标准 QED+普通环境无法复制的、可定量检验的预言。
