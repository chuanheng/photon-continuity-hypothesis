## 研究命题和出处

原始问题是入射光子与物质交换能量后是否仍保持个体身份。后续研究聚焦吸收、存储、再发射和可访问测量。应分开考察三个命题：完全沉默的本体标签；标准量子光学中的模式、物质存储与环境记忆；具有明确耦合且产生独有可观测预测的身份变量。前两个命题各有明确的操作解释，第三个仍待构造。

- 历史讨论检索覆盖了早期散射/吸收问题、项目的可辨识性边界、独立标定、反方审稿及普通环境对照。另读取了历史论文草稿与五批归档主索引。能检索到的历史摘要和文件有范围限制，旧讨论中的版本号和测试仅作线索。当前核验以 main 的报告、代码和执行结果为准。
- [项目 README](../README.md) 与 [英文预印稿](../paper/preprint.md) 保存初始假说、衰减和能动量账本。英文稿是早期版本。应优先使用 [v3.21 中文修订稿](v321_revised_manuscript_zh.md)、[v4.11 批次稿](../v402_v411/manuscript_zh.md) 和 [v4.21 批次稿](../v412_v421/manuscript_zh.md) 承接近期科学结论。
- v1.12–v3.21 各十轮有 `docs/v*_batch_index_zh.md` 及链接的报告、代码和测试。更早原始材料的归档有历史缺口，入口见 [v0.87 历史回填索引](historical_backfill_index_v087.md)。本次未逐一验证早期所有归档、附件 ZIP 和原始运行日志。历史主索引说明早期附件源码与 GitHub 整理版并非逐字节一致。
