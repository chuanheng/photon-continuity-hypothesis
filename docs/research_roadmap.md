# 下一阶段研究路线

[v5.52–v5.61](../v552_v561/README.md) 已在本地完成。下一批聚焦在明确的备择机制和普通环境模型之间设计最少而独立的操作，而后计算可复核的有限样本辨识力。

| 轮次 | 研究问题 |
|---|---|
| v5.62 | 能否以两个独立控制识别材料记忆与普通相干旁路 |
| v5.63 | 未观测的普通辅助端口对因果定位造成多大的等价范围 |
| v5.64 | 有限模式泄漏和输入可区分性怎样改变两光子联合预测 |
| v5.65 | 在相关漂移下，逐区组随机化是否保持留出检验覆盖 |
| v5.66 | 仪器和材料的联合校准需要多少种独立干预 |
| v5.67 | 按光学模式、探测器和材料分层的检验有哪些条件功效 |
| v5.68 | 未知普通模型字典可否给出可审查的全局距离下界 |
| v5.69 | 同一可见数据如何约束相互作用参数集合的大小 |
| v5.70 | 若添加可观测额外荷，有哪些能区分它与模式标签的联合预测 |
| v5.71 | 严格规定跨吸收候选构造失败或进入实验的条件 |

见 [交接](research_handover.md) 与 [状态](../research_state.json)。
