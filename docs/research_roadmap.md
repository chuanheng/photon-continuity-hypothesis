# 下一阶段研究路线

以 [交接说明](research_handover.md) 和 [机器可读状态](../research_state.json) 为起点。根据核对的 main，下一批为 **v4.22–v4.31**，首轮为 **v4.22**。本页是研究计划，以下结果均待求证。

## 主问题

在事先约定的制备、干预和读出范围内，独立校准能否约束普通环境，使显式候选产生无法重拟合的观测差异？优先检验这个差异的来源。对协议集合 `A` 和独立校准允许域 `Θ_cal`，用候选分布 `P₁ᵃ` 定义加权距离

`D* = inf_{θ∈Θ_cal} Σ_{a∈A} wₐ KL(P₁ᵃ || P₀ᵃ(θ))`，其中权重非负且和为 1。

标准模型应在不同协议之间共享物理参数，容许经标定支持的串扰、漂移和普通记忆。一次局部拟合为上界，模型族内显式重拟合可证明零距离。正距离需有可核验下界，并同时报告标定误差与标准模型族的外推边界。距离正值先解释为排除该实验定义的受限标准族。

| v4.26 | 排除有限经典 HMM 后，允许标准量子相干记忆能否再现差异？选一对非对易干预，给出物理 CPTP 或过程张量基准。 | 比较普通经典与普通量子记忆；核对 Choi 正性和因果归一。若标准量子过程有匹配解，记录反例。 |
| v4.27 | 能否给出含独立校准约束的复合零假设全局距离下界？推导线性见证或可验证区间下界。 | 在零距离重拟合正控和已知分离的合成正控上核验界；数值松弛若不能给出正下界，保留未决。 |
| v4.28 | 把参考抽样、受控词重叠、完整重拟合和协议选择放入同一检验流程，控制整个流程的误报率。 | 训练与留出分离，每次重采样重跑同一选择流程；在复合标准族多个边缘/内部点报告误报、功效及 Monte Carlo 区间。 |
| v4.29 | 在固定总曝光下，以最坏情形距离或功效优化标定、训练、留出和干预分配，推导可执行设计。 | 与均分方案和 v4.25 标定域比较；独立种子评估最坏漂移与校准误差。只推广到已测试参数域。 |
| v4.30 | 能否写出与普通介质记忆有明确区分的局域有效耦合？从光—物质模型出发逐项检查交换、规范、洛伦兹、能动量、局域与无信号条件。 | 对具体候选做有限截断矩阵计算，核查其标准内部模式或环境重表达；逐项注明有限维核查能支持的范围。候选若失败，给出失败方程及反例。 |
| v4.31 | 为通过前置检查的候选锁定干预对比、观测量及失败阈值，推导预注册的判定逻辑。 | 盲跑合成的标准环境、已知分离正控与漂移反例，核验判定规则。若没有合格耦合或正距离证书，交付有条件的负结果及合成协议，无物理发现结论。 |

批次完成后，按 [执行规范](../AGENTS.md) 交付、更新论文并核验远端。若有可行候选，后续先做理论一致性复核与独立标定验证，再决定是否形成真实实验。若模型可重拟合或候选不满足一致性，则记录排除范围、反例和重新启动该方向所需的新条件。
