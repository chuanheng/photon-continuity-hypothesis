# 下一阶段研究路线

本页以 [交接说明](research_handover.md) 和 [机器可读状态](../research_state.json) 为起点。已验证批次为 [v4.22–v4.31](../v422_v431/README.md)，下一批为 **v4.32–v4.41**。以下是待验证研究计划。

## 核心问题

v4.22 的区分来自如何重置普通持久状态。v4.30 的候选则可重拟合成普通失谐。下一批先研究能否通过独立物理校准给普通量子记忆跨越吸收、重置与再发射的传递能力设上界。任何超界差异先检验普通旁路，再考察身份特异解释。

| 轮次 | 问题与验证方向 |
|---|---|
| v4.32 | 推导对扩展环境有效的近似量子因果切断界。使用带参考系的信道距离，构造普通量子正反例并核对判据是否饱和。 |
| v4.33 | 比较只校准局域读出与加入辅助系统的完整过程校准。构造局域统计相同、重置携带能力不同的量子仪器反例。 |
| v4.34 | 使用材料与探测器独立切断的 2×2 交叉协议，推导串扰、共享参考漂移及旁路带来的交互项范围。 |
| v4.35 | 在吸收和回读之间加入显式路线交换。对普通的模态、源、失谐和材料记忆给出公平对照，并检验载体语义交换是否改变分布。 |
| v4.36 | 将有限经典可达证书与含非对角控制的有限量子过程比较，在固定有限维和可用仪器下给出可验证的相等或差异证书。 |
| v4.37 | 把校准误差从局域边缘推广到含序列相关性的最坏情况。推导有限样本覆盖并对照独立二项的失配。 |
| v4.38 | 研究具有动态同位素/谱线背景参数的普通散射或吸收再发射对照。独立观测谱时与临时只看总通量时分别作全局重拟合。 |
| v4.39 | 在玻色对称且含完整普通光—物质存储的有限模型里，寻找候选身份作用项的明确必要条件。列出可局域寻址的可观测代数与未通过条件的反例。 |
| v4.40 | 对通过必要条件的候选给出可执行读出与效应大小；若无候选，通过构造加隐环境反例，核验量子旁路是否重建全部受限实验的预测。 |
| v4.41 | 反方复核整个推断链，预先锁定实验门槛、频率误报上界与可能失败的校准。仅当有明确物理预言时形成真实光学实验的可执行方案。 |

每轮遵循 [研究执行规范](../AGENTS.md)。持续从 main 恢复工作。近期负结果的关键检查点是，校准的物理覆盖范围应先于显著性比较；光学过程数据需要同时面对普通相干环境和器件记忆。
