# 下一阶段研究路线

[v5.92–v6.01](../v592_v601/README.md) 已在本地完成。下一批将两次散射的条件角概率嵌入有限铝板的普通输运，给出能与实测曝光相比较的背景率和不确定度。

| 轮次 | 研究问题 |
|---|---|
| v6.02 | 从标准截面库核对光电、相干与非相干过程的能量依赖 |
| v6.03 | 有限铝板的首碰撞深度和无碰撞透射如何独立验证 |
| v6.04 | 中间程的边界逃逸如何改变两次散射的绝对发生率 |
| v6.05 | 二次粒子与束缚电子展宽如何影响降能窗 |
| v6.06 | 偏振与孔径调制能否约束普通两次路径的系统误差 |
| v6.07 | 按相同几何与截面比较独立标准输运器与解析近似 |
| v6.08 | 随机厚度、角窗与总曝光误差如何传播到留出预测 |
| v6.09 | 如何用独立探测器尾语料、空板和替代板锁定背景 |
| v6.10 | 原始候选能否规定独立的可观测耦合和事件角能谱 |
| v6.11 | 以冻结的普通背景率与候选的最小事件率决定实验可行性 |

见 [交接](research_handover.md) 与 [状态](../research_state.json)。
