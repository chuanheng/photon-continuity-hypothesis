# PCH-A v1.07 — 独立两光子参考标定、三光子 Gram 矩阵与可辨识性

**全为标准量子光学的合成数值研究。没有真实光子测量，也没有历史个体光子永久存在的新可检验预言。** 此 GitHub 文档是本地实际运行研究包的概要，对应完整报告和全量数据保存在 photon_v107_complete.zip。

## 实验分组及统计推断

受限输入为 |2_phi,1_psi>：两个相同内部纯模式 phi 的光子进入同一空间端口，第三个模式 psi 的光子进入另一端口；rho=|<phi|psi>|²。理想50:50分束器的输出光子数（输出A有k=0、1、2、3个）的概率为

P(k|rho)=rho(3,1,1,3)/8+(1-rho)(1,3,3,1)/8。

第二种是两个相同输入端光子与来自另一输入端、正交于它们的单光子。此插值只能用在这个**受限、两光子同模式**的输入，不是一般三光子部分可区分性公式。

v1.06把rho当oracle真值。本轮设计独立**两光子**参考：制备相同的纯模式phi、psi，以理想且已独立校准的50:50参考分束器测量两端符合次数C：

C|rho ~ Binomial(n_ref,(1-rho)/2)；rho~Uniform(0,1)。

用801点rho参考后验和151点M0网格，同v1.06中的连续传感器随机游走、24块2次相位读数、40次独立相位零点参考、源类别PNR、两探测器效率/暗计数、电子学触发背景及主实验近远双点击二项似然联合重要性采样。每个主实验近远各1500门控。**这里假设参考器件的光子模式确实等于产生三光子污染的模式，而且参考分束比、暗点击、损耗、非理想单光子事件已被完美校正。** 真实设备不能无条件满足。

设计100组主物理合成数据，固定真实M0=.72，真实rho=.10、三光子事件比例f=.14。每组重复六个推断假设，使用相同主数据及160个重要性粒子。总计600次拟合，但不是600个独立主实验：

| rho策略 | 估计M0均值 | M0 RMSE | 标称95%贝叶斯可信区间覆盖 | 平均M0区间宽 |
|---|---:|---:|---:|---:|
| 错设rho=1 | .465169 | .263952 | **4/100** | .290941 |
| 无独立参考，Uniform rho先验 | .595546 | .140690 | 89/100 | .413888 |
| 100次理想匹配参考 | .689064 | .078041 | 95/100 | .332823 |

100/1000/10000次匹配参考得到的rho后验与光学数据联合估计均值分别约.139752、.100521、.098327。Oracle是**不具备现实测量误差的极限对照**，不能写成由主实验单独识别rho。贝叶斯95%可信区间的频率学经验覆盖：4/100的精确Clopper-Pearson二项95%区间[1.10%,9.93%]；95/100[88.72%,98.36%]；96/100[90.07%,98.90%]。固定真值100组审计**不是完整先验SBC**。

## 一般三光子 Gram 矩阵反例

对三个任意归一化纯内部态分别以(a,a,b)空间分布入射，使用完全玻色对称的产生算符在输出端口 × 内部正交态Fock基底生成多模态，基于创建算符的sqrt(n+1)权重，**先规范化同输入空间端口的初态**，再在输出内部态上求迹，得到不同端口占据概率。Gram G_ij=<psi_i|psi_j>应为3x3 Hermitian正半定且G_ii=1。

取两个不同的物理有效Gram（均最小特征值>0），使三对|G_ij|²都**等于.25**，但三体循环相位 arg(G12 G23 G31)分别为0和pi/2。精确输出概率是：

- 相位0，P(k=0,1,2,3)=[.200,.300,.300,.200]；
- 相位pi/2，P(k=0,1,2,3)=[.175,.325,.325,.175]。

因此仅测三对常规两光子HOM幅度平方，仍不足以完全确定一般三光子输出。三体相位是标准多玻色子干涉的内部态不变量，**不是永久历史光子个体标识**。这与2026年已发表的Gram矩阵光子聚束实验研究一致：https://www.nature.com/articles/s41377-026-02250-4 。

## 物理/统计边界与下一步

1. 独立参考较主实验提供新增信息，缓解M0与rho的局部混淆；但即使10000次参考，M0仍有约-.0204的平均估计偏差，其他实验有限样本和模型近似仍需处理。
2. 参考光子模式须代表主污染的真实内部态，不可将不同准备路径/漂移后的rho直接移植。
3. 三对两光子幅度平方不确定完整三光子Gram相位，需真正三体可观测参考或其他可识别操作。
4. 这些计算没有提出跨吸收与再发射保持同一“原始光子”的新可测试预测。

**v1.08优先方向**：量化参考模式与主实验rho存在偏移时的系统性偏差；设计可辨识三体相位的独立实验和联合似然，再做模型外覆盖率审计。
