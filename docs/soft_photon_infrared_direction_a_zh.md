# v0.20：软光子红外问题与原始光子身份

**方向 A：每个原始光子永远存在。仍是待证假说，不能把软辐射误认为该公设的证据。**

## 1. 软辐射与独立辐射近似

在适当带电散射过程的领头对数软辐射近似下，考虑指定能量区间 ε_min<ε<ε_max 内的额外软光子。采用示意谱 dN̄=β dε/ε，其中 β≥0 是人为给定的过程依赖系数。则

N̄=β ln(ε_max/ε_min)。

进一步假设辐射计数服从独立泊松分布：

P(N=n)=exp(−N̄) N̄^n/n!。

特别地，区间内没有额外软光子的概率：

P₀=(ε_min/ε_max)^β。

在 β>0 且 ε_min→0 时，P₀→0，而区间平均软辐射能量为 β(ε_max−ε_min)，保持有限。该推导只在所声明的简化假设内成立，不是全阶 QED 结果。

## 2. 实验分辨率的重要性

真实探测器存在能量阈值 Δ。所谓“未观察到额外辐射”，指的是未分辨出高于阈值的辐射，不能直接解释为量子场严格处于零光子 Fock 态。探测器分辨率改变，实验定义的排他性概率也会改变。

在完整 QED 中，红外发散的处理涉及虚修正与实软辐射的包容性求和、适当的渐近态以及实验可分辨观测量。单独讨论无限精度的固定粒子数末态可能产生红外问题。

## 3. 与方向 A 的核心区别

- 标准 QED 允许电离等过程吸收入射光子，同时伴随零个或多个额外辐射光子（具体依赖可观测定义）。
- 方向 A 要求每个入射光子都有同一身份的正能量后继光子。
- 额外软光子是否存在，不回答“是否与入射光子为同一个粒子”。
- 对相同量子态的光子，逐粒子身份不是标准 QED 中通常可测的标签。若方向 A 不提出额外观测量，它可能与标准理论在经验上不可区分。

## 4. 示例

取 β=0.1，ε_max=1（任意一致能量单位）：

| ε_min | P₀ |
|---|---:|
| 10⁻¹ | 0.7943 |
| 10⁻² | 0.6310 |
| 10⁻³ | 0.5012 |
| 10⁻⁴ | 0.3981 |
| 10⁻⁵ | 0.3162 |
| 10⁻⁶ | 0.2512 |

数字完全来自示意模型，不是光电效应实测值或具体材料的预测。

## 5. 下一步：可证伪性优先

对同一光电电离实验，明确电子/离子能动量和光子探测器的能量、角度分辨率。计算标准 QED 在同样测量定义下的包容性预测，再要求方向 A 给出额外可观测差异，例如条件软辐射谱或多光子关联。仅断言“还有不可探测的原始光子”不足以建立可检验的新理论。
