# v0.30：软光子辐射与必然后继光子的探测阈值比较

## 研究定位
方向 A“原始光子永远存在”仍未经验证。本轮区分：
- A1：每次吸收都存在具有正能量、可在原则上探测的后继光子；
- A2：仅有不改变观测量的不可见身份标签。

仅 A1 在规定后继光子的能量与耦合后具有直接可证伪预测。**这里的模型是领先对数独立泊松辐射玩具模型，不是完整 QED 计算。**

## 标准软光子玩具基准
设软辐射在阈值 Δ 与上限 Λ 间的平均数 μ=β ln(Λ/Δ)，β≥0，0<Δ<Λ。独立泊松辐射和独立探测效率 η_s 的假设下：
P_QED,toy=1−exp(−η_s μ)。
这里的“QED,toy”只是受软光子行为启发的近似；没有完整过程依赖的系数、虚修正、相空间或包容性截面。不能直接作为真实氢原子光电电离的精确基准。

## A1 额外后继信号
额外假设每次电离都产生一个**独立**后继光子，其能量 ε0>0，探测效率 η_h，且不改变标准软辐射分布。若 ε0≥Δ：
P_A1,toy=1−(1−P_QED,toy)(1−η_h)；
ΔP=η_h exp(−η_s μ)。
若 ε0<Δ，P_A1,toy=P_QED,toy。

这是条件性预测，来自新加入的假设，不是“永久存在”本身的逻辑必然推论。后继光子如果不是独立的、与标准辐射不可区分，或改变相空间，公式不再成立。

## 示例参数
β=0.1、Λ=10 eV、ε0=2 eV、η_s=η_h=0.8。阈值 Δ=1 eV 时，μ=0.1 ln10≈0.23026，标准玩具点击率≈16.82%，A1 玩具点击率≈83.36%。Δ=2.5 eV 时后继信号低于阈值，两者相同。

## 理论与实验局限
1. 红外安全可观测量需要实辐射与虚辐射修正联合处理；不能用“无任何软光子”的极限概率直接断言物理。
2. 能量、动量、原子反冲和电子连续态需要一致计算。额外后继光子必须从总能量预算中扣除。
3. 真实探测器具有连续响应、有限角覆盖、暗计数、时间抖动和背景。
4. 标准 QED 本身存在辐射电离通道，额外点击并不自动证明身份连续。
5. A2 若不改变任何观测结果，则不能被本实验检验。
6. 不能将本轮示例数字与实测数据比较后直接宣称发现新物理。
