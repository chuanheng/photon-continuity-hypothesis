# 能谱鉴别与统计可识别性：合成示例 v0.5

**重要：所有能谱计数都是人为构造的教学数据，不是 NIST XCOM 的完整模拟结果，也不是任何真实实验。**

## 1. 为什么仅比较两个衰减指数不够

标准模型的能量分箱期望 B_i 应来自实际入射谱、材料截面、散射角分布、多次散射、荧光和探测器响应。当前仓库只实现了未碰撞束衰减；不能把该曲线冒充完整标准能谱。

我们用一组人为设定的 B_i 演示统计分析；它不能用于证明或否定光子连续存在假说。

## 2. 定义可证伪的扩展

在固定能量分箱 i 中，标准模型预期 B_i>0。假设额外可观测光子具有预注册形状 T_i≥0，且 ΣT_i=1。设其总计数强度 A≥0，则

μ_i(A)=B_i+A T_i。

观测 n_i 服从独立泊松分布的理想化模型。**A 是新增的可探测事件数，不是“永生光子”数量。**

## 3. 固定背景的 Asimov 演示

假设数据恰好等于扩展模型期望 n_i=B_i+A T_i，则在固定 B_i、固定 T_i 的理想情形下：

q_A=2 Σ_i [(B_i+A T_i) ln((B_i+A T_i)/B_i) − A T_i]。

q_A 是期望对数似然比的两倍；不能不经边界条件、搜索效应及系统误差校准就将 sqrt(q_A) 宣称为实验发现显著性。

## 4. 一个关键反例：背景归一化可吸收额外信号

如果背景总体强度存在完全自由的归一化参数 β，模型变为 μ_i=β B_i + A T_i。

在 A=0 附近，固定背景下的 Fisher 信息 I_AA=Σ T_i²/B_i。

将 β 作为自由干扰参数后，A 的有效局部信息为：

I_AA,profile=Σ T_i²/B_i − (Σ T_i)²/(Σ B_i)。

如果 T_i 与 B_i 成正比，结果**严格等于零**：任意额外强度 A 都可通过调整 β 完全模拟。此时无论计数多高，仅凭该谱形都不能识别额外信号。

这个反例说明，必须先找到区别于标准物理背景的独特谱形或相关性，而不是仅假设有额外光子。

## 5. 模拟文件

运行：
```bash
python3 models/spectral_discrimination.py
python3 -m unittest discover -s tests -v
```

程序仅用 Python 标准库，打印人为设定的能量分箱、固定背景 Asimov q、以及放开背景归一化后的信息损失。

## 6. 下一步严肃研究门槛

1. 从可靠实验或验证过的输运程序生成 B_i 并公开版本、几何和不确定度。
2. 根据具体微观理论推导 T_i，**不能根据观察到的残差事后选择形状**。
3. 估计源强、探测器效率、能量标定、材料厚度和散射背景的干扰参数。
4. 使用预注册的统计判据和蒙特卡洛覆盖率检查。
5. 对于永远不可探测的残余“原始光子”，该方案仍然无法证伪。

研究现状：只有一个可重复的统计示例；尚无新物理信号预测或实验数据。
