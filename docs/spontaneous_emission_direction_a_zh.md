# v0.23：开放量子系统、自发辐射与原始光子身份

**研究方向 A：每个原始光子永远存在。仍为待检验假说。**

## 1. 从封闭到开放系统

v0.22 的闭合单模 Jaynes–Cummings 模型可出现光子数归零和完整复现，但真实原子通常与环境中大量电磁场模式耦合。使用无外驱动、马尔可夫、零温真空环境的两能级自发辐射模型：

dρ/dt=−i[H,ρ]/ℏ+Γ(σ₋ρσ₊−{σ₊σ₋,ρ}/2)。

在相互作用表象取 H=0，σ₋=|g⟩⟨e|，Γ≥0。

## 2. 解析结果

若初始原子为激发态，激发概率 P_e(t)=exp(−Γt)；累计首次发射概率 F(t)=1−exp(−Γt)，等待时间密度 p(t)=Γexp(−Γt)，中位等待时间 t_50=ln2/Γ（Γ>0）。

若初态密度矩阵的激发人口为 p，非对角元为 c，则

ρ_ee(t)=p exp(−Γt)，
ρ_eg(t)=c exp(−Γt/2)，
ρ_gg(t)=1−ρ_ee(t)。

这个映射保持迹与正性（对有效初态）。无驱动时，理想两能级原子在一次跃迁后停留于基态；本模型不包含再次激发。

## 3. 与方向 A 的关系

原子从激发态跃迁至基态并向环境辐射光子，是标准开放量子系统理论可以描述的过程。它不证明该辐射光子就是之前被吸收的原始光子。

如果方向 A 认为原始光子在原子激发、局部光场真空阶段仍存在，需要定义额外的状态空间、能量动量和耦合，并计算与标准模型不同的可测量预测（寿命、谱线、时间关联、输出场统计等）。否则它可能只是对同一测量结果的不同解释。

## 4. 重要限制

- 此 Lindblad 方程是将辐射场迹掉后的原子约化动力学；约化模型不显式跟踪环境光子。
- 零温、马尔可夫、旋波近似、两能级、无驱动；不适用于所有真实原子与材料。
- Γ 是输入参数，不是从微观 QED 计算得到。
- “首次发射概率”针对理想单跳跃量子轨迹；有限探测效率时观测点击率不同。
- 这不是对方向 A 的实验验证或普遍不可能性证明。
