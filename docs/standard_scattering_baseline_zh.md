# 标准散射基线与可区分预测（v0.4）

## 1. NIST 60 keV 铝参考

NIST 铝表：60 keV 的总质量衰减系数 μ/ρ = 0.2778 cm²/g；取密度 ρ=2.699 g/cm³，则 μ=0.7497822 cm⁻¹。

未相互作用的理想窄束光子数 N_u(x)=N_0 exp(-μx)。这不是探测器实际记录的完整透射谱，也不是“光子是否存活”的判据。

来源：https://physics.nist.gov/PhysRefData/XrayMassCoef/ElemTab/z13.html

注意：NIST 同一行的 μ_en/ρ=0.1099 cm²/g 是**质量能量吸收系数**，不能当作总衰减系数。XCOM 还区分相干、非相干、光电等分过程，但它提供的积分系数不能直接代替能量-角度双微分散射截面。

## 2. 标准理论已描述非弹性散射

在非共振近似下，常用表达式为

d²σ/(dΩ dE_f) ∝ (E_f/E_i) r_e² |ε_f*·ε_i|² S(q,ω),

其中 ω=(E_i−E_f)/ℏ，q=k_i−k_f；S(q,ω) 是材料的动态结构因子。比例系数和 S 的归一化取决于约定。具体散射强度由材料电子结构、激发态、偏振、几何和选择定则决定。

近前向散射的有限能量损失并非新现象；不能仅凭“前向低能光子”宣布发现新物理。

来源：
- IUCr: https://dictionary.iucr.org/Inelastic_X-ray_scattering_%28IXS%29
- Baron review: https://beamline.harima.riken.jp/bl43lxu/pdfs/review_paper.pdf

## 3. 可观测量定义

预先指定入射谱、样品厚度 x、出射角 θ、能量 E_f 和仪器响应 R。

H0（标准模型）：μ_j(E)、标准非弹性散射核 S(q,ω)、光电吸收、荧光及多次散射等，共同产生预测计数 B_i。

H1（参数化扩展）：B_i + A T_i(α,λ,几何,探测器)，其中 T_i 是**预先计算并归一化**的额外模板，A≥0 是额外强度。

若 T_i 的形状或参数可随数据任意改变，结论没有可证伪性。若模板与标准散射及背景不可区分，则无法鉴别 H1。

## 4. 统计检验

对能量与角度分箱的计数 n_i，可采用 Poisson 似然

L(A,η)=∏_i Poisson[n_i | B_i(η)+A T_i(η)]，

η 表示源谱、几何、探测器和材料响应等干扰参数。用轮廓似然或蒙特卡洛校准显著性及上限；A=0 在参数边界，不能未经检查直接套用普通卡方近似。

必须提供系统误差、盲分析方案、预注册参数范围及功效分析。无额外信号只限制具体的 (A,α,λ) 范围，不能排除任意弱且不可探测的“原始光子”。

## 5. 当前最重要的困难

“光子在被吸收后仍以不可测的超低能形式存在”缺乏操作性定义。若没有可测谱形、相关性或能量守恒上的独特偏差，就不能构成独立可检验的物理理论。
