# v0.71 Stinespring 扩张唯一性与光子身份的数学冗余

同一完全正保迹量子信道的最小 Stinespring 扩张在环境酉变换意义下唯一。非最小扩张可以额外附加不可访问辅助空间。定义等距映射 V:H_S→H_E⊗H_S，V†V=I，Φ(ρ)=Tr_E(VρV†)。任意环境酉 U_E 满足 V'=(U_E⊗I)V，故 Φ'=Φ。

振幅阻尼 Kraus 算符 K0=diag(1,sqrt(1−γ))、K1=[[0,sqrt(γ)],[0,0]]，V=|0>⊗K0+|1>⊗K1。附加任意归一化身份态 |h> 后，系统信道不变。γ=0 时 Choi 秩1，0<γ≤1 时 Choi 秩2；最小环境维数等于 Choi 秩。额外身份量子比特不改变 Choi 秩。

本地6项单元测试全部通过。数学等价不证明身份不存在；但不可访问的辅助标签无法单独构成新物理预测。此处为有限维量子信道示例，不是完整光子 QED。
