# v0.73 超选择规则、可观测量代数与光子身份

有限维荷扇区 H=⊕_q H_q，允许可观测量满足 [A,Q]=0，即 A=⊕_q A_q。定义 D_Q(ρ)=Σ_q P_qρP_q，则任意允许 A 均有 Tr(ρA)=Tr(D_Q(ρ)A)。

给定全部块对角 POVM，等先验最优区分距离 D_op(ρ,σ)=1/2||D_Q(ρ)-D_Q(σ)||_1。

二维示例 |+> 与 |-> 完整迹距离为 1；若 |0>、|1> 属于不同扇区，则 D_op=0；若属于同一扇区则 D_op=1。同一扇区内部的相干性不会被消除。

重要限制：假定某个“永久身份”标签受超选择规则约束，并非证明这种规则在真实光子中存在。需要从对称性、允许算符及耦合中独立推导可观测预测。该模型不是 QED。实际本地运行16项单元测试全部通过。
