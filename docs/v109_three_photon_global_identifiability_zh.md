# v1.09：真实三端口三光子干涉模型与全局可辨识性

**日期：** 2026-11-14。**研究性质：** 标准量子光学的可复现合成数学研究，不是实际实验，不涉及对光子永久身份的测量或验证。v1.07 原始 600 组结果尚未纳入此次复现。

## 1. 问题与模型

三光子分别占据三个输入端口，在平衡的 Fourier tritter 内发生干涉。取酉矩阵 U[j,k]=exp(2πijk/3)/sqrt(3)，j,k=0,1,2。光子内部纯态的 Gram 矩阵满足 G_01=G_12=r、G_20=r exp(iΦ)、G_ii=1，其余由 Hermitian 条件确定。r∈[0,0.5] 确保该矩阵对任意 Φ 半正定。

三个输出检测口的无序占据模式 o，其概率为

P(o)=[1/(∏_k n_k!)] Σ_{σ,τ∈S3} ∏_{i=1}^3 U[o_i,σ_i] U*[o_i,τ_i] G[σ_i,τ_i]。

这里 n_k 是端口 k 的占据数，σ、τ 是输入光子标签的全部排列。枚举全部十种模式，计算完整探测概率，而非仅仅比较 Gram permanent。

概率非负，且合计为 1（浮点精度内）。r=0 时可复现完全可区分光子的经典输出概率：P(3,0,0)=1/27、P(1,1,1)=2/9。

## 3. 关键全局不可辨识反例

对固定 r=0.3，比较 Φ=+π/3 与 Φ=-π/3。

**保留完整端口标记：** 十种概率分布不同；最大绝对概率差 0.009；total variation distance=0.027；D_KL(P_plus || P_minus)=0.0022181753 nats / event。因此，在模型成立且统计次数足够时，原则上可以辨识符号。

**只保留输出类型：** 合并为三个事件类型：全部同端口 (3)、二同一异 (2+1)、三个不同 (1+1+1)。在这两个相位配置下，三类合并概率严格相同（数值精度内）：

[0.14411111, 0.65766667, 0.19822222]。

其 KL 散度为 0。于是在这种**粗粒化测量方案**下，两个不同的 Φ 值严格观测等价；增加样本量无法恢复已经丢弃的端口信息。

**注意：** 这不意味着三光子闭环相位普遍不可辨识，也不意味着任意干涉仪都存在相同符号退化。此结论仅针对所给 Fourier tritter、两种指定相位及明确的端口粗粒化方式。

## 4. 局部 Fisher 信息

(r,Φ) 的十类 multinomial 输出概率所给每事件 Fisher 信息，在 r=0.3、Φ=π/3 时为：

- I_rr≈0.5923663592
- I_rΦ≈0.0031450766
- I_ΦΦ≈0.0014420330
- det(I)≈0.0008443203 > 0

因此在此二参数理想模型的这一内部点局部可辨识。**Fisher 满秩不是全局可辨识的证明。** 当 r=0 时，任意 Φ 对输出概率均不产生影响，相位不再可辨识。

## 5. 物理意义和限制

- 两光子参考实验通常约束两两重叠模长平方，无法仅凭这些数据普遍确定规范不变的三光子闭环相位。
- 三光子完整端口探测可能提供额外相位信息；只保留三种输出分区会损失其中的一部分。
- 本轮假设完美的 unitary、每个输入端口恰好一个光子、无损耗、无探测噪声、共同可用的三个内部纯态，以及全部端口光子数分辨。
- 尚未加入探测效率、模式漂移、干涉仪误差或其他干扰参数，不能推断真实仪器的实际检验功效。
- 这一类闭环相位影响属于已有的**标准量子光学**。不能把它当成光子连续存在假说区别于标准理论的新证据。
