# v1.10：非理想三光子干涉——仪器偏差、探测损耗与独立标定漂移

日期：2026-11-14。研究状态：**实际执行的标准量子光学合成模型研究；不是实际实验，也不是对永久光子身份的证据。**

## 模型

承接 v1.09 的三个单光子输入与 Fourier tritter：U_F[j,k]=exp(2πijk/3)/√3。设置一个可控的、严格酉性的输出混合变换 U(ε)=R_01(ε)U_F。内部纯态 Gram 矩阵 G_01=G_12=r、G_20=r exp(iΦ)，r=0.3，Φ=π/3。依照部分可区分光子标准公式计算十个端口占据模式的概率。

输出探测器的光子数分辨效率设为 η=(η0,η1,η2)，各输出光子独立经历 Bernoulli 探测损耗。对每个三光子输出模式，乘以三端口二项 thinning kernel，生成总光子数 0 至 3 的 **20 个**探测占据结果。再将探测结果按排序后的占据类型合并，即为丢弃端口标签的粗粒化结果。

此模型没有暗计数、探测串扰、光子源不纯、时间相关效率、背景噪声，亦未将器件偏差作为联合未知量估计。结果只对已知的固定 ε、η 成立。

## A. 两种闭环相位符号的统计区分

比较 H+: Φ=+π/3 与 H-: Φ=-π/3，其他参数固定。

| 条件 | ε | 探测效率 | 完整结果 TV | 完整结果 KL (nats/事件) |
|---|---:|---|---:|---:|
| 理想 | 0 | (1,1,1) | 0.027000000 | 0.002218175 |
| 仅器件扰动 | 0.08 | (1,1,1) | 0.026655137 | 0.002159051 |
| 仅不对称损耗 | 0 | (0.86,0.82,0.90) | 0.018808200 | 0.001429542 |
| 扰动与不对称损耗 | 0.08 | (0.86,0.82,0.90) | 0.018567968 | 0.001391742 |

两类误差同时存在时，完整结果 KL 比理想下降约 37.3%。探测总光子数的期望为 η0+η1+η2=2.58。

对称损耗 η=(0.85,0.85,0.85) 时，上述两相位在粗粒化探测上仍严格等价（数值精度内）。**但不对称损耗** η=(0.86,0.82,0.90) 的粗粒化结果为：

| ε | 粗粒化 TV | 粗粒化 KL (nats/事件) |
|---:|---:|---:|
| 0 | 0.000004608 | 3.7884×10^-10 |
| 0.08 | 0.000004549 | 3.6927×10^-10 |

因此一个严格零的信息通道可能在仪器不对称性下变成非零，但效果微小且依赖**准确已知**的仪器效率。不能把可检测的仪器不对称当成新物理效应，也不能在效率参数未知时直接宣称相位可辨识。

## B. 模式标定跨实验漂移

采用 r_main=0.3、Φ_true=π/3、ε=0.08、η=(0.86,0.82,0.90) 的**理论总体概率**作为拟合目标，假定参考实验给定固定 r_ref，网格拟合完整 20 项探测分布下 Φ 的伪真实值（网格步长 0.5°）。

| r_ref | 估计 Φ | 估计 Φ（度） |
|---:|---:|---:|
| 0.27 | 1.108284075 | 63.5° |
| 0.29 | 1.073377490 | 61.5° |
| 0.30 | 1.047197551 | 60.0° |
| 0.31 | 1.021017612 | 58.5° |
| 0.33 | 0.968657735 | 55.5° |

这是**总体 KL 极小值的合成拟合**，不是有限样本 Monte Carlo 均值、RMSE 或可信区间覆盖率。已知真实 r 的正确模型恢复 Φ；把有系统差异的参考 r 当成主实验参数会引入不可由多采样消除的偏差。

如果只错设 ε=0（但 η 正确），得到拟合 Φ≈1.064650844 rad（61.0°），最小 KL≈2.144×10^-5。若连探测损耗都假设不存在，则会出现观测到失光事件而模型赋零概率的 support mismatch，KL 为无穷大；这不是有意义的公平参数拟合对照。

## D. 解释与限制

1. 由输出端口混合构造的 ε 扰动是一种**特定的设备误差模型**，不能代表所有光学变换不确定性。
2. KL / TV 对比以两组完全指定的假设为前提；若 η、ε、r 等同时未知，需要 profile likelihood、联合 Fisher 信息矩阵及全局观测等价类分析。
3. 不对称损耗可能解除特定的严格退化，但不保证有实际统计检验功效，更不意味着真实仪器误差有益。
4. 任何上述差异都由标准多光子量子干涉和普通探测误差解释；没有新预测，也没有测到“光子永久身份”。
