# v1.11：三光子联合 Fisher 信息与新增 10,000 次实验预算分配

**2026-11-14 · 合成模型数学研究，非物理实验。** 本轮承接 v1.10 标准量子光学的 Fourier tritter 模型，目标是评估既有标定条件下，对三光子闭环相位 Φ 的局部渐近估计精度。**结果不能证明永久光子身份。**

## 1. 参数和主实验

联合参数 θ=(r, Φ, ε, η0, η1, η2)，真实值 (0.30,π/3,0.08,0.86,0.82,0.90)。主实验完整保留 20 种输出探测占据事件（含未探测到光子的情况），以独立同分布 multinomial 采样为假设。光学 U(ε)、Gram 矩阵、binomial 探测损耗使用 v1.10 的实现。

主实验单次 Fisher 信息 I3 = Σ_y [∂θ p(y)∂θ p(y)^T/p(y)]。数值导数用中央差分 h=1e-5；该参数点上 p(y)>0。

额外参考标定作为**彼此独立、且与主实验严格共享相应参数**的 Bernoulli 观测：

- HOM 型两光子参考：单次 coincidence 概率 p_H=(1-r²)/2；r 为内部**振幅**重叠，不是重叠模长平方。忽略两光子参考中的额外损耗与其他干扰参数。
- 探测器标定：单次标定轮次向每个探测器各注入一个已知单光子，相互独立探测概率 η0、η1、η2。因此“一次效率标定”涉及**三个**已知入射光子；每次成本按一个抽象预算单位计，并非严格等光子/等时长成本。
- 器件角度标定：单次 Bernoulli 的事件概率 p_ε=sin²(π/4+ε)，假定专门设计的光学校准支路能观察到此统计量。此处它仅仅是可解析的**辅助测量假设**，并未论证真实实现方式。

联合总 Fisher：I=N3 I3 + Nr Ir + Nη Iη + Nε Iε。若 I 正定，Φ 的 Cramér–Rao 标准差下界为 sqrt((I^-1)[Φ,Φ])，不是 Monte Carlo RMSE、可信区间覆盖率、检验功效或全局可辨识证明。

## 2. 预算方案与实际计算

既有基线 (N3,Nr,Nη,Nε)=(10000,1000,1000,1000)。新增预算恰好 10,000 个抽象轮次，按 1,000 步长遍历所有非负四元整数分配，共 C(13,3)=286 种。计算结果：

| 新增预算用途 | Φ 标准差下界（rad） | 相对基线改善 |
|---|---:|---:|
| 无新增预算 | 0.3340974074 | -- |
| 10000 全用于三光子主实验 | 0.2364182414 | 29.24% |
| 10000 全用于 HOM 参考 | 0.3332453678 | 0.26% |
| 10000 全用于探测器效率参考 | 0.3340948906 | 0.00075% |
| 10000 全用于光学器件角度参考 | 0.3339409381 | 0.047% |
| 四项各 2500 | 0.2985230689 | 10.65% |

**在这一设定和 1,000 步长的 286 个候选方案中，最优为 (10000,0,0,0)。** 这是局部 Fisher/固定参数/固定成本模型下的解，不能外推为真实实验通用最优配置。

主实验单次 Fisher 矩阵在本参数点的数值秩为 6，最小特征值约 8.6642×10^-4；它并非局部秩亏，故继续增加主实验次数能够直接提升 Φ 的估计精度。基线联合总 Fisher 最小特征值约为 8.95866，条件数约 1.0246×10^4。条件数还取决于参数尺度，不能孤立解读。

## 4. 限制与反例风险

1. **局部而非全局：** Fisher 满秩未证明参数组合不存在其他全局观测等价解、相位周期歧义或边界退化。
2. **Fisher 精度而非后验：** 当前没有实施多次 multinomial 随机采样、完整极大似然优化、置信区间覆盖统计，因此不应宣称已获得实际 RMSE。
3. **计数预算不是成本预算：** HOM、三光子生成、三路效率标定、光学参考支路可能有完全不同的成本、实验时长与成功率。若改用真实成本约束，最优分配可能变化。
4. **参考模型理想化：** HOM 与主实验具有完全相同 r，效率与角度参考完全共享参数；未考虑时间漂移、不匹配、计数非独立、背景噪声。
5. **本结果不是普遍定律：** 选用不同初始样本量、其他参数点或其他相位损失函数，最优预算可能不再全部投向主实验。

- 明确建立连续身份假说相对于标准量子光学的**独有可证伪预测**。若仍无法构造，不应把现有标准干涉效果解读为对该假说的支持。
