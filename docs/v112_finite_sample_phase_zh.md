# v1.12：有限样本相位 MLE 与区间覆盖

**研究状态：** 2026-11-16；本轮是基于标准量子光学 Fourier tritter 的合成计算，绝非光子永久身份的实验证明。

**公共假设：** 三光子各入一端口；重叠 Gram 矩阵 G01=G12=r，G20=r exp(iΦ)；器件 U=R01(ε) UF；三个光子探测器独立二项损耗。真实参数为 (r,Φ,ε,η0,η1,η2)=(0.3,π/3,0.08,0.86,0.82,0.90)。种子 20261116。除有说明，结果均为理论或合成统计，非真实采样。

固定除 Φ 外全部五个参数，每次合成 10000 个主实验事件，共 80 次独立 multinomial 重复。单参数限制区间 (0.05,3.08) rad 内最小化负对数似然。估计均值 1.013746333 rad，偏差 -0.033451218 rad，RMSE 0.366334325 rad；oracle Fisher 标准差下界为 0.332144403 rad。用真实参数处 Fisher 下界构造的 Wald 95% 区间覆盖 73/80=91.25%。

**判断：** 有限样本误差可能高于 Fisher 下界；80 次重复不足以精确判断长期覆盖率。固定 nuisance 和使用真实 Fisher 的 Wald 区间都属于理想化条件。

**复核入口：** 本批次完整计算代码与 JSON 数据见本次对话交付的附件；本报告所列指标应以固定随机种子运行的结果为准。
