# v1.13：两参数联合 MLE 与 HOM 参考

**研究状态：** 2026-11-16；本轮是基于标准量子光学 Fourier tritter 的合成计算，绝非光子永久身份的实验证明。

**公共假设：** 三光子各入一端口；重叠 Gram 矩阵 G01=G12=r，G20=r exp(iΦ)；器件 U=R01(ε) UF；三个光子探测器独立二项损耗。真实参数为 (r,Φ,ε,η0,η1,η2)=(0.3,π/3,0.08,0.86,0.82,0.90)。种子 20261116。除有说明，结果均为理论或合成统计，非真实采样。

进行 35 次配对合成推断：主实验每次 N=3500，独立 HOM 型参考 N=1200；HOM coincidence 概率 (1-r²)/2。联合拟合 r∈[0.03,0.49]、Φ∈[0.05,3.08]，其他仪器参数固定真实值。35/35 次优化器报告成功；r 的 RMSE=0.019344997，Φ 的 RMSE=0.562540151 rad，相位偏差 +0.024969843 rad。

**限制：** 35 次重复规模小；优化器报告成功不等于已排除局部极小值。相位仅拟合正相位分支，不能推断全局可辨识。
