# v1.15：未知仪器参数的 Fisher 代价

**研究状态：** 2026-11-16；本轮是基于标准量子光学 Fourier tritter 的合成计算，绝非光子永久身份的实验证明。

**公共假设：** 三光子各入一端口；重叠 Gram 矩阵 G01=G12=r，G20=r exp(iΦ)；器件 U=R01(ε) UF；三个光子探测器独立二项损耗。真实参数为 (r,Φ,ε,η0,η1,η2)=(0.3,π/3,0.08,0.86,0.82,0.90)。种子 20261116。除有说明，结果均为理论或合成统计，非真实采样。

在同一真实参数处用中心差分计算完整 20 类输出的六参数 Fisher 信息，数值秩为 6。N=10000 时，其他参数理想已知的单相位标准差下界为 0.332144403 rad；六参数全部未知且只看主实验时为 0.339375332 rad；加入基线参考计数 (HOM 1000、效率 1000、器件 1000) 后为 0.334097407 rad。

**判断：** nuisance 未知会使边际相位精度变差；参考标定能够部分补偿，但 Fisher 的局部可辨识并不证明全局无退化。
