# v1.18：重叠趋零的相位退化

**研究状态：** 2026-11-16；本轮是基于标准量子光学 Fourier tritter 的合成计算，绝非光子永久身份的实验证明。

**公共假设：** 三光子各入一端口；重叠 Gram 矩阵 G01=G12=r，G20=r exp(iΦ)；器件 U=R01(ε) UF；三个光子探测器独立二项损耗。真实参数为 (r,Φ,ε,η0,η1,η2)=(0.3,π/3,0.08,0.86,0.82,0.90)。种子 20261116。除有说明，结果均为理论或合成统计，非真实采样。

保持其他四个仪器参数固定真值，只考察 Φ 的单参数 Fisher 信息：

| r | Φ=0 | Φ=π/3 |
|---:|---:|---:|
| 0.03 | 9.16073e-10 | 9.16941e-10 |
| 0.10 | 1.25767e-6 | 1.25672e-6 |
| 0.30 | 9.39829e-4 | 9.06455e-4 |

精确 r=0 时内部态正交，概率与 Φ 无关，相位不可辨识。计算中 r=0 以 1e-5 代入并得到数值为 0。非零重叠但极小时 Fisher 相位信息极小，需要非常多的事件。

**限制：** 研究的是单参数局部信息，不是联合全局判别；π 周期与局部最值问题要在后续 profile-likelihood 分析中处理。
