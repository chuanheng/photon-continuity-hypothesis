# v1.21：永久身份假说的可证伪性门槛

**研究状态：** 2026-11-16；本轮是基于标准量子光学 Fourier tritter 的合成计算，绝非光子永久身份的实验证明。

**公共假设：** 三光子各入一端口；重叠 Gram 矩阵 G01=G12=r，G20=r exp(iΦ)；器件 U=R01(ε) UF；三个光子探测器独立二项损耗。真实参数为 (r,Φ,ε,η0,η1,η2)=(0.3,π/3,0.08,0.86,0.82,0.90)。种子 20261116。除有说明，结果均为理论或合成统计，非真实采样。

检验一个逻辑上必须明确的零效应扩展：在标准 quantum-optical 模型上额外附加不可观测的“持续身份标签”，但标签不改变任何制备、动力学、干涉矩阵或探测 POVM 的概率。此时新旧模型的观测概率逐项相等，L1 距离=0、KL=0。

**严格结论：** 若永久身份标签不产生可测概率差异，它在这个实验族内不可检验；任何统计样本量都无法辨别两者。这不是证明光子有或没有永久身份。

**下一阶段必须提供：** (1) 超出标准量子光学的显式动力学方程；(2) 预注册、可观测且量化的新预测；(3) 共享 nuisance 条件下模型差异严格非零；(4) 能量/动量守恒与现有实验约束；(5) 明确否证阈值和仪器背景系统误差。
