# v1.22：不可观测永久身份标签的等价性

> **方法声明（2026-11-16）**：这是为约束光子连续性假说而建立的简化量子模型或统计模型，不是 QED 全过程模拟、真实物理实验或永久光子身份的验证。能量用任意单位，参数均为合成设定。请勿把普通低能光子出射等同于“原始光子永久保留”。

**研究类型：** 数学结果

设标准量子模型给出观测概率 P(D|θ)。向态的描述加入身份寄存器 L，但制备、演化和所有实际 POVM 都不依赖 L。对不可访问的 L 做偏迹后仍得到 P(D|θ)，因此 P(D|θ,L)=P(D|θ)，KL 散度严格为 0。

**结论**：增加采样次数无法检验一个对任何允许测量均无作用的标签。要获得新物理，必须使身份参与动力学或允许额外可测算符。不能把这个结论扩展成“量子理论已经证明不存在光子个体身份”；它只说明当前操作集合下不可判别。

**下一步**：为标签指定正定态空间、交换对称作用及可测耦合。
