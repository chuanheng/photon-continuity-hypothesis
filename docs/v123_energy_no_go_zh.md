# v1.23：保持原能量同时激发物质的能量账

> **方法声明（2026-11-16）**：这是为约束光子连续性假说而建立的简化量子模型或统计模型，不是 QED 全过程模拟、真实物理实验或永久光子身份的验证。能量用任意单位，参数均为合成设定。请勿把普通低能光子出射等同于“原始光子永久保留”。

**研究类型：** 守恒约束

初态包含硬光子能量 E_h=3、靶物质基态能量 0，总能量为 3。若出态仍保留能量为 3 的硬光子，并令靶激发获得 2，则总能量变成 5；能量差 ΔE=+2。

**结论**：在封闭且时间平移不变的系统中，这一候选转换被能量守恒排除。若存在外场泵浦、外部功源、初始靶储能等，则必须显式纳入总哈密顿量和能量预算，不能只声称硬光子既完整存活又向物质供能。

**可检验要求**：逐通道列出包含靶、场、反冲及外界的守恒式。
