# v1.24：降能光子与物质激发的合法末态

> **方法声明（2026-11-16）**：这是为约束光子连续性假说而建立的简化量子模型或统计模型，不是 QED 全过程模拟、真实物理实验或永久光子身份的验证。能量用任意单位，参数均为合成设定。请勿把普通低能光子出射等同于“原始光子永久保留”。

**研究类型：** 构造性反例

改用三种能量相同的联合基态：|h,g>（光子能量 3、靶基态 0）；|vac,e3>（无出射光子、靶激发能量 3）；|s,e2>（软光子能量 1、靶激发能量 2）。三者总能量均为 3。

**结论**：软光子与激发靶共存可满足守恒，但这并没有证明软光子与入射硬光子具有相同的“永久身份”；标准非弹性散射或辐射通道也可产生低能光子。严格微观模型还须满足动量守恒、角动量与选择定则。
