# v1.26：低能光子信号的实际探测统计

> **方法声明（2026-11-16）**：这是为约束光子连续性假说而建立的简化量子模型或统计模型，不是 QED 全过程模拟、真实物理实验或永久光子身份的验证。能量用任意单位，参数均为合成设定。请勿把普通低能光子出射等同于“原始光子永久保留”。

**研究类型：** 合成计算

假设标准低能光子通道概率 b0=0.04，候选模型 b1=0.055，软光子探测效率 η=0.70，独立暗计数概率 d=0.01。单轮可见点击概率 p=d+(1−d)bη。

得到 p0=0.037720，p1=0.048115。以两组所有参数都已知的简单假设比较，D_KL(Bern(p1)||Bern(p0))=0.0013727095186360661 nat/轮；N=10000 时期望 log 似然比为 13.727095。

**关键限制**：b1 增大只说明“软出射通道增强”这一额外机制有可观测影响，不意味着该差异专属于永久身份；b0、η、d 在真实实验中必须独立约束。
