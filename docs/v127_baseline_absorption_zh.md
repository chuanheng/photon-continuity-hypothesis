# v1.27：普通散射基线可完全吸收新通道

> **方法声明（2026-11-16）**：这是为约束光子连续性假说而建立的简化量子模型或统计模型，不是 QED 全过程模拟、真实物理实验或永久光子身份的验证。能量用任意单位，参数均为合成设定。请勿把普通低能光子出射等同于“原始光子永久保留”。

**研究类型：** 全局观测等价

如果候选身份模型只有软通道概率从 b0=0.04 增加 Δb=0.015，而标准模型允许自己的软通道基线 b0' 自由变化，则标准模型取 b0'=0.055 时，所有 Bernoulli 点击概率与候选模型完全一致，KL=0。

**结论**：检测到软光子的概率变化不够。只有在**标准理论对照已约束**出不能通过正常散射、荧光、探测器背景和其他干扰参数解释的差异，才可能形成值得继续检验的新预测。

**边界**：这里的“等价”只针对单一软点击观测量，不能宣称所有光学观测均等价。
