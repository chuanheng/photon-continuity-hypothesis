**研究类型：** 局部秩分析

取 p=d+(1−d)bη，若 η=0.7 已知、b 和 d 都未知，则同一探测设置只有一个 Bernoulli 概率。其 Jacobian 行向量为 [∂p/∂b,∂p/∂d]=[(1−d)η,1−bη]=[0.693,0.972]，秩为 1；JᵀJ 的另一个特征值为 0（数值舍入附近）。

**结论**：在该测量配置里增加无限多次同种采样仍无法单独确定 b 和 d。需要额外探测设置、暗计数参考或其他可观测信息。
