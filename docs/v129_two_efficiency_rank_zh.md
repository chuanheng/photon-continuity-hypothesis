# v1.29：两档效率对局部退化的修复

> **方法声明（2026-11-16）**：这是为约束光子连续性假说而建立的简化量子模型或统计模型，不是 QED 全过程模拟、真实物理实验或永久光子身份的验证。能量用任意单位，参数均为合成设定。请勿把普通低能光子出射等同于“原始光子永久保留”。

**研究类型：** 局部秩分析

保持 b=0.04、d=0.01 的共享参数假设，用已知效率 η1=0.7、η2=0.9 分别观测软光子点击。Jacobian 两行为 [(1−d)ηi,1−bηi]，JᵀJ 的特征值为 0.0125024414 与 3.1357075586，行列式为 0.039204，因此局部满秩。

**结论**：当效率确实独立已知、两档设置共享同一 b,d 时，双档参考能够区分软通道与暗计数。**注意** JᵀJ 不是 Fisher 信息；要得到精度下界必须按 Bernoulli 方差加权并乘每档样本量。若两档暗计数各不相同，又出现额外 nuisance，不保证满秩。
