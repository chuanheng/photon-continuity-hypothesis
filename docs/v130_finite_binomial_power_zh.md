# v1.30：固定假设下的种子可复现试验

> **方法声明（2026-11-16）**：这是为约束光子连续性假说而建立的简化量子模型或统计模型，不是 QED 全过程模拟、真实物理实验或永久光子身份的验证。能量用任意单位，参数均为合成设定。请勿把普通低能光子出射等同于“原始光子永久保留”。

**研究类型：** 随机采样与近似功效

取 v1.26 的 p0=0.03772、p1=0.048115，每组 N=10000，Python random.Random 固定种子 20261116 / 20261117，逐次模拟 Bernoulli 点击。零假设计数 414，候选计数 505；候选样本的 log LR（模型 p1 对 p0）为 19.7913097。

另外，单侧显著性 α=0.05 的正态近似检验功效约为 0.9996543。

**关键限定**：这些结论以 p0,p1 被事先精确指定为前提；若允许标准模型自由重新拟合 b、d，功效结论并不成立。正态近似不是精确二项检验，单组模拟亦不能提供 RMSE 或覆盖率估计。
