# v1.31：永久身份假说进入检验阶段的门槛

> **方法声明（2026-11-16）**：这是为约束光子连续性假说而建立的简化量子模型或统计模型，不是 QED 全过程模拟、真实物理实验或永久光子身份的验证。能量用任意单位，参数均为合成设定。请勿把普通低能光子出射等同于“原始光子永久保留”。

**研究类型：** 严格研究判断

十轮研究没有获得“光子永久身份”独有的可观测量。不可访问身份标签不会改变统计结果；若赋予它软出射等额外动力学，该动力学在目前的简化观测下也可能被标准非弹性散射通道完全吸收。

因此当前的明确结论是：**未形成标准量子光学/QED 不能解释的、定量且可证伪的新预测**。这不是否定个人对持续身份的哲学解释，而是拒绝把可复现的普通量子光学效应当作该解释的实验验证。

进入物理新理论检验前应给出：(1) 显式且自洽的哈密顿量/量子通道；(2) 守恒律与对称性；(3) 与标准 QED 同一装置下的预注册概率差；(4) 完整 nuisance 轮廓剖面后的非零最小 KL；(5) 实验功效与真实仪器预算；(6) 与既有实验的定量约束。

**建议下一批次 v1.32–v1.41**：若没有提出这些新机制，不再单纯增加轮次；优先开展机制候选的反例审查和现有实验约束清单。
