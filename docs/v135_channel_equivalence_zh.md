# v1.35：与准静态环境噪声完全等价

**日期：2026-11-16。研究性质：标准量子模型中的辅助寄存器玩具机制，非真实光学实验，不能证明永久光子身份。**

公共参数：g=1，Δ=0.7，κ=0.45，η=0.82，暗点击 d=0.015；时间 t=0.4,0.8,...,4.0（10 个点），ℏ=1。系统基为一激发扇区 |1,g〉、|0,e〉。哈密顿量 H=(gσx+Δσz/2)⊗I+κσz⊗Z；辅助寄存器初态 |+〉。该额外寄存器仅是**模型化的环境/身份候选自由度**，并未物理定义永久身份。

含寄存器的总演化可在 Z=±1 的两个子空间分块：U±=exp[−it(gσx+(Δ±2κ)σz/2)]。辅助初态 |+〉，测量前将辅助迹掉，所得系统通道恰为 E_t(ρ)=½U+ρU+†+½U−ρU−†，与一个普通的二值准静态失谐噪声模型完全一致。对四个 2×2 基算符分别比较显式 4×4 联合态偏迹与噪声通道，最大矩阵元差为 0（浮点精度下）。这是比存留率一致更强的**对全部单次系统态与 POVM 的相同通道**结论，但未涵盖可以直接操纵额外寄存器的操作。
