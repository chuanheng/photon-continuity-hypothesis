# v1.36：激发数守恒的作用范围

**日期：2026-11-16。研究性质：标准量子模型中的辅助寄存器玩具机制，非真实光学实验，不能证明永久光子身份。**

公共参数：g=1，Δ=0.7，κ=0.45，η=0.82，暗点击 d=0.015；时间 t=0.4,0.8,...,4.0（10 个点），ℏ=1。系统基为一激发扇区 |1,g〉、|0,e〉。哈密顿量 H=(gσx+Δσz/2)⊗I+κσz⊗Z；辅助寄存器初态 |+〉。该额外寄存器仅是**模型化的环境/身份候选自由度**，并未物理定义永久身份。

Jaynes–Cummings 旋波近似下 N=a†a+σ+σ−。选取单激发扇区 |1,g〉与 |0,e〉，N 在该扇区等于单位矩阵。因此 H0 与 κσz⊗Z 都在该扇区内作用，[H,N⊗I]=0，算符范数为 0。这是本模型的激发数守恒，不等同于任意时变/强耦合/外泵浦实验都会严格守恒同一个 N；系统总能量由完整 H 守恒。
