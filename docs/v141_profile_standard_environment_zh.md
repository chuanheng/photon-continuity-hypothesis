# v1.41：对真实新物理证据的最终可辨识性判定

**日期：2026-11-16。研究性质：标准量子模型中的辅助寄存器玩具机制，非真实光学实验，不能证明永久光子身份。**

公共参数：g=1，Δ=0.7，κ=0.45，η=0.82，暗点击 d=0.015；时间 t=0.4,0.8,...,4.0（10 个点），ℏ=1。系统基为一激发扇区 |1,g〉、|0,e〉。哈密顿量 H=(gσx+Δσz/2)⊗I+κσz⊗Z；辅助寄存器初态 |+〉。该额外寄存器仅是**模型化的环境/身份候选自由度**，并未物理定义永久身份。

将标准理论对照从单一静态失谐扩展到**二值准静态失谐噪声**：Δ±=Δ±2κ，各概率 1/2。由于与辅助寄存器的约化量子通道完全一致，所有可访问系统实验（在不操纵隐藏寄存器且每次新制备同样环境的前提下）的统计分布相同，profile KL=0。有限辅助环境在纯退相干特例中可产生 |cos(2κt)| 型相干恢复，但普通有限量子环境同样可以产生，不能解释为永久光子身份独有现象。**结论**：该候选动力学是合理的量子模型，但尚无任何永久身份独有的可证伪预测。下一阶段必须定义新操作、新守恒电荷或新的场耦合，并与完整标准 QED 和真实仪器约束对照。
