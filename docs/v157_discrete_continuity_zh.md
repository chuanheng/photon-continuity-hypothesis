# v1.57：格点连续性方程与数守恒

**2026-11-16 · v1.52–v1.61 批次。** 使用有限维矩阵、格点相位与理想概率进行计算；不是量子电动力学的新理论、完整洛伦兹协变证明或真实实验。代码：[模型](../models/identity_qft_gates_v152_v161.py)、[测试](../tests/test_identity_qft_gates_v152_v161.py)。

两节点单粒子跃迁模型 n0=diag(1,0)、n1=diag(0,1)。定义局域粒子数时间导数 J0=i[H,n0]、J1=i[H,n1]。计算 [H,n0+n1]=0 且 ||J0+J1||=0，电流算符满足厄米性。**结论**：此格点模型满足全局 U(1) 数守恒和两点间概率流的连续性条件，但并不意味着所有电磁相互作用保留光子数；真实 QED 中粒子产生、吸收和再发射可改变光子数。
