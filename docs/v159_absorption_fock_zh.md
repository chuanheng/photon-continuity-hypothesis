# v1.59：吸收与再发射不是永久编号传递

**2026-11-16 · v1.52–v1.61 批次。** 使用有限维矩阵、格点相位与理想概率进行计算；不是量子电动力学的新理论、完整洛伦兹协变证明或真实实验。代码：[模型](../models/identity_qft_gates_v152_v161.py)、[测试](../tests/test_identity_qft_gates_v152_v161.py)。

在 Jaynes–Cummings 旋波近似单激发子空间 {|1,g>,|0,e>} 用 H=gσx，g=1。t=0.4 时物质激发的概率 sin²(0.4)=0.1516466453，仍存在光子的概率 cos²(0.4)=0.8483533547；联合激发数始终为 1，光子数本身不守恒。**结论**：在吸收支路中，光子占据数可从 1 变为 0。若主张原光子身份仍持续存在，必须定义其在零光子 Fock 扇区中的可观测表示，不能仅通过普通场激发数描述。
