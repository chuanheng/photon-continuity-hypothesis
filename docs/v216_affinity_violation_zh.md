# v2.16：直接计算违反混合态仿射性

**日期：2026-11-17。科学边界：** 本报告属于有限维单量子比特非线性映射的数学反例审查。它**不是光子场论机制、真实实验或永久光子身份的预测/证据**。统一代码：[模型](../models/identity_nonlinear_v212_v221.py)；[十项测试](../tests/test_identity_nonlinear_v212_v221.py)。本地原始版本使用 Python 标准库、固定随机种子，10 项单元测试全部通过。

取 ρ_A=|+><+|（Bloch (1,0,0)），ρ_B=|0><0|（Bloch (0,0,1)），各以一半混合得 ρ_m 的 Bloch=(0.5,0,0.5)。先混合再调用非线性规则，输出 Bloch=(0.4,0,0.5)；分别调用后再混合，输出=(0.1,0,0.5)。两输出迹距离为 0.15。**解释：** 新规则不满足单一固定 CPTP 通道的凸混合恒等式。这首先是模型物理自洽性的障碍；若当作实验预测，必须说明为何不同的混合操作具有不同物理语义。
