# v2.61：永久个体身份与常规内部自由度的判定

**日期：2026-11-18。研究性质：** 两个相同玻色子的二维内部标签与单量子比特探针的有限维玩具模型；不是完整光子 QED、实际实验、永久个体身份的证据。** 本地 Python/NumPy 实际执行 10/10 单元测试通过。复现：[统一模型](../models/identity_operator_v252_v261.py)、[十项回归测试](../tests/test_identity_operator_v252_v261.py)。参数 θ=0.8，固定 NumPy RNG 种子 20261118。

本批次证明三件严格限定的事实：①完全不耦合的标签在规定操作代数下不可访问；②交换对称的集体内部量可以通过探针产生真实模型概率差；③所有构造与数值都可以被已有的相同玻色子内部自由度及受控探针模型表示。**尚无**跨吸收和再发射持续追踪个体的可测算符、独立场论新耦合、规范与洛伦兹一致性或标准 QED 不可复现的观测预测。因此这是一条“可观测≠永久身份”的正反例组合，不是身份假说的验证。下一研究优先级应是明确微观耦合的实测可行性、物理能量来源和对照实验，而不是仅增加合成计数。
