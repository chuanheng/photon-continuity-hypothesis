# v2.95：可读的标签归入标准内部量模型

**研究日期：2026-11-19。证据等级：** NumPy 有限维量子信息计算与局域 U(1) 规范代数的数值一致性检查。**不是完整 QED、真实实验，亦不是永久光子身份的证明。** 本地原始代码已完成 10/10 自动测试。GitHub 整理版模型：[Python](../models/identity_theory_audit_v292_v301.py)；[测试](../tests/test_identity_theory_audit_v292_v301.py)。

选择交换对称集体内部量 A=(Z₁+Z₂)/2 和二能级探针，受控演化 U=exp(−iθA⊗Y_probe/2)，θ=.8；探针初态 |0>、读出 X+。数值给标签输入 |00>、|11>、对称 (|01>+|10>)/√2 的读出概率分别 0.858678045449761、0.141321954550239、0.5。该相互作用在粒子交换下不变，能读出物理内部量。**但是** 这就是普通集体自旋/内部模式探针：无需持久个体编号即可产生全部概率，不能从“有差异”推导“同一个原始光子一直存在”。
