# v2.96：隐藏标签导致 HOM 概率变化但不能识别其本体

**研究日期：2026-11-19。证据等级：** NumPy 有限维量子信息计算与局域 U(1) 规范代数的数值一致性检查。**不是完整 QED、真实实验，亦不是永久光子身份的证明。** 本地原始代码已完成 10/10 自动测试。GitHub 整理版模型：[Python](../models/identity_theory_audit_v292_v301.py)；[测试](../tests/test_identity_theory_audit_v292_v301.py)。

理想平衡 HOM 双光子干涉中，可见内部模式重叠平方 q=.81、附加标签重叠平方 s=.64，模型预测符合概率 P=(1−qs)/2=.2408。一个完全不含新身份标签的标准量子光学模型，只需令普通内模式有效重叠 q_eff=qs=.5184，得到同样 .2408，差0。**该观测的 profile KL=0**。这里证明的是选定 HOM 读数的严格重参数化，不代表所有新物理不存在。只有额外的身份独有算符或不可由标准内部模式重现的过程，才可能改变判定。
