# v2.99：可以写出规范不变的新作用项，但不包含永久编号

**研究日期：2026-11-19。证据等级：** NumPy 有限维量子信息计算与局域 U(1) 规范代数的数值一致性检查。**不是完整 QED、真实实验，亦不是永久光子身份的证明。** 本地原始代码已完成 10/10 自动测试。GitHub 整理版模型：[Python](../models/identity_theory_audit_v292_v301.py)；[测试](../tests/test_identity_theory_audit_v292_v301.py)。

从 v2.98 的 F_{μν} 出发，若假设存在**新的中性洛伦兹标量场 χ(x)**，局域有效作用项 χ F_{μν}F^{μν}/Λ 可以在 χ 为规范单态时满足电磁 U(1) 规范不变性，且通过标量指标收缩构成洛伦兹标量（更完整理论需确定质量维数、归一化、对称性及动力学）。以数值 χ=.7，施加 A→A+∂α 后 χF² 的变化为0。**这既非永久光子身份理论，也不等于该标量实际存在**：χ 是额外物理场，不是对不可区分光子的个体编号；真正提出新理论还需要哈密顿量、动力学、能量、参数界限、现有实验约束以及与已知标量—光子 EFT 的区别。标准 QED 自身已有 gauge-invariant 的高阶 F⁴ Euler–Heisenberg 项，不可把“能写出规范不变项”当作发现新物理。
