# v3.01：永久光子身份可证伪性阶段性最终判定

**研究日期：2026-11-19。证据等级：** NumPy 有限维量子信息计算与局域 U(1) 规范代数的数值一致性检查。**不是完整 QED、真实实验，亦不是永久光子身份的证明。** 本地原始代码已完成 10/10 自动测试。GitHub 整理版模型：[Python](../models/identity_theory_audit_v292_v301.py)；[测试](../tests/test_identity_theory_audit_v292_v301.py)。

**可严格支持的条件性结论**：在所选可访问操作集合里，若身份标签永不耦合到仪器或其他可达自由度，并且不会通过可见—环境相关性产生后续影响，标签统计上不可观测；若为它增加可见探针相互作用，必须先分析它是否已经是普通内部模式/额外场的标准动力学。在本批次显式模型中，光学 HOM、集体探针和光—物质写读均可由标准量子理论解释；规范场论层面仅做了必要条件的初步检查。**不可声称**已证明一切永久身份理论不可能、全部 QED 实验已覆盖、或新物理被实验证伪。下一步科学决策：要求一条明确的可访问身份独有动力学 + 完整竞争模型；在其出现之前，以“未验证、在所测试操作中不可辨识的假说”为正式论文结论。
