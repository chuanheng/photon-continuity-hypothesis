# v3.12–v3.21 匿名反方审稿意见

**建议：大修后重新评估（Major Revision）。日期：2026-11-20。未经真实同行审稿。**

## 优点
研究已从“任意隐藏参数与合成显著性”转向可访问仪器、操作等价、标准量子光学和系统环境反例，具备可复现的模型计算与公开限制说明。

## 六项必须修订的问题
1. **原创性**：量子仪器CP操作、同约化态在固定通道下的不可辨识、HOM内态重叠、GST规范自由度有已发表文献。未证明条件no-go是独立原创数学定理，标题、摘要应避免暗示普遍新定理。
2. **假设遗漏的危险**：不同初始S–E相关性在共同局域初态I/2下，经E控制S翻转可得到完全正交的输出局域态，迹距离1；必须把反馈排除条件显式放进命题并将反例放入正文。
3. **混用固定CPTP与制备相关通道**：对同输入|+>，恒等与Z完全退相干两组有效通道给出迹距离0.5。这是标准物理，不能先用错误共享通道强行构造身份效应。
4. **HOM假设**：混态公式P_coin=[1−Trρσ]/2仅在理想平衡分束器和独立单光子及未分辨内部态等条件下使用；实际源须额外检查光子数污染、光谱、探测损耗和相关性。
5. **统计归因**：n=200、p0=.095、p1=.2408，阈值≥27、size≈.040273、power≈.999929，但完整标准内模式族包含p1，profile KL=0，不能由对固定错误null的拒绝声称新物理。
6. **物理可测性缺失**：没有定义跨吸收/再发射永久个体的场算符和相互作用，亦未完成规范、洛伦兹、微因果及真实实验验证；理论定位应为方法学审查。

## 建议
要求修订稿清晰区分定理、标准已知知识、数值复现、尚未完成的原创贡献；公布随机种子、测试和统计假设；把不可辨识性严格局限在给定操作集合下。

**投稿状态**：可作为工作论文自公开；尚不足以声称永久光子身份发现，未能判断期刊原创性与接受概率。
