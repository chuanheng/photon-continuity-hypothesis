## 连续运行获得的关键结果

1. v3.72–v3.81：二项极大似然和18格点参数剖面复核提示数值局部极值；仅30次零分布模拟不能正式校准阈值。
2. v3.82–v3.91：在真正普通四态HMM生成的独立留出数据中，一项残差达到约2.84σ。
3. v3.92–v4.01：若考虑训练参数预测不确定度，最大|z|降为约2.24；100次完整重新拟合的粗略最大统计量超越率0.06。**这不是新的永久光子身份信号**。
4. v4.02–v4.11：隐标签“L”和普通持久设备态“C”可由独立计算实现对长度1至6的全部观测产生相同概率，最大数值差约2.2e−16。观测非Markov性只说明低阶简单基准不足。
5. v4.12–v4.21：理论Hankel矩阵的秩为4，五万条合成记录使用武断奇异值阈值却可能把秩错认成8。60次普通HMM噪声重抽样下第五奇异值符合随机扰动。

## 物理审稿判断

本项目到v4.21仍没有跨光—物质吸收再发射的永久个体身份专属可观测算符、规范/洛伦兹/玻色交换一致新动力学或可信真实光学实验。所有本轮数据均可以由普通隐藏环境/仪器状态完整解释。这里的精确等价只覆盖有限经典HMM及明确允许的干预，不是全部QED的普遍no-go定理。
