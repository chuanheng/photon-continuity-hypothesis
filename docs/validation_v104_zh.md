# PCH-A v1.04：严格 SBC 子模型、留出预测检查、重要性采样诊断

**研究性质：所有数据为合成模拟；没有真实光子实验；没有历史个体光子身份的新可检验预测。** 此 GitHub 文档是 v1.04 本地完整研究包 \`photon_v104_complete.zip\` 中报告的对应摘要。

## 1. 审计层次必须分开

上一版 v1.03 的高维 HOM 统计模型同时含 Gaussian 相位随机游走、未知读数超参数、三玻色子Fock分束、PNR误分类、探测器效率/暗计数、线上电子学背景。由于尚未对整个物理/仪器模型建立与推断完全一致的**联合先验生成器**，不能把固定M0的经验覆盖或权重ESS误称为完整 simulation-based calibration（SBC）。

本轮分三个子任务：
- **正式 SBC**：对有完全指定先验的*一维HOM近延迟子模型*，从同一先验抽取真值并检验后验抽样秩。验证范围严格限于子模型。
- **留出预测检查**：使用未参与拟合的零相位标准传感器读数，检验尾部异常。属于复杂模型的局部模型失配审计，但不是整个推断的SBC。
- **重要性提议尺度敏感性**：固定真实M0=.72，比较v1.03的Hessian-Gaussian proposal尺度与ESS、估计/区间表现。属于数值灵敏度分析，不是先验预测SBC。

## 2. 子模型 SBC：450轮

明确的生成/推断模型：
\[
M\sim\mathrm{Uniform}(0,1),\quad
k\mid M\sim\mathrm{Binom}(280,0.25-0.17(0.76)M).
\]
801点网格配合梯形端点权重计算归一化一维后验。每轮先从**同一**先验独立模拟M、k，再独立抽取49个后验M，计算秩 \(r=\sum_{j=1}^{49}\mathbf1[M_j^{post}<M^{true}]\)。

实际450轮结果：
- 十个等宽rank分箱 **[59,35,47,49,43,37,36,54,47,43]**，理论各45；
- χ²(9)=**12.3111**，均匀性检验 p=**0.19633**，未观察到统计显著偏离，**不能据此证明显然完全均匀**；
- 贝叶斯等尾95%可信区间的经验覆盖为 **430/450=95.56%**；精确二项95%不确定区间约 **[93.22%,97.26%]**。

## 3. 留出PPC：受控模型失配

每组传感器零标准100次，使用前70次参与高斯相位超参数拟合，保留后30次，检测后验加权的超出3σ的标准化尾部计数，并用160组后验预测复制形成诊断概率。

- 正确高斯留出集75组：异常阈值 \(\mathrm{PPC}\le.05\) 触发 **6/75=8%**。
- **刻意仅污染留出集**：9%的留出读数附加标准差.85的离群分量，75组中触发 **51/75=68%**。
- 正确高斯平均观察尾数.1281，预测平均.0843；污染留出平均观察1.5701，而预测平均仍.0843。

该构造专门测试分布移位，**没有**在训练数据内加入同样的异常，因此不能把68%当作一般非高斯传感器的检测率。后验预测概率也并不自动具备传统频率学p值的严格均匀性质。

## 4. 重要性采样尺度：配对32组

每组复用相同光学物理合成数据，超参数候选数90，比较不同Hessian Gaussian提议尺度：

| 提议标准差尺度 | 超参数ESS中位 | ESS最小值 | M0后验均值 | RMSE |95%区间覆盖 | 平均区间宽 |
|---:|---:|---:|---:|---:|---:|---:|
| .8 |64.54|25.35|.71729|.01704|31/32|.07456|
| 1.4|59.17|52.42|.71707|.01734|31/32|.07600|
| 2.2|19.86|14.39|.71733|.01798|31/32|.07646|

对尺度.8与2.2，平均点估计绝对差约.00289。ESS降低表明候选权重集中，不能仅因这32组M0均值相近就保证复杂尾部概率稳定。此部分与正式SBC是**不同实验**。

## 5. 与光子连续性假说的关系

SBC验证数值推断实现，PPC验证有限数据层面的模型失配，ESS审计计算效率，**三者均不提供新QED动力学**，也没有证明跨吸收/再发射可测的“原始光子历史个体身份”。如果身份标签仍然只通过总HOM模式重叠影响计数，则普通混合模式及仪器模型仍可重现这一可观测量。

## 6. 下一轮 v1.05

为含PNR/探测器参数的完整模型定义与后验推断一致的联合先验生成机制，实施多参数SBC（M0、相位噪声、PNR混淆）；在**训练/测试数据都存在异常**时比较Gaussian、Student-t/混合传感器模型的留出预测评分和覆盖率。当前不应宣称完成这些任务。
