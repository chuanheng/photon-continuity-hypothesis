# v0.48：联合校准泊松模型的参数自举、功效与失配

## 范围与解释

本版本是**标准统计 toy model**，不是从“光子永久身份/连续存在”假说推导出的物理定律，也不构成该假说的实验证据。模型只回答：若预先给定一个额外信号模板，带效率和背景校准计数的泊松实验可有多大统计功效、校准错配会怎样影响结果。`h` 尚非光子连续存在假说的独立可观测预测；要检验该假说，仍需先给出机制、量纲、信号模板和可证伪预测。

指定的 `/mnt/data/photon_v047/models/joint_calibration.py` 在当前环境不存在，工作目录亦未包含 v0.47 文件。因此本实现根据引用对话中公布的接口结构独立重建，不能保证与不可访问源码的 API 完全兼容。仅使用 Python 标准库；参数估计采用多起点、约束坐标搜索，适合这里低维演示，不是通用高精度优化器。

## 模型

主实验分箱计数独立满足

\[n_i\sim\mathrm{Poisson}\{t(\eta s_i+\beta b_i+\epsilon h_i)\}.\]

两个独立校准计数满足 `C_eta ~ Poisson(k_eta eta)`、`C_beta ~ Poisson(k_beta beta)`。检验 `H0: epsilon=0` 对 `H1: epsilon>=0`，统计量为联合似然比 `q=max(0, 2(logL1-logL0))`。η、β、ε 都约束为非负。零假设下参数在边界，故不直接套用普通 χ² 阈值。

基准模板为 `s=(10,8,6,4), b=(1,1,1,1), h=(0,0,3,0)`；η=β=1，ε=1 是功效评估效应；主曝光 `t=1`，校准尺度 `k_eta=k_beta=100`。比较方案分别把主实验曝光提高至 3、或把两种独立校准尺度提高至 300。

## 自举设计与可复现性

每种场景做 199 次零假设拟合、199 次备择假设拟合。以零假设自举 q 分布的经验上尾 5% 阈值（保守秩、严格大于阈值拒绝）评估误报率和功效；每一个重复数据集都重新拟合 H0 与 H1。随机种子分别为 `20261112`、`20261113`、`20261114`、`20261115`。区间为二项比例的 95% Wilson 区间。每场景 199 次对应的蒙特卡洛标准误上限约 3.5 个百分点，因此小差别不应过度解读。

## 实际运行结果

| 场景 | q 阈值 | 误报率（95% MC 区间） | 功效（95% MC 区间） |
|---|---:|---:|---:|
| 基准：t=1, k=100 | 3.280 | 4.5%（2.4–8.4%） | 18.6%（13.8–24.6%） |
| 主实验曝光×3 | 2.621 | 4.5%（2.4–8.4%） | 58.3%（51.3–64.9%） |
| 校准数据×3 | 2.995 | 4.5%（2.4–8.4%） | 24.1%（18.7–30.5%） |
| 校准效率均值低估5% | 2.222（按无偏零假设校准） | 6.0%（3.5–10.2%） | 32.7%（26.5–39.5%）* |

* 最后一行的备择功效在同一有偏校准生成机制下测得，仍使用无偏零假设的阈值。误报率基准因此反映校准模型失配下的假阳性风险，而非重新校准后的名义误报率。

该例下增加主实验曝光比单纯增加校准数据更有效，但二者都未将功效推至 80%；这只是该特定信号模板、背景、曝光与校准尺度的比较，不能外推为普遍实验建议。低估效率校准均值 5% 后误报率从 4.5% 到 6.0%，区间较宽且高度重叠，说明 199 次不足以精确测量小幅膨胀；需要更大模拟规模及系统偏差扫描，不能把该点估计当作稳定效应量。

## 边界和不可辨识性

- ε=0 是边界；似然比 q 非负，有限样本分布由参数自举估计。
- 若 `h=c*s`，主实验仅识别 `eta+c*epsilon`。没有效率校准时 ε 与 η 不可分别识别；测试验证这一情形下 H0/H1 的最大似然相同。有效校准可提供约束，但校准失配会重新造成偏差。
- 若 `h` 与 `b` 共线，ε 和背景幅度 β 也可能不可辨识或弱可辨识。应检查模板矩阵秩、轮廓似然和优化稳定性；本示例没有自动给出完整秩诊断。
- 零曝光/零校准在概率计算上可处理，但会失去相应参数信息。零均值对应正计数的似然为零。模板、曝光、参数的负值和非有限值会被拒绝。
- 坐标搜索结果依赖起点和步长终止条件；应用于真实数据前应与独立优化器、梯度/轮廓分析及覆盖率模拟交叉验证。

## 测试与复现

模型：`models/joint_calibration.py`；35 项单元测试：`tests/test_joint_calibration.py`；模拟脚本：`run_simulation.py`。运行：

```bash
python3 -m unittest discover -s photon_v048/tests -v
PYTHONPATH=photon_v048 python3 photon_v048/run_simulation.py
```

在当前环境实际执行的测试为 **35/35 通过**。模拟规模为每场景 199+199，耗时约 11 秒。以上测试与数值结果只验证此 toy model 的代码行为，不验证任何新物理主张。
