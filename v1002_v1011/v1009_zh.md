# v10.09　区组化强度扫描怎样与普通材料漂移混淆

设备有低、高效率 .12 与 .30。强度随机交错且不泄漏时，各格拥有相同 80/20 混合，单光子响应亦按此混合；若按区组分配，弱探针全遇高效率、强探针全遇低效率。对两组表分别做同一解析处理。

**实际数值**　运行 `python -m v1002_v1011.model` 查看字段 `block_drift`：`{"randomized_lower": 0.15032805667902516, "pooled_y1": 0.157688, "blocked_lower": 0.38530490056929867}`。

**检验及边界**　区组选择能使表观下界高于任何一个真实效率对应的 Y₁。可按时间分层和随机交换强弱脉冲位置检验。长寿命材料记忆若响应于当次控制，仍需独立测量。

上述数值是合成验证。已知理论与文献见[批次索引](README.md)。
