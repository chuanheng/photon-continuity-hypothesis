# v10.16　交叉扫描与对角扫描分别留下多大简并

先只给强度 0,.08,.35 的对角格，再给 0,.035,.15,.5 的全 16 格。分别对同一个真实 Y₁₁=.122 的合成源做剖面；结果表示两个具体设计的实得区间。

**实际数值**　运行 `python -m v1012_v1021.model` 查看字段 `rectangular_scan`：`{"diagonal": [0.0, 0.1884285423333786], "rich": [0.12179836442631141, 0.12206700220395406]}`。

**检验及边界**　这两个设计的格数和强度都不同，数值差不能单独归因于多出交叉格。v10.13 的零方向严格说明独立调节两端的价值。用相同光子预算比较效率尚未完成。
