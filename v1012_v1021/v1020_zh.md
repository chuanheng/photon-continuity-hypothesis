# v10.20　标称强度与入射损失能否由全部强度扫描同时定标

若实际入场强度为 tμ、材料或探测激活系数 η，则相干扫描只含乘积 tη。两种组合 (.8,.6) 与 (.96,.5) 使任意标称强度的完整增益相同。按入射面光子数定义，Y₁₁ 则随 η 改变，固定另一臂 .4。

**实际数值**　运行 `python -m v1012_v1021.model` 查看字段 `attenuation_gauge`：`{"effective": 0.48, "alternative": 0.48, "one_photon_yields": [0.122, 0.10200000000000001]}`。

**检验及边界**　这是一族结构简并，增加相同类型的扫描点无效。需要在同一参考面引入独立的绝对效率或光子数标定。此处没有原装置的绝对标定数据。

上述数值是合成验证。已知理论与文献见[批次索引](README.md)。
