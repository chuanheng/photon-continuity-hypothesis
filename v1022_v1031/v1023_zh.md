# v10.23　阈值探测下如何修正泊松多对误差

**假设与推导**　若对数 N 服从泊松分布，三项无击负对数为 x=ma、y=mb、z=m(a+b−ab)。故 c=x+y−z=mab，a=c/y、b=c/x、m=xy/c。原始条件比包含跨对巧合。

**合成验证**　运行 `python -m v1022_v1031.model`，字段 `multipair` 的结果为 `{"naive": 0.5822418221472301, "corrected": [0.5499999999999998, 0.48000000000000026, 0.35000000000000003]}`。

**适用边界与检验**　m=.55 时简单条件比明显偏高。校正需要给定光子数的线性损耗与已确认的对数分布；以分光后独立计数或泵功率留出测量检验。
