# v10.54　两个监测器共用同一非材料态，能否再缩紧界

**假设与推导**　非材料块为普通量子比特，两个效应分别是 .32I+.18σₓ 与 .32I+.18σ_z。因此两个非材料均值位于圆盘而非独立区间。观测向量 p 必须满足 ‖p−xb−(1−x)a‖≤(1−x)r。在 [0,1] 上求二次不等式的根并验证端点由单位 Bloch 向量达到。

**合成验证**　运行 `python -m v1052_v1061.model`，字段 `joint` 的结果为 `{"interval": [0.4254938670109751, 0.6500000000000001], "intersection": [0.3980000000000007, 0.6747058823529412]}`。

**适用边界与检验**　得到的紧区间比逐监测器区间之交更窄。紧性依赖同一制备、校准测量轴及量子比特块假设；随机交错监测可减小漂移，增加第三方向可检验块模型。开发阶段首组数据的下根为负，修正程序显式裁至物理区间，再用两根皆在内部的样本检验饱和。
