# v10.55　相位踢动偏离 π 时，双模反演的最坏误差有多大

**假设与推导**　理想等权 I 与 π+δ 两组的平均非对角系数模为 abs(sin(δ/2))。双模效应的非对角元 c=.08，对角响应差 .32，任意密度矩阵满足 2abs(ρ₀₁)≤1。用理想对角公式反演 x 的全局绝对偏差至多 abs(c sin(δ/2))/.32，等幅纯态选取适当相位可达。

**合成验证**　运行 `python -m v1052_v1061.model`，字段 `angle_error` 的结果为 `{"residual": 0.0599640064794446, "worst_population_bias": 0.014991001619861149}`。

**适用边界与检验**　δ=.12 rad 时最坏偏差接近 .015；这是假设驱动仅加相位后的界。若相位误差与输入态相关，或脉冲混入其它模式，须重新建模。
