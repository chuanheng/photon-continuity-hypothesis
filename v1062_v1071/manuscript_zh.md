# 修订稿

普通两模量子存储在三组独立时点测量给 K=1.5；每个末端边缘仍为 1/2，但插入中间仪器会使首末联合表改变，总变差距离 .375。六个普通非侵入路径加结果筛选可在相同 8/9 接受率下重拟合所有三对记录。若允许包含上下文的污染试次且等比例混入，所需最小比例为 .25。

每组接受率相同、每个边缘不变均不足以验证非侵入操作。标定脉冲、共同漂移、读出串扰、材料记忆和选样都会改变联合表。本轮没有排除标准量子光学，也没有跨吸收身份的新预言。有限非侵入模型和完整普通物理族的结论应分别报告。

时序非侵入界和无信号条件核对 [Clemente 与 Kofler](https://doi.org/10.1103/PhysRevA.91.062103) 及 [Kofler 与 Brukner](https://doi.org/10.1103/PhysRevA.87.052115)。各数值均由本批模型生成。
