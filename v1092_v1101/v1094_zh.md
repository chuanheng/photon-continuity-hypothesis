# v10.94　非正交侧记录将确定性恢复限制在什么水平

**假设与推导**　考虑等先验二元随机 I/Z 错误，另给恢复器一份由该经典错误选择的纯标记，标记内积 .6。限制为先测标记、再依结果作量子反馈。上轮的最大后验界把最优纠缠保真度化为最小错误判别成功率，即 (1+√(1−s²))/2。

**数值复现**　运行 `python -m v1092_v1101.model`，字段 `imperfect_marker` 为 `{"overlap": 0.6, "optimal_Fe": 0.9}`。

**适用边界与可证伪条件**　得到 .9。须有独立经典随机选择或不可访问的纯化；本例没有把非正交向量直接当成经典互斥标志。相干接入错误生成器时操作集不同。
