# v10.96　两次读标一致是否能防止误反馈

**假设与推导**　假设原误差在一个时钟中确定，两次二值读标均有误率 e=.15，仅在报告相同时接受。独立读错时两次错质量 e²、接受率 (1−e)²+e²；若两个读头共享同一错误位，则一致率为一、条件误率仍为 e。

**数值复现**　运行 `python -m v1092_v1101.model`，字段 `repeat_read` 为 `{"both_wrong_independent": 0.0225, "both_wrong_shared": 0.15, "accepted_independent": 0.7449999999999999, "conditional_independent": 0.0302013422818792}`。

**适用边界与可证伪条件**　单读头准确率相同而双读后的风险相差近五倍。以同步注入的已知标签记录四格，检验串扰、共同环境和慢漂移，不能把重复次数本身当独立样本。
