# 内部反方审稿

1. v11.35 的全事件构造在局域粒子数旗标无误且测量按扇区分块时成立。设置依赖漏检或旗标串扰会重开 detection loophole，必须用全点击表而非条件符合表检验。
2. v11.36 的标度需要可区分、相位相干的多个时隙。它复现已知超选规则下的资源激活，未引入跨吸收身份算符。
3. v11.37–v11.39 只覆盖独立损失、二元误翻和单高斯漂移。材料的非马尔可夫相干、相关暗计数、谱依赖串扰和参考失配会扩大普通模型族。
4. v11.40 已给出直接反例：ABBA 只消常数和线性漂移，普通二次项精确重拟合候选列。没有同步参考约束时，候选不可辨识。
5. v11.41 排除了一个按形式粒子槽编号的耦合，不是对所有可能新物理的普适排除。反过来，任何新耦合都需给出交换对称、局域和守恒的作用量；当前假说仍缺这一要件。

可推翻本批结论的条件包括发现报告中的矩阵或熵恒等式错误，或给出满足上述一致性条件且其可观测分布与完整普通对照族严格分离的身份耦合。本批没有真实数据或同行评审。
