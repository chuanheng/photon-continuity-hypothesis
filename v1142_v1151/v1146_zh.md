# v11.46　系统因果切断勘误

原记录把系统重制备直接赋值为两步自由演化，撤回原差值 0.337602 作为因果切断见证。令两比特初态均为 +X，作用 exp(−iθ Z⊗Z)，无条件丢弃系统后制备 +X，则第二步之前的联合态为 Tr_S(ρ_ES)⊗|+⟩⟨+|。环境 Z 布居仍各半，一步后的系统 X 均值为 cos(2θ)。同时刷新环境得到相同均值。θ=.31 时二者均为 .81387846。无系统重制备的两步连续作用才给 cos(4θ)，仅在中途刷新环境则给 cos²(2θ)。

实验上可在相同脉冲时序中插入重制备并读出 X；保留第一次测量结果、条件化后续统计是另一项操作。结论限于所列静态耦合和无条件边缘。依据 Pollock 等，PRL 120, 040405，https://doi.org/10.1103/PhysRevLett.120.040405 。仅有模型验证。
