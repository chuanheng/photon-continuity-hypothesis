# v11.68　倾斜双阱中用能量补偿解离

设两站单粒子能差 Δ。双占据初态与分离构型相差 U+Δ；把 Δ 从 0 调为 −U，在同一个 t=.9 探测解离。另一双占据能量为 U−Δ，全三态计算保留它。

从仓库根运行 `python -m v1162_v1171.model`，输出字段 `tilt_resonance` 为 `[0.05973065951197971, 0.9039826187216736]`。

能级交叉给出普通材料共振。利用独立差频标准和两种初始双占据逐侧互换；若共振随探针强度移动，应纳入光移。

证据为条件推导和合成计算。文献、普通模型和输入见[批次索引](README.md)。
