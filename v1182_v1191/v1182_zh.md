# v11.82　可由单个分束器制备的定向参考

从同一输入端注入双占据，两次创建算符经平衡分束变为相同 + 模的双光子。三种输出振幅为 (1/2,1/√2,1/2)。在已标定角 .33 分析器上，φ=0 或 π 的左聚束率为 [(1±sin .66)/2]²。

从仓库根运行 `python -m v1182_v1191.model`，输出字段 `reachable` 为 `[0.6505364945301705, 0.03741964255673651]`。

需要知道制备器相对分析器的端口相位。两者若共同翻转仍属不可辨识；此设计不需要上一批的非平凡目标态制备。

证据为条件推导和合成计算。文献、普通模型和输入见[批次索引](README.md)。
