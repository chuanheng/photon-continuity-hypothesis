# v11.84　不同谱态的对称输入为何无法定向

把两光子分别输入正交的 +、− 超模，纯谱态重叠为 .7。同一端口的两条交换路径干涉后聚束率为 (1+0.7²)q(1−q)，q 是 + 模单粒子左端概率。镜像使 q 与 1−q 互换。

从仓库根运行 `python -m v1182_v1191.model`，输出字段 `orthogonal_ports` 为 `[0.23247267787025447, 0.23247267787025447]`。

即使独立 HOM 测准谱重叠也无法赋予这种对称参考方向性。换用上一轮同端输入可破除该特定简并。假设空间变换无频率色散。

证据为条件推导和合成计算。文献、普通模型和输入见[批次索引](README.md)。
