## 核心成果

系统环境E_t∈{0,1}、初始P(E=1)=r=.2；每次观测Y_t=E_t XOR Bernoulli(ε=.1)。两次之间以κ概率重新抽取E，否则继续沿用同一环境状态。单时P(Y=1)=.26；二时读数不一致概率D(κ)=.18+.2048κ。κ=0、.5、1时分别为.18、.2824、.3848。

κ=.5的模型二时分布可被普通HMM完全重现，完整标准模型族中的profile KL为0。错误地固定标准模型κ=1会得到KL=.03313134936，但不能证明新身份机制。

NumPy seed=20261121，10000次二时合成测量计数依次 [6000,1451,1376,1173]，估计κ=.5146484375，在r与ε**已知**前提下理论Fisher SE=.01983023523。若误把读出错误率设为.12，估计变为.53129328255。用普通两态HMM可进一步严格生成三时概率，全部概率归一化。

## 科学判定

多时间测量证明普通环境记忆可被检测，却**无法从输出概率独有地确定记忆载体**。未得到支持永久光子身份的独有可测规律、完整光子QED新动力学或真实数据。研究结论是特定模型与操作下的可辨识性限制，并非全局不可能性定理。
