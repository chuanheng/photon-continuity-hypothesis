# v3.32–v3.41 内部反方审稿意见

**2026-11-21；建议：继续作为方法学/否定性工作论文，不宜宣称新物理发现。**

本批次的优点是使用透明的标准隐藏马尔可夫环境建立完整联合概率、精确KL与Fisher分析，避免仅从单时实验猜测多时间动力学。主要问题和审稿要求：

1. 切勿混淆“能检出环境记忆”与“能唯一确定记忆位于某个光子个体”。普通物质态、源漂移、相关探测器噪声都可产生等价统计。
2. κ估计建立在r、ε已知假设下；真实装置的独立标定、时间漂移及置信区间传播仍未实现。
3. 本批次的HMM属于经典对角子理论，不能从其等价性推导整个量子过程张量或完整QED的普遍不可辨识性。
4. 必须公平使用允许环境记忆的标准族。仅与κ=0或κ=1两个固定弱基准比出正KL，并不能推翻标准量子模型。
5. 更有价值的后续研究是具有明确实验控制的干预序列：选择性重置材料环境、切换光源、单独替换探测器读出链，再比较受约束的多时间量子仪器。
6. 暂无跨吸收和再发射保持身份的可测算符、交换统计与相对论场论的一致动力学，也没有真实数据。原创性未获独立同行评价。

**审稿判断：** 当前模型可以作为“误把普通记忆当作粒子永久身份”的反例教学或方法学组件，不能称为永久光子身份的新验证。
