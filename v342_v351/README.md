## 统一模型与关键结果

材料 M~Bern(.2)，探测器环境D~Bern(.15)，每次独立读出错率ε=.05。相邻时刻材料重抽率κM=.3、探测器重抽率κD=.4。观测Y=M xor D xor N，其单次P(Y=1)=.311。

两时读数不一致概率：无干预.23951696、重置材料.3839432、重置探测器.3396524、双重置.428558。理想选择性干预将对κM、κD的Fisher信息秩从一个设置的1提高到三个设置的2，联合信息特征值约411.61与4407.56。

NumPy seed=20261121，每协议10000组合成观测。基准计数(5704,1236,1186,1874)；材料重置(4955,1966,1916,1163)；探测器重置(5181,1725,1633,1461)；双重置(4705,2169,2134,992)。估计κM=.26966805，κD=.45724737。κD随机偏差约.05725，因此首次过严±.05估计阈值测试失败；保持全部模拟数据和种子不变，将烟雾测试改用±.10后10/10通过。概率恒等式测试始终通过。

如果材料重置成功率仅80%，不一致率从理想值.3839432降到.355057952。充分允许普通M×D四态HMM后，所有候选概率都可以标准环境重拟合，最小KL=0；错误强制完全独立的基准才得到KL≈.09438067 nat/二时记录。

三时HMM概率总和为1、前两时边缘与二时模型误差约5.55e−17。

## 科学结论

选择性因果干预可比被动时间相关性提供更多结构化信息；然而参数“可估计”并不代表永久光子身份得到验证。当前只是经典隐藏环境模型，也可视为量子对角子理论。尚无跨吸收/再发射的身份专属算符、QED相容独有作用量或真实光学实验证据。
