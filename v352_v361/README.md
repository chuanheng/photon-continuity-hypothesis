## 统一五参数模型

材料M与探测器D平稳1概率分别rM=.2、rD=.15；原刷新率κM=.30、κD=.40；观测Y=M XOR D XOR N，N~Bernoulli(ε=.05)。复位成功率u=.85、非目标载体串扰额外刷新率c=.12，五未知(κM,κD,u,c,ε)。

四组协议的二时不一致概率为：无干预 **.23951696**、只复位材料 **.36863241152**、只复位探测器 **.33630012752**、双重置 **.40996591556864**。理想材料复位无串扰时对应概率 **.3839432**；材料复位时探测器有效刷新率由.4变成.472。

四组观测对五未知的Fisher秩为4；另外加上真正独立的探测错误率参考，局部秩为5（Jacobian行列式≈−.00018313）。**满秩不代表有限样本可信。**

用NumPy seed=20261121，五通道每组10000次，合成计数[2385,3754,3376,4085,527]；点估计(.180425,.512139,.810219,.246081,.0527)，与真实(.3,.4,.85,.12,.05)存在显著统计偏差。300组模拟的名义95%区间覆盖率约[89.33%,90.67%,94%,93.67%,94.67%]；故局部 Fisher 正态区间并不总是可靠。

错误固定u=1,c=0时概率L2残差约.0229239；真实主实验ε=.07但过时独立参考固定ε=.05时，普通参数拟合受到明显污染。完整普通4态HMM与候选完全同分布，profile KL=0。
