# v3.52–v3.61 内部反方审稿报告

**2026-11-21；模拟审稿建议：Major revision。此报告不是期刊或独立同行评审。**

1. 本研究的贡献是对常规环境记忆的实验设计与参数识别审计，并非新光子身份理论。必须在题目与摘要中避免“永久身份获证实”的表述。
2. 仅凭四协议数值的Fisher秩为4，加入理想独立ε参考后秩5；实际装置能否拥有真正独立且可共享的参考，需要实验验证。
3. 300次Monte Carlo中，κM和κD的名义95%区间覆盖低至89%–91%，需使用profile likelihood、bootstrap、边界约束下的可靠区间，并对多种真参数做覆盖检验。
4. 错误地假设完美复位和无串扰会造成约.0229的概率残差。应先排除一般普通器件误差后再对新理论模型作任何比较。
5. 探测器错误率主实验.07而参考仍.05时，估计明显偏差。交错标定、复位效率、交叉串扰和漂移应共同进入实验设计。
6. 全部数值在一个普通四态HMM中精确实现。没有真实数据、独有光子身份观测或完整QED新作用量。不能声称排除全部可能新物理；也不能将合成结果当做真实光学实验。
