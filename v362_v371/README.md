## 统一模型与研究结果

五未知参数(κM,κD,u,c,ε)的真值(.30,.40,.85,.12,.05)，四个干预协议加独立探测错误率参考，每通道10000次。

- 只有四组主实验时Jacobian秩4；增加独立参考后满秩5，但Fisher条件数约**6970.8**。
- 真值处的Fisher局部标准误依次是(.064624,.077459,.052436,.109678,.002179)。
- seed=20261121，观测合成计数[2385,3754,3376,4085,527]；约束加权最小二乘估计约(.180425,.512139,.810219,.246081,.0527)。
- 180次重复模拟的名义95%固定Fisher正态区间经验覆盖率依次为[90%,92.22%,95.56%,94.44%,95.56%]。**不是所有参数都达到标称95%**。
- 基于这一单份样本估计的180份参数Bootstrap百分位区间依次为κM[.001,.3204]、κD[.3519,.7051]、u[.7237,.9026]、c[.04665,.42611]、ε[.04852,.05746]。κM触及人为参数下边界，未验证区间实际覆盖率。
- 以κM为目标的33点**近似WLS轮廓**，粗网格阈值区间约[.08,.32]，左端受扫描网格约束。它既不是全局精确二项MLE轮廓，也没有得到可信的覆盖率校准。
- 若主实验真实ε=.07但参考停留在.05，偏差拟合使κM变为.3784等；是普通标定失效而非粒子身份发现。
- 所有概率可由原标准四态HMM精确复现，最小KL=0。

## 物理与方法学结论

估计方法改变的是对已定义参数的**不确定度表述**，不会把一个与标准量子环境模型完全等价的机制变成永久光子身份的独有新物理。当前没有跨吸收/再发射的个体身份测量定义、规范/洛伦兹一致新作用量或真实实验。
