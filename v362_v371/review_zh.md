# v3.62–v3.71 模拟反方审稿意见

**日期2026-11-21；建议Major Revision。该报告由项目内部生成，不是真实同行或期刊审稿。**

本轮有明确的研究方法价值：对比相同合成模型上的Fisher局部区间、实际经验覆盖、参数Bootstrap和近似轮廓，公开条件数与参数下界问题。需要重点修正：

1. 不能把“5/5 Fisher满秩”写成有限样本区间已可靠。材料κM在180份重复样本中的正态区间只覆盖90%。
2. Bootstrap百分位区间基于单个点估计再采样180次，未检查其在各种真值下的实际覆盖率；κM触及.001拟合边界应有边界敏感性分析。
3. 轮廓不是精确的二项MLE profile：外层计算似然、内层仍用WLS拟合。不能以其格点CI直接做正式95%统计主张。未来应真正优化二项似然、扩大扫描区间、多起点优化、用参数Bootstrap校准似然比阈值。
4. 必须报告独立参考与主实验读出噪声是否同质、是否存在漂移以及控制设备串扰。
5. 对完整普通四态HMM，最小KL严格为0。多种统计工具都无法把隐藏环境机制重新命名成新的永久光子身份实证。
6. 没有真实光学实验、规范/洛伦兹一致的永久身份场论或独有跨吸收再发射预测；不宜提交为新物理发现论文。

对照：[Gate Set Tomography 2021](https://quantum-journal.org/papers/q-2021-10-05-557/)；[非线性有限样本LRT研究2023](https://doi.org/10.1371/journal.pcbi.1011417)。
