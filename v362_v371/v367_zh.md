# v3.67：近似轮廓似然的范围与限制

**日期：2026-11-21。** 研究性质：普通四态隐藏马尔可夫环境的合成统计估计，不是真实光子实验，也不是光子永久个体身份或完整 QED 新动力学的证据。固定参数真值 (κM,κD,u,c,ε)=(.30,.40,.85,.12,.05)，每通道 n=10000；随机种子 20261121。本文中的区间是模型内有限样本估计，所有负结果均限定于所测试操作和模型。参考：[Nielsen et al., Gate Set Tomography (2021)](https://quantum-journal.org/papers/q-2021-10-05-557/)；[有限样本轮廓似然统计研究 (2023)](https://doi.org/10.1371/journal.pcbi.1011417)；[Pollock et al., Operational Markov condition (2018)](https://pubmed.ncbi.nlm.nih.gov/29437441/)。

## 设定、计算与解释

固定κM为网格 .08 至 .72（共33点），其余四参数在各网格点重新拟合，再计算二项似然的差异。采用加权最小二乘得到各点的参数优化结果，因此该曲线严格来说是**基于WLS解的近似似然轮廓**，而非对二项对数似然完成全局极值搜索的精确profile LRT。以渐近χ²_1 95%阈值3.84146做探索性截断，粗网格区间约[.08,.32]；左端是人为设置的网格下限而非物理下界。鉴于小样本和接近参数边界的情况，本研究**不声称该区间已有正确覆盖率**。

## 判定范围

所有推断仅与本次合成的普通隐藏环境模型相容，不能作为真实永久光子身份的实验发现。
