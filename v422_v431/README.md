# v4.22–v4.31 受控等价、独立标定与标准量子反例

本批完成十个独立问题。证据覆盖受限数学证明、有限维标准理论演算和合成模拟，无真实光学实验数据。

| 版本 | 报告 | 主要结果 |
|---|---|---|
| v4.22 | [受控等价](v422_zh.md) | 可达空间给出任意长度的等价证书；改变普通设备重置语义后出现两步见证 |
| v4.23 | [整数/有理秩证书](v423_zh.md) | 受控与被动词表深度 2 均见证精确秩 4 |
| v4.24 | [非负实现](v424_zh.md) | 同为秩 3 的制备—读出块分别需要 3 与 4 个普通状态 |
| v4.25 | [独立标定与漂移](v425_zh.md) | 联合参考界可证，漏标定普通载体破坏主包络 |
| v4.26 | [普通量子存储](v426_zh.md) | 单量子位可超越单经典位上界，两经典位可重建同一统计 |
| v4.27 | [全局 KL](v427_zh.md) | 受限最小边缘 KL 为 0.00105794 nats，解除串扰约束后为零 |
| v4.28 | [有限样本与后选择](v428_zh.md) | 给出复合族内 5% 误报上界和合成操作特性 |
| v4.29 | [曝光分配](v429_zh.md) | 指定扰动下模拟功效由 67.775% 提至 75.075% |
| v4.30 | [候选色散耦合](v430_zh.md) | 普通条件失谐混合重建完整光—物质约化态 |
| v4.31 | [合成盲标判据](v431_zh.md) | 强分离及漏测普通漂移在同一规则下均可触发拒绝 |
