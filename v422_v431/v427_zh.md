# v4.27 复合普通模型的全局 KL 证书及零距离重拟合

**证据类型：条件性数学最优值和数值核查。**

**假设。** 采用 v4.25 模型与事先给定的理想参考盒 d∈[.18,.22]、u∈[.75,.85]、c∈[.06,.10]、m∈[.20,.40]，以及 |e|≤.006。合成候选固定为 (q_A,q_B)=(.54,.58)。目标函数是两个 Bernoulli 边缘 KL 的等权平均，适用于边缘协议比较。同一条记录的嵌套事件应使用联合多项式似然。

**推导。** a 在 [.0162,.044]；(q_A,q_B) 同时达到各自上界 (.528,.55)。当 p>q 时，Bernoulli KL 对 q 的导数为 (q−p)/(q(1−q))<0，所以该角点全局最小，证书不依赖数值优化初值。重叠记录的联合 KL 至少为任一边缘 KL，由数据处理得到，但这不是联合 KL 的精确值。

**复现与反例。** 最优边缘 KL 为 0.000289193953 和 0.001826692658 nats，平均为 0.001057943305 nats。若 c 不受独立参考约束，在 (d,u,c,m)=(.20,.80,.34,.30)、e=0 时，a=.08，两个概率以及嵌套事件的联合分布都可精确匹配。浮点残差约 1.11×10⁻¹⁶。

**可检验预测与局限。** 如果这些独立盒和漂移上限确有物理支持，两个边缘概率超界应排除该受限普通模型。本例的盒、候选概率都为合成设定。尚无身份动力学推出这两个概率，放开一个未经独立物理验证的限制就会恢复等价。
