# v4.30 光—物质交换的色散身份耦合反例

**证据类型：限制性量子推导与有限截断数值实验。**

**候选与假设。** 单腔模与两能级物质做共振交换，另有持久二值变量 C。取 ħ=1，尝试局域装置模型 H=ωN+g(aσ₊+a†σ₋)+χa†aZ_C。假定制备时装置变量与光—物质系统乘积，控制和读出对 C 不寻址。参数 ω=2、g=.42、χ=.17。C 的初态含非零相干项。

**推导。** [H,N]=0；H 对 C 的 Z 块对角。偏迹 C 后，光—物质通道严格为两路普通条件失谐演化的凸组合，权重只依赖 C 的 Z 布居。在 photon→matter→photon 交换中，可观测相干与布居都由标准普通设备位复制。普通色散频移是该候选的公平对照。

**复现。** `optics.dispersive_identity_audit()` 在 81 个时点对照完整密度矩阵和普通失谐混合。单激发子空间完整约化态最大误差 6.68×10⁻¹⁶，能量误差 6.22×10⁻¹⁵，光模占据最低约 0.03974。零、一、二激发截断下数值对易子为零。光模 Fock 描述满足其玻色占据表示；没有加入可观测的粒子槽位编号。

**反方审查。** 共同固定幺正与偏迹给出 CPTP 局部通道，标准操作下无信号。模型只定义腔的有效耦合和时间演化，激发数的全局 U(1) 对称不提供局域电磁规范不变性的证明。它没有给出协变作用量、空间局域交换、相对论能动量或微因果检验。该候选已因普通设备精确重拟合而失去身份独有性，不能升级为场论结论。

参考 [Blais 等，Rev. Mod. Phys. 93, 025005 (2021)](https://doi.org/10.1103/RevModPhys.93.025005)。
