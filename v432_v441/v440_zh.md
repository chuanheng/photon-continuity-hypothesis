# v4.40 普通环境何时精确复制持久相位记忆

证据类型为条件性推导及确定性模型核查。复现见 [批次笔记本](reproduce.ipynb)。

**假设与推导。** 每步使用保持同一设备位 Z 的受控相位，实验控制与读出只作用于可见系统 S。所有 S 上的操作在该设备位分块中闭合，偏迹消去块间相干。因此初始设备位 |+⟩ 与 I/2 对任意这类有限操作给出相同记录分布。包含测量和条件反馈时，对每条分支的非归一化态同理。

**数值核查。** 三种非对角或对角控制组成长度 0–4 的 121 条词，完整约化态最大差为零。若后来允许直接测设备位的 X，两种解释在期望值上差 1。那是新增局域寻址，测试的是辅助设备相干。

**局限。** 普通可复制性已证明于分块保持环境与指定可访问操作。含设备位非对易控制或跨设备写入时需重新比较。
