# 内部反方审稿 v4.42–v4.51

内部工作记录，未经过外部同行评审。

1. 环境探针参考有匹配前提。切断目标可能改变设备阻抗、环境频谱或锁相相位。普通馈通在信号与参考之间的差 Δ 可完全进入目标估计。应测不同负载的注入响应，并预注册稳定性界。
2. 三域切断的证书只在互斥的非相干路径模型中有效。共同光学模式或相干交叉项可以绕过三组干预。实际器件需要全试次标定旁路，必要时测振幅和相位，不能把 .025 当作可迁移的仪器上限。
3. 会话检验仅覆盖独立同分布高斯会话。对持续热漂移或会话随设置选择的情况，需要独立的时间顺序及随机化诊断。5.04% 是有限模拟结果。
4. Voigt 重拟合是确定的普通反例。谱仪传递、谱线混合、耦合储存模式还可能扩大标准族。模式投影测到的差也应先用通道响应和光子内部模式解释。
5. 分支通道 CP 与整段因果性是不同层次。每个历史都落在 Pauli 通道族，并不自动证明任意组合的多时概率都可物理实现。完整序列需要联合操作的过程张量与归一约束。
6. 只要额外普通同号旁路允许 .14，v4.50 的合成距离证书即失效。相同触发率也完全不控制条件对比，应保存拒绝分支并标定条件失效率。

修订稿据此将正距离限定为明确盒约束，保留未校准备选载体，要求联合记录触发、阴性及校准。当前候选仍缺跨吸收和再发射的新作用量与独有可观测预测。
