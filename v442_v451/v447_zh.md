# v4.47 标准谱线放开峰位和宽度后的精确反例

**模型与证明。** Voigt 核为以标准差 σ 参数化的高斯与半高宽 γ 的 Lorentz 核卷积。特征函数为 exp(iμk−σ²k²/2−γ|k|)。将原本 σ=.27、γ=.11 的谱线和均值 .13、标准差 .19 的普通失谐卷积，加入 .07 的 Lorentz 展宽，恰得峰位 .13、σ=sqrt(.27²+.19²)、γ=.18 的普通 Voigt。乘上同一已知光学传递函数后，二者仍然相同。

**数值。** `extensions.spectral_refit()` 用独立求积构造目标，和闭式参数重拟合在 31 个频点比较。冻结原谱参数的最大差 .31724，允许上述普通机制后的最大差 8.88×10⁻¹⁶。反例对全频域成立，强于仅在网格证明。单位为合成频率及其倒数密度。

**判据。** 该反例补足 v4.38 的背景自由度问题。单次谱扫描无法分解这些卷积展宽。若独立参考线排除所需峰位和线宽，还需对混合线、仪器传递及背景联合重拟合。可用配对测量锁定频移和全部线形参数后，针对明确动力学检验跨设置残差。Voigt 谱宽背景见 [Olivero 与 Longbothum，1977](https://doi.org/10.1016/0022-4073(77)90161-3)。当前为数学反例与合成计算。
