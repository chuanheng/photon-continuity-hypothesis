# v4.51 相同触发率掩盖条件样本的强伪对比

**问题与模型。** 两个设置共享一个普通公平隐位 L，代表探测前材料或仪器记忆，最终读出 Y=L。设置 0 对 L=0、1 的触发概率分别取 .9、.1，设置 1 取 .1、.9。两设置均有一半触发率。

**推导与数值。** 按 Bayes，触发后两设置的 P(Y=1) 各为 .1、.9，产生 .8 的差。对触发与未触发分支求和均恢复 P(Y=1)=.5，对比为 0。用 `extensions.selection_control()` 枚举全部联合概率，无随机输入，两个对比与解析式一致。这回应此前只比较固定样本条件下的误差界的问题。

**反方判据。** 相同边缘触发率不足以限制条件分布。应同步保存拒绝次数、探测时钟和参考记忆变量，并校验各潜在读出分层下的触发率。若失败试次的 Y 不可观测，必须额外建模、用独立探测或报告缺失数据界。该模型是标准仪器选择反例及合成计算。触发测量的真实标准实验背景见 [Grangier、Roger 与 Aspect，1986](https://doi.org/10.1209/0295-5075/1/4/004)，该论文的真实数据不用于本轮计算。
