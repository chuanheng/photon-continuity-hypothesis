# v4.64 腔内存储与输出、损耗端口的激发账本

被动单模腔初始单激发，输入端其后为真空。设观测端口衰减 κₑ，内部库衰减 κᵢ。Markov 条件下，腔内 P(t)=exp[−(κₑ+κᵢ)t]，积分光子流给每个端口 Qⱼ=κⱼ/(κₑ+κᵢ)(1−P)。因此 P+Qₑ+Qᵢ=1。在窄带共振近似，每个激发对应约 ℏω₀；若光谱宽或有外部驱动，能量需逐频计算。区别于 v4.56 的封闭相干交换，这里检验了开放腔端口的观测账本。

取 κₑ=.7、κᵢ=.3、T=8。用 `model.cavity_ledger()` 独立求解三分量速率方程并比较 81 个时间点。末态 (P,Qₑ,Qᵢ)≈(.00033546,.69976518,.29989936)，归一误差 4.44×10⁻¹⁶，最大解析误差 8.15×10⁻¹³。

只监控出射端口可把普通内部损耗误报成约 .3 的异常。应独立扫描耦合率、测腔环降与端口收集效率，检验时间和端口比例。相干回灌、非 Markov 库和探测漂移应作为附加普通模型。背景参见 [Gardiner 与 Collett，1985](https://doi.org/10.1103/PhysRevA.31.3761) 和 [Fan、Suh 与 Joannopoulos，2003](https://doi.org/10.1364/JOSAA.20.000569)。本轮无新的光学实测。
