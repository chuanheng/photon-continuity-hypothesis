# v4.69 有限光学参考能恢复多少数态间相干？

信号为 (|0⟩+|1⟩)/√2，参考为 Σrₙ|n⟩，只允许守恒总光子数的观测。全局相位平均使总数 n 的块包含 |0,n⟩ 和 |1,n−1⟩。读取每块相等权的相干，最佳对比上界为 Σ|rₙrₙ₋₁|。在 n=0,…,L−1 的参考支持内，它是路径矩阵相邻元素 1/2 的最大 Rayleigh 商，即 cos[π/(L+1)]。正弦本征向量达到上界。相比 v4.59 的共享相位极限，本轮固定参考资源大小。

`controls.finite_reference()` 枚举 L=1、2、4、8 的块。L=4 最优 .809017 对比均匀参考 .75，L=8 最优 .939693 对比 .875。纯参考、可按总数块实施匹配读出是上界可达前提。直接用仅一个固定分束器未必可达。该数学构造适用普通光学相干，对真实仪器应另测参考光谱、能量与相位漂移。

如果测得的对比在已知参考支持下超出上限，应先检验参考截断、额外参考和条件选择。该结论不赋予光子可访问个体标签。参见 [Aharonov 与 Susskind，1967](https://doi.org/10.1103/PhysRev.155.1428) 和 [Bartlett、Rudolph 与 Spekkens，2007](https://doi.org/10.1103/RevModPhys.79.555)。
