# v4.72–v4.81 内部反方审稿

1. v4.74 的两个端口成功概率含滤波，倘若只登记成功信号则难以验证恢复是对任意状态一致的。用归一化前矩阵与输入无关成功率作为检验，并留存失败数据。
2. v4.75 的深度分析不排除跨门记忆和深度相关测效。普通读出参数 .622222 即提供完全重拟合。固定 SPAM 是待独立验证的物理条件。
3. v4.76、v4.81 的距离只约束被校准复振幅，不会自动给出显著性，也不能证明仪器无隐藏端口。相干幅度合成可突破按不相干漏能量制定的预算。若普通路径有效功率超过 .010733，v4.81 的排除消失。
4. v4.77 的容量结果是无辅助独立用次，真实通道含相关噪声、后选和反馈时不能援引零容量。v4.78 的端点是确定性缺失包络和合成漂移，不能当跨总体置信区间。
5. v4.79 的精确匹配刻意以普通模型生成，用途是反例。有限频带不能验证全频段的 Kramers–Kronig 关系，必须给出频带外信息。
6. v4.80 已有普通光物质相干交换解释。若身份参数确有耦合，应找出在独立校准的联合过程上超出普通材料、相干环境和探测模型的预测，给出显式规范不变算符及能动量账本。当前版本支持对沉默标签的操作不可辨识解释。

审稿为仓库内部工作记录。上一版中的通量、振幅和统计证据范围已在各轮及修订稿中分别注明。
