# v4.75 单深度偏振层析能否预测二次传输

**条件推导。** 取六个 Pauli 本征偏振输入与分析器。各向同性 Bloch 准备、通道及读出分别收缩 a、λ、b，均在 [0,1]，其二值概率为 (1+abλⁿ u·v)/2。在单深度 n=1，完整表仅确定乘积。固定准备与读出并排除门间记忆时，同轴的二深度与单深度中心化对比之比为 λ。与 v4.63 单一旋角控制相比，此处变化的是重复传输深度。

**合成检查。** `controls.polarization_transfer()` 中 λ=.70 与 .90 的 36 个单深度概率完全一致，固定校准的二深度最大差 .0504。将后一模型在二深度的读出收缩改成 .622222，全部二深度概率又一致至 1.11×10⁻¹⁶。

**检验与边界。** 交错随机化深度，在等时长空白序列上预标定读出漂移，保留跨门环境的模型和时间标签；用第三深度和非共轴干预挑战同一通道。若材料有记忆、探测器记录前次脉冲或多次循环累积串扰，固定读出的比值也可能偏离，一般 CPTP 通道不服从标量公式。这里的反例覆盖所有六轴组合，结论仅限定标量族。已知方法见 [Nielsen 等，Gate Set Tomography](https://doi.org/10.22331/q-2021-10-05-557) 和 [Gilchrist 等，2005](https://doi.org/10.1103/PhysRevA.71.062310)。无实测。
