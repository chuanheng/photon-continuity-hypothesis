# v4.76 多端口同时复位下的相干串扰预算

**条件定理。** 复位后输入旁路可由复向量 x 描述，残余可相干读出的各端口振幅为 z。给定全复矩阵 T，Tx=z 蕴含 ||T||₂≥||z||₂/||x||₂。取 T=z x†/||x||² 即达到等号。进一步限制 ||T||₂≤ε 时，允许输出正是半径 ε||x||₂ 的闭球，最小残差是 (||z||₂−ε||x||₂)₊。此处比单端口上限多约束同一复振幅测量下的总功率。范数低于一的矩阵可通过奇异值分解、分束损耗端口和无损旋转组成；非互易实现如需要必须单独建模。

**合成检查。** `controls.multiport_reset()` 以固定两路输入测试三个输出。最大单端口 .083，独立合成联合校准 ε=.12。最小拟合范数 .134216，残差 .014216；解开校准上限后，普通被动网络重拟合误差 1.39×10⁻¹⁷。

**可证伪域。** 用同一相位参考独立标定传输矩阵的最大奇异值，并监测复位相位、器件和参考漂移。对未经校准的材料激发或探测器相干偏置，残差可以另由它们携带，本轮上界只约束作用于已测 x 的线性被动项。加入新的独立光学端口时须重建 x 的范数。模型背景见 [Fan、Suh 与 Joannopoulos，2003](https://doi.org/10.1364/JOSAA.20.000569)。无实测。
