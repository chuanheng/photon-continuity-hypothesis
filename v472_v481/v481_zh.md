# v4.81 全端口账本与两正交相位读出联合预注册

**条件定理。** 同一归一化入射模式下，以复场 c 表示所有普通相干旁路的合计。两正交参考测得 z=(Re c,Im c)+e，各坐标的校准误差 |eⱼ|≤dⱼ。给定合计功率上限 P，普通对照的可行域是圆盘加矩形。逐坐标把零投影到 [zⱼ−dⱼ,zⱼ+dⱼ]，得到最小普通功率 ∑max(|zⱼ|−dⱼ,0)²。每一象限的分量检查均可以通过，合计仍可能违约。与 v4.76 的复多端口传输范数相比，这里用同一端口的两正交观测和独立功率账本，专门覆盖相位切换中的联合可行性。

**合成检查。** `controls.joint_quadrature()` 以 z=(.095,.075)、d=(.012,.013)、P=.008 演示。最强单分量功率需求 .006889；联合下限 .010733。普通预算增 .002733 即可在误差盒内精确重拟合。

**预注册与反例。** 先冻结参考平面、单位、频带、功率与测效校准、相位随机化、探测噪声覆盖和误差计算；记录漏读端口及总相干功率，包含储存再释放的时间窗。P 必须约束可干涉合成场，不能拿各泄漏路径功率简单相加。隐藏共同相位旁路或跨块态不同均可破坏模型。大于上限只质疑此校准族；将独立未读模式、外部驱动、材料与仪器记忆、串扰和漂移纳入后，尚无独有身份预测。输入输出框架见 [Gardiner 与 Collett，1985](https://doi.org/10.1103/PhysRevA.31.3761)。无实测。
