# v4.82 带擦除标志的光学存储纠缠证书

**条件定理。** 向存储器送入一对 Bell 态的一半，另一半保留作参考。计入全部试次，成功分支的未归一化态为 S，η=tr S。若成功分支是纠缠破坏的 CP 仪器，则 S 可分。任意归一化纯积态对二维最大纠缠态的重叠 ≤1/2，由 Schmidt 展开与 Cauchy–Schwarz 得证，凸组合保持。因此 W=⟨Φ|S|Φ⟩−η/2≤0。擦除分支单列，成功标志必须由经过审计的本地仪器产生。

**合成结果。** `model.flagged_bell()` 模拟普通等轨损失及去极化，η=.43、偏振保留参数 .58，成功保真度 .685，W=.07955，带标志完整态的部分转置负性 .07955，迹误差为零。极端允许假成功贡献完美 Bell 统计时，最多 .5 单位见证/单位绝对假成功率，故需独立证明假成功质量低于 .1591 才能保留正见证的这部分裕量。

**判据。** 结合事件就绪层析、无输入背景、交错标定、独立两臂读出和全部擦除计数。共同参考、设置相关的筛选、探测串扰、普通相干存储与多光子噪声需纳入。正见证排除已校准纠缠破坏通道，普通相干存储能实现，并无身份判据。和 v4.77 的容量问题不同，此处是单次通道纠缠证书。参见 [Horodecki 等，原文](https://arxiv.org/abs/quant-ph/0302031) 和 [Gühne 与 Tóth，2009](https://doi.org/10.1016/j.physrep.2009.02.004)。无实测。
