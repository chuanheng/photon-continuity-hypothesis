# v4.83 阈值 HOM 曲线的双对污染反例

**模型。** 50:50 分束器，双对输入 |2,2⟩ 在全相干和两入射束可区分时，输出一端的计数分布分别为 (3/8,0,1/4,0,3/8) 和 Bin(4,1/2)。前者由 (a†+b†)²(a†−b†)² 的标准玻色展开得到。两端独立等效探测率 η 时，给定 n 个输出光子与一端 k 个，阈值符合率是 [1−(1−η)^k][1−(1−η)^(n−k)]。单对模型可改变对产生率和波包重叠，拟合远近两点。

**合成结果。** `model.multipair_threshold()` 在 η=.8、单对概率 .22、双对概率 .024 下，远近符合率 .0882176 与 .0055296。单对产生概率改为 .27568、重叠改为 .937319 后误差 1.39×10⁻¹⁷。近点同一端实际探测计数达四的事件为 .0073728，纯单对模型给零。与此前只有波包重叠的 HOM 解释相比，区分依赖额外的光子数记录。

**判据与边界。** 变动泵浦强度并记录全计数直方图。探测堆积、串扰、级联 dark count 和器件记忆会伪造多计数，需用独立脉冲、阻断输入和时间基线校准。此处只拟合远近两点；真实模式的延迟依赖、强度漂移和非等效率须另拟合。已知干涉参见 [Hong、Ou 与 Mandel，1987](https://doi.org/10.1103/PhysRevLett.59.2044)。无实测。
