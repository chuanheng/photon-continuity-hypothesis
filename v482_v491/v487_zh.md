# v4.87 光子数二阶矩与电子假计数的等价边界

**模型。** 环境热模经分束器进入真空探针输出，单模热分布 p(n)=μⁿ/(1+μ)^{n+1}，μ=(1−η) n_env。其二阶阶乘矩为 2μ²，同均值独立 Poisson 为 μ²。普通几何电子假计数寄存器在单路所有计数 n 上与热光完全等价。热光经 50:50 分束，理想独立两探测器交叉矩 E[n₁n₂]=E[n(n−1)]/4=μ²/2。相较早期均值暗计数对照，此处规定联合计数判据。

**合成结果。** `model.thermal_bunching()` 以 .62 的透射和 .38 的热环境平均占据给 μ=.1444，64 级截断下平均数与 Poisson 相差 2.78×10⁻¹⁷，g² 分别为 2、1。几何电子全边缘误差 1.39×10⁻¹⁷，光学双探测器的交叉矩 .010426。

**检验与适用域。** 测第一和第二阶矩及独立双探测器全联合分布，阻断探针与背景并校准恢复窗、邻路串扰和计数非线性。共同电子爆发可重现 bunching，随瞬时强度漂移的普通混合 Poisson 也会超 Poisson。已知理论见 [Holevo 与 Werner，2001](https://doi.org/10.1103/PhysRevA.63.032312) 与 [Hanbury Brown、Twiss，1956](https://doi.org/10.1038/177027a0)。无实测。
