# v4.94 全部两两 HOM 相同仍可有三光子不同聚束

**已知物理与推导。** 三个不同输入端各一光子，内部纯模式的 Gram 矩阵 G；端口均匀三分束。指定一输出口的全聚束概率为 perm(G)/27，来自同口三个玻色产生算符乘积的范数。取两两模重叠都为 r，perm(G)=1+3r²+2r³cosΦ，Φ 为闭三角乘积相位。各两光子 HOM 只见 r²。r=.38 时正负 Φ 选择的 Gram 因严格对角占优而正定。

**合成结果。** `model.triad_bunching()` 对 Φ=0、π 用 Cholesky 生成普通内部模式，并独立枚举六个对称张量分量。指定端聚束 .0571461 与 .0490169，解析最大差 6.94×10⁻¹⁸。相比 v4.83 的源双对污染，此处是恰有三光子、普通复重叠携带的第三阶相位。

**判据。** 三路同步、PNR、独立两两干涉、三路联合记录和模式层析共同约束三元相位。频率、偏振、脉冲漂移、四光子污染与多端口串扰都可导致差异。相位由已有标准模型解释。已知实验见 [Menssen 等，2017](https://doi.org/10.1103/PhysRevLett.118.153603)，多端口公式见 [Tichy，2015](https://doi.org/10.1103/PhysRevA.91.022316)。本项目无实测。
