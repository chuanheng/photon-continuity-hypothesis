# v4.99 两独立材料支路经共同奇偶监测可产生条件相关

**条件推导。** 独立均匀的两个普通材料位 X、Y 在各自支路制备；共享控制器输出 Q=X⊕Y⊕N，N 是独立翻转位。X 与 Y 互信息为零，而且 X 与 Q、Y 与 Q 也各自独立。给定 Q，判明 X 时可推断 Y 的误差率为 ε，故 I(X:Y|Q)=1−h₂(ε)。与 v4.86 共享本振带来的无条件协方差不同，此处是对共同输出条件化带来的相关。用两路普通读出进入经典奇偶器即可实现。

**合成结果。** `model.common_controller()` 对所有八个联合概率求和。奇偶准确率 .9，无条件 I=0，条件 I=.531004 bit，熵公式误差 0。

**判据。** 分别随机化输入，永久保留包含共同控制器全部记录的未筛选数据，改变控制器逻辑，检查探测串扰、丢失计数、参考共同漂移与材料相互作用。其他常规碰撞选择同样可能产生条件相关。对量子环境的推广需指定量子条件寄存器，不能直接套用经典奇偶统计。熵理论背景见 [Lieb 与 Ruskai，1973 原文](https://www.numdam.org/item/RCP25_1973__19__A5_0.pdf)。无实测。
