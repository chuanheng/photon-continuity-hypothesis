# v5.01 可见标量耦合与光子身份命题的分离

**候选与条件推导。** 在局域有效场论加入实标量 φ，标准正动能与 m²≥0，耦合 −gφF_{μν}F^{μν}/4。在弱背景 |gφ|≪1、给定源和推迟边界下，标量满足 Klein–Gordon 源方程，源与 F²=2(B²−E²) 成正比。理想真空单平面波 F²=0；驻波纯电腹处局域 F² 非零，可用外加场和受控几何产生谐波源。点状谐波源的出射频域核为 e^{ikr}/(4πr)，k²=ω²−m²，取 Im k≥0。相互作用局域且规范不变，玻色场代数不附带个体索引，背景不变时由完整场与源的能动量账本给出守恒。本轮没有建立带材料边界的完整散射和源的功率，仅检验线性格林函数与源选择规则。

**合成结果。** `model.sourced_scalar()` 用 m=.78、频率 .55 与 1.1、81 个半径。低频衰减、高频传播，普通有截止波动方程的实指数/正余弦重拟合误差 6.94×10⁻¹⁸。这是一种普通有效模型反例，实际装置需有相应几何、传播介质与跨隔断通路。对比 v4.72 的外置旋光背景，本轮重点是生产源算符和距离规律。

**预注册与停止条件。** 若研究该标量，应独立改变 F² 源几何、屏蔽几何、距离和阈值频率，纳入普通有截止传播、电子串扰、漏光、源相干和漂移。即使这些测量排除所有已校准标准机制，耦合测到的是场与集体源响应；要作为原假说预测还需要定义跨吸收的身份算符，并推出不同于新场本身的统计。给不出这一项的候选停留在新场搜索。本项目无实测。相关背景见 [Jaeckel 与 Ringwald，2010](https://doi.org/10.1146/annurev.nucl.012809.104433)。
