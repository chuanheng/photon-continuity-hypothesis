# 内部反方审稿工作记录

2026-11-24。评审对象为本批工作稿和合成模型。

1. 多距离的数据若来自同一个无源均匀区，已知完整复场时其后续传播可能完全由同一测量推出。正文须将 z 定义为导波长度干预，并解释两臂进入共同测量投影的条件。把 z=0 和 2π/0.7 用作唯一两点会破坏排除。
2. 斩波基频在 B≠0 时可由普通平方通道产生。非零相位读出能排除完全去相干通道，但相位保留的普通交换是精确反例。物质归因还需要隔离端口与独立干预。
3. 零事件限值依赖 B 端有代表性的注入和试验内抽样模型。重新定义独立批次会显著放宽上界。Hankel 证书只约束指定端到端 LTI 族，任意探测器内部动态可贡献状态。
4. 复圆盘距离的全局性来自指定的路径包络。独立漏光校准失效、未监测端口或超出预注册扫参范围会推翻错误排除保证。合成示例已经给出将距离变为零的反例。

结论：方法学结果可保留。进入物理候选检验前，需给出带可访问耦合的身份预测及与完整普通对照共同定义的留出检验。
