# 内部反方审稿工作记录

2026-11-24，范围为 v5.12–v5.21 数学推导及合成结果。

1. 共同旁路模板首先需要外部约束。放开逐设置相位与幅度会恢复精确拟合。椭球方向如果与科学数据共同选择，标称误差覆盖会失效。
2. 正态参考块的覆盖实验使用已知方差。实际估计方差、时变共享噪声、不正确的配对规则均可改变覆盖。20 个设置的精确阈值只对给定独立分布成立。
3. 已知方差的功效只能在候选可分时参与物理判断，给出交叠反例后应先查联合观测的最小距离。校准成本与误差缩减是示例参数，固定方向排序无法替代同时选择方向和仪器的优化。
4. 公开种子的标签随机化不构成真实盲测。若上游注入的频谱、时序或耦合不代表候选，应将回收率限于该注入信号。通过盲注入鲁棒性检查后仍须独立建立身份特异的观测预测。
