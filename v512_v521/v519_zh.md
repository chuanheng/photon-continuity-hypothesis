# v5.19 候选与普通集合的交叠

**证据**：闭圆盘距离恒等式与合成例。把 v5.11 的点对普通集合排除扩展为两侧允许各自重拟合的全局设计。

普通族是中心 0 半径 0.10 的圆盘，候选族是中心 δ、半径 0.07 的圆盘。其距离为 max(0,|δ|−0.17)。δ=0.13 时，交叠点 0.07647 可由任一模型取得。δ=0.21 时全局间隙 0.04。这里允许两侧在各自参数域独立重拟合。若试验真实强制两族共享同一外部观测的干扰参数，应对联合数据重建两族。

**可证伪判据**：独立冻结两个幅度预算与候选的效应区间。若两族在联合观测下相交，则没有仅用该均值统一判别的设计。若存在正间隙，才可为指定噪声估算检验功效。

复现：`python -m v512_v521.model`。
