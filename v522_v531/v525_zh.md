# v5.25 校准端口串扰与逆矩阵误差

**证据**为扰动界和合成两端口。承接 v5.21 的上游注入。名义混合 C 的主对角元为 1，串扰为 0.05i、0.04。普通漂移 ΔC 在左下角增加 0.10。注入已知参考 x=(1,0)，使用名义逆矩阵会在科学端口留下约 0.10 的振幅。由 Ĉ⁻¹(C+ΔC)x 和范数次乘性，误差不超过 0.103251，实算 0.100125。若独立校准约束 ‖ΔC‖₂≤0.03，输出残差 0.10 超界；重估普通矩阵后误差为零。

**可证伪判据**。解盲前以独立双端口注入锁定相位矩阵与算符范数覆盖，保留间隔参考注入以检查漂移。标准预测允许因频段、输入强度和连接变化而不同的串扰。证书只针对给定线性工作点。
