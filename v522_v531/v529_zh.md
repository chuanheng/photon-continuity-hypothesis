# v5.29 共用标定源造成系统误差下限

**证据**为 GLS 方差和合成八实验协方差。相较 v5.17 的块内相关，新增跨仪器共用的外部标定。模型 yᵢ=μ+b+εᵢ，b 的零均值随机标准差为 0.10，独立 ε 的标准差为 0.06。μ 的组合标准误为 √(0.10²+0.06²/8)=0.10223，误把仪器边际方差当彼此独立给出 0.04123。配对差抵消共有项，标准差 √2×0.06。若 b 为未知固定偏差，μ 和 b 两列相同，秩为 1，绝对值结构不可辨识。

**可证伪判据**。按标定溯源分组估计共享协方差，插入独立参考与有意翻转响应的对照。部分相关、尺度误差与非线性漂移需其他传播模型。合成随机偏差的先验尺度不能替代实际校准。

复现：`python -m v522_v531.model`。
