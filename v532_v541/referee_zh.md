# 内部反方审稿工作记录

2026-11-24。评审范围为 v5.32–v5.41 的有限维通道与受控普通存储。

1. Choi 纠缠和互补基上界均要求受信输入和读出。轴重复、设定泄漏、选择性成功和普通偏振漂移可以推翻指定实验的认证。二维 Choi PPT 充分性不可任意外推高维系统。
2. 0.02 残余功率示例只给出纯损耗模型中的平方根标度。把一次复位校准扩展为通用过程范数上界需要更多可访问操作。
3. 原始擦除旗标正交且在输出可用。补空失败态改变了实际通道。需要联合报告成功率、旗标定义、全输入覆盖，并用真实硬件数据验证。
4. 环境相位参考和脉冲必须独立标定。若环境测量和动力学同步重标定，有限系统记录可完全等价。相干 CNOT 或 SWAP 是标准量子对照。当前模型的正见证没有把持久个体身份从普通环境中分离出来。
