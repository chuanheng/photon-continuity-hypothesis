# v5.40 中间环境脉冲区分相干和完全去相干存储

**证据**为标准量子电路和合成通道。进一步扩展 v5.39 的被动环境读出，加入受信主动干预。先将 +X 通过系统控制的 CNOT 写入环境，形成 |Φ+⟩，普通备择在这一步完全去相干，两者局部布居完全一致。中间对环境施加 X 或 Z，再做同一 CNOT 反写，末端系统 X 期望在相干模型为 +1、−1，完全去相干模型为 0、0。

**可证伪判据**。环境脉冲需通过独立的轴校准、串扰试验和共同参考。该测量在给定准备下排除完全去相干普通存储，但相干普通量子存储直接实现两象限。要把因果效应定位到环境而非脉冲直接作用于系统，需跨设备阻断和串扰界。

复现：`python -m v532_v541.model`。受控过程的相关参考 [Pollock 等](https://doi.org/10.1103/PhysRevLett.120.040405)。
