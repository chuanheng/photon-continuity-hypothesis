# 稳健控制设计、有限功效与停止条件

2026-11-24 中文工作论文。

将两组普通响应的自由重拟合、联合标定误差和有限样本设计放在同一可核验框架中。所有数值均为解析或合成结果。

- **v5.72 按最小奇异值选择控制组合**。基线和差动控制组合达到最小奇异值 0.84853，接近共线的一组仅 0.10499。若合成读出误差半径为 0.03，最优组合的参数误差上界为 0.03536。
- **v5.73 控制矩阵误差改变辨识证书**。名义最小奇异值 0.78562，稳健下界 0.72562；一个合成扰动的算符范数 0.04050、响应差 0.00546，名义参数差 0.00481。证书覆盖预定球内的全部矩阵误差。
- **v5.74 制备误差与读出泄漏联合重拟合**。理想读出会报 0.70，只有读出串扰时为 0.676，两误差共同存在时为 0.63856。差异由普通制备与探测通道直接生成。
- **v5.75 联合标定相关性收紧普通集合**。椭球和边际盒的支持分别为 0.04472、0.14142。投影观测 0.09 对椭球有 0.04528 的分离下界，但边际盒可以容纳该投影。
- **v5.76 最强单次量子输出判别**。布居读出差为零，最优测量概率差与迹距离同为 0.30463，等先验错误率 0.34768。普通相位与去相干模型也能实现两状态。
- **v5.77 相近计数率的精确有限功效**。第一次达到 90% 功效在 N=968，拒绝阈值 113，实际大小 0.04865，功效 0.90024。所有较小整数 N 的最高功效约 0.89837。
- **v5.78 区组相关性给复制设置功效上限**。每块 64 次时正确标准误为 0.02051，错当独立得到 0.00327；在真实效应 0.045 时已知方差单侧功效约 70.84%。每块无限重复的标准误下限是 0.02041。
- **v5.79 参考材料到新样品的留出迁移**。严格迁移下裕度 0.05。改用未监测的保守迁移误差 0.15，裕度 −0.04，普通响应取偏移 0.14 可精确重拟合。
- **v5.80 能量分辨率和旁路谱形的全局见证**。全合并能箱的概率差为零，三个分辨箱下示例总变差 0.16205，标定类的全局下界 0.12675。若普通谱位置允许 0.7，可精确重拟合。
- **v5.81 可观测分布相交时停止重复原试验**。合成原模型的普通重拟合误差为零。在第二设置独立限定普通关系为 (p,p+0.05) 时，两维均值的全局欧氏距离 0.07/√2≈0.04950。此距离只在新普通约束成立时证明分离。

优先检查候选分布和普通对照是否相交。若当前操作集存在精确相交，重复同类测量无法提高最坏条件下的身份检出率。独立环境干预可以移除此类交点，但本研究尚未找到排除完整普通族的身份特异预测。
