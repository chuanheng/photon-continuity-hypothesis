# v5.77 相近计数率的精确有限功效

## 假设与推导

独立伯努利固定样本设计，衔接 v5.67。以 0.10 为普通事件率上界、0.13 为预注册备择。在每个 N 取满足 5% 单侧大小的最小非随机化整数阈值，枚举较小 N，避免离散功效随 N 跳变。

## 结果与普通对照

第一次达到 90% 功效在 N=968，拒绝阈值 113，实际大小 0.04865，功效 0.90024。所有较小整数 N 的最高功效约 0.89837。

## 可证伪条件与局限

968 针对指定独立二项率与非随机化检验。若有先后多次查看数据、普通率估计误差或跨块相关，必须另计。

复现入口为 `python -m v572_v581.model`。
