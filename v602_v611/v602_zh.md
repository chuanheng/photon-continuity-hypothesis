# v6.02 冻结铝的分过程质量截面

## 假设与推导

数据交叉核对。导出 xraylib 4.3.0 的 Z=13 截面，35–65 keV 每 0.25 keV 一点，单位 cm²/g。独立读 NIST 表的 60 keV 总值。参照 [xraylib 原始论文](https://doi.org/10.1016/j.sab.2011.09.011) 和 [NIST 铝表](https://physics.nist.gov/PhysRefData/XrayMassCoef/ElemTab/z13.html)。

## 结果与普通对照

60 keV 的光电、相干、康普顿分量分别为 0.095639、0.033859、0.148313，合计 0.277810，与 NIST 0.2778 相对差约 3.7×10⁻⁵。冻结表可由 python -m v602_v611.extract_cross_sections 再导出。

## 可证伪条件与局限

总值一致只核验数值及单位。均匀密度取 2.70 g/cm³，合金、孔隙和厚度误差需独立测量。

复现入口为 `python -m v602_v611.model`。
