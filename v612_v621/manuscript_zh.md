# 混合散射与不完整普通背景的可检验界

2026-11-24 中文工作论文。

扩展相同的 60 keV、1 mm 厚、5 mm 半径铝板，采用 xraylib 原子角分布的近似混合模型，继续区分数值可靠度、物理遗漏与假定探测响应。

- **v6.12 原子散射函数重加权**。该角窗中双康普顿从 1.57672×10⁻⁶ 增至 1.69846×10⁻⁶/入射，差约 7.72%。关闭原子权重后与 v6.04 的旧自由角核迹象一致。独立表可由 python -m v612_v621.extract_atomic 重建。
- **v6.13 混合瑞利和康普顿路径**。康普顿后瑞利约 1.009×10⁻⁷/入射，瑞利后康普顿约 7.718×10⁻⁸。与双康普顿相加约 1.8765×10⁻⁶，混合约占 9.49%。两次瑞利在理想无能损假设下不进入真降能窗。
- **v6.14 入射位置偏心的影响**。偏心 0、2.5、4.5 mm 的双康普顿分别约 1.698、1.630、1.290×10⁻⁶/入射。外侧示例为中心的约 76%。
- **v6.15 三次或更多作用的保守上界**。最长弦约 1.005 cm，首碰概率约 0.0723，乘积界约 0.0430/入射。该界不筛选最后角能窗，故比选定双康普顿率大约 2.53 万倍。
- **v6.16 入射能量依赖压力测试**。四个点的双康普顿率分别约 1.589、1.657、1.698、1.721×10⁻⁶。最大/最小约 1.0833。
- **v6.17 重复积分与过程次序不对称**。三路径积分相对标准误小于 0.000066，先康普顿后瑞利平均为反顺序的约 1.307 倍。几何、能量依赖和先后分过程共同决定该比值。
- **v6.18 探测效率折叠区分出射率和记录率**。所得总记录率约为真出射分项的 76.39%，各路径效率不同。
- **v6.19 总背景上界支配检验功效**。普通上界从 1×10⁻⁵ 升至 2×10⁻⁵、2.8×10⁻⁵ 时，候选功效约从 100% 降到 90.16%、8.48%。
- **v6.20 同一角能谱可来自不同内部路线**。两种模型的读出均为 (0.6,0.4)，不可见路线占比差 0.25。沿用 v6.10 的停表逻辑：若开放普通核可产生相同角能谱，则谱本身不足以区别路线。
- **v6.21 推进实体标定前的背景门槛**。当前粗界约是示例增量的 4302 倍，无法以此作为精细背景上界。完整输运验证和探测器标定仍未知，现有角能谱亦无身份特异的备择输出。

在受限的恰好两次作用模型里，三条普通路径相加约 1.88×10⁻⁶/入射，混合路径约占 9.5%。三次以上的保守界仍过宽，独立模拟和真实标定未取得，不能将该分项结果认作总本底。
