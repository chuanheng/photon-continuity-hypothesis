# v6.12 原子散射函数重加权

## 假设与推导

数据库输入与数值敏感性。用 xraylib 的 S(q) 重加权康普顿差分核并按新核重新归一化；碰撞概率仍取分过程总截面。能量仍使用静止自由电子关系，不含束缚动量展宽。参照 [xraylib](https://doi.org/10.1016/j.sab.2011.09.011) 与 [Geant4 Livermore](https://geant4.web.cern.ch/documentation/dev/prm_html/PhysicsReferenceManual/electromagnetic/gamma_incident/compton/livermore_compton.html)。

## 结果与普通对照

该角窗中双康普顿从 1.57672×10⁻⁶ 增至 1.69846×10⁻⁶/入射，差约 7.72%。关闭原子权重后与 v6.04 的旧自由角核迹象一致。独立表可由 python -m v612_v621.extract_atomic 重建。

## 可证伪条件与局限

需用角分辨散射和束缚电子能谱验证。混合使用总截面和独立归一化的差分近似保总率，但未认证联合材料响应。

复现入口为 `python -m v612_v621.model`。
