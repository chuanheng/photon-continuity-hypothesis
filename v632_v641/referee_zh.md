# 内部反方审稿记录

1. 从模拟可见两次普通散射回到前向锥。仅有探测器的一个终点不能重建每次相互作用；真实观测若要标记反冲或中间方向，需要考虑标记效率和它对散射的扰动。
2. 原种子只在本地重放。第二种子提供独立模拟样本，两次运行仍共享同一个物理列表、材料和束流设定。单次小角残差提示自由反冲近似的适用范围；未做逐壳层归因。
3. 在未产生次级的设置里，零计数上限只覆盖模拟定义，无法代替次级产生阈值、周边材料或仪器响应的敏感性扫描。稀有事件的区间未包含模型系统误差。
4. 四个几何设置的拟合残差需要独立限制普通模板。每设置一个额外普通偏置足以重拟合全部均值。工作假说尚未给出可测的身份耦合。
