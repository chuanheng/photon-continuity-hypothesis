# v6.47 容许漂移的最坏情形阈值

若独立标定保证样品普通总率不超过参考的 1.05 倍，使用条件二项概率上界 1.05n/(1.05n+m) 取临界值，单调性保证族内尺寸。

示例给出边界尺寸和无漂移处功效。若 5% 只是点估计，未将界外概率计入，尺寸保证无法移植。

从模型入口复算的输出如下。概率均按单个入射光子计。

```json

  "threshold_fraction": 0.5121951219512195,
  "worst_endpoint_size": 0.022775866379920896,
  "nominal_power": 0.07285191906605393
}
```
