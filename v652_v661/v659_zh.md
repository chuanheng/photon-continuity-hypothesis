# v6.59 产生长度切值对次级光子计数的作用

对同一几何和物理列表设置两种产生长度切值 0.7 与 0.001 mm。逐轨迹首次步记一次次级 gamma，另按入射事件去重。产生计数、穿出铝箔和穿出后又满足读出窗属于不同观察量。按有次级的事件数给每个设置 97.5% 单侧二项上限。

两项各一百万次入射。几何切值由材料转换为能量阈，低能数据下限与原子退激发配置也会影响结果。即使产生数显著改变，也要单列真正过窗的次级；零计数仅提供有限暴露上限。实体阈值须另外校准。

本轮证据为条件推导、数值计算或输运模拟。复现入口为 `python -m v652_v661.model`。输入、单位与随机种子见[运行记录](verification.json)。
