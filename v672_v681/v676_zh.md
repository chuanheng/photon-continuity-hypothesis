# v6.76 锗 K 边与滤片

对假设的 0.1 mm 锗片，用 xraylib 的质量衰减系数计算窄束透射 exp(−ρμₘd)，对 10.98 keV 附近真实入射能量作高斯积分。宽度从 0.01 增至 0.15 keV，平均透射从 0.214 降至 0.166。

**反例、局限与判别条件**　展宽指到达滤片的能谱；改变下游电子学分辨率不会产生此效应。滤片、厚度和高斯谱均属设计假设。

**复现**　在仓库根目录运行 python -m v672_v681.model，读取 v6.76 项。[原始论文及图2、图3](https://hrcak.srce.hr/file/437541)。
