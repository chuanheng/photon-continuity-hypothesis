# v7.12 外部实验的反冲能窗

1995 年实验使用 54.612、55.791 keV；1997 年报道 59.537 keV、约 170°；2000 年报道 86.5 keV。同取散射光子窗 34.5–36.5 keV，按全能收集 E反冲=E入射−E散射，原实验覆盖 18.112–21.291 keV 的两个重叠窗口，后两实验分别对应 23.037–25.037 和 50–52 keV。检索到的后续论文摘要未给出原装置两线×两方向响应表；同材质无法保证响应可迁移。

复现入口为 python -m v712_v721.model 的 v7.12 字段。计算为确定性，原谱数字化沿用 v7.11。
