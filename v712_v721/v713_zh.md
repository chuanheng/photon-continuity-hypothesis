# v7.13 共同效率的适用范围

1995 年原文式(1)使用估计探测效率 0.93、符合效率 0.98。若四格共用，两因子乘积 0.9114 在交叉比中完全消去。若实际全能吸收、门选或逃逸概率依能量与方向共同变化，需要独立测量各格。原文绝对几何误差约 9%，没有给这种交互的界。

复现入口为 python -m v712_v721.model 的 v7.13 字段。计算为确定性，原谱数字化沿用 v7.11。
