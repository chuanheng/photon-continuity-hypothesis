# v7.14 单个外部参考的零点

设 g(E) 为两方向增益比的对数，以 59.537 keV 为精确锚点，普通线性响应 g=b(E−59.537) 取 b=−0.252/keV 就重现两条原谱之间的对数差 0.297。此构造仅检验单锚约束；其他能量上的较大外推值不得解释为测得的增益。

复现入口为 python -m v712_v721.model 的 v7.14 字段。计算为确定性，原谱数字化沿用 v7.11。
