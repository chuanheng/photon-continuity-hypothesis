# v7.16 目标能区的局部斜率

均值定理给出产生中心差所需的最大绝对斜率下界 0.297/1.179=0.252 每 keV。若有匹配装置对整个区间的较低上界，就能排除单靠此响应产生全部中心差。单点导数或原实验误差棒均不能提供全区间界。

复现入口为 python -m v712_v721.model 的 v7.16 字段。计算为确定性，原谱数字化沿用 v7.11。
