# v7.17 参考测量的计数预算

假设四格独立泊松计数、期望相等且足够大。对数交叉比一阶方差约为 4/n。让参考标准差达到 0.05，每格需预期 1600 个有效事件。背景扣除、共用事件或不均衡计数需重算。

复现入口为 python -m v712_v721.model 的 v7.17 字段。计算为确定性，原谱数字化沿用 v7.11。
