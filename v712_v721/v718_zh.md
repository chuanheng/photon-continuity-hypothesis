# v7.18 减去独立参考后的精度

设参考装置交互严格匹配，且参考与主测量独立，则两对数交叉比之差的方差相加。沿用上一批主测量标准差代理 0.463，加上参考标准差 0.05 后为 0.466。单独提高参考精度无法收窄已有主测量的统计误差。

复现入口为 python -m v712_v721.model 的 v7.18 字段。计算为确定性，原谱数字化沿用 v7.11。
