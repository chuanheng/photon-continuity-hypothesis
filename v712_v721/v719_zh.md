# v7.19 按假定效应规划曝光

以观察到的 0.297 作为设计情景，采用双侧 5% 正态检验及近似 80% 功效条件，目标总标准差约 0.106。参考固定在 0.05，主测量误差按曝光平方根缩减，则约需原等效曝光的 24.6 倍。效应取自已有数据，属于敏感性计算；不能视作新实验预期信号。

复现入口为 python -m v712_v721.model 的 v7.19 字段。计算为确定性，原谱数字化沿用 v7.11。
