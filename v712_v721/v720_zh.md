# v7.20 参考与主测量交错

四个等间隔时点采用主、参、参、主顺序，对比权重为 (1,−1,−1,1)/2。常数与线性共同漂移精确抵消，但二次漂移留下二倍系数；系数 0.1484 每时间步平方即可模拟中心差。若切换本身改变装置，需额外空白对照。

复现入口为 python -m v712_v721.model 的 v7.20 字段。计算为确定性，原谱数字化沿用 v7.11。
