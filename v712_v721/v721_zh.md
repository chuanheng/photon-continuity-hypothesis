# v7.21 探测器位置对调

若假定候选效应随交换变号、普通响应保持不变，交换前后半差保留候选量。一个也随位置变号的普通几何响应 (C,−C) 给出同一结果。若另有匹配的空白参考测得普通奇分量 0.1，差减后只剩 0.197。全部是设计例，永久身份本身尚未导出变号规则。

复现入口为 python -m v712_v721.model 的 v7.21 字段。计算为确定性，原谱数字化沿用 v7.11。
