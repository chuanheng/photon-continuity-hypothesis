# 原装置的已知尺寸

原文第二区分有效体积与外部屏蔽。两只 ORTEC 平面高纯锗探测器标称有效面积 200 mm²、有效厚度 13 mm。该尺寸不是前表面不灵敏层厚度。在公开装置描述中没有找到逐台死层厚度或电荷收集剖面，因此下面反求必需厚度，不把参数扫描当作装置测量。

复现入口为 python -m v722_v731.model 的 v7.22 项。
