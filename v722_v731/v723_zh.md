# 入射双线的衰减差

取锗密度 5.323 g/cm³，在 NIST 的 50、60 keV 总质量衰减系数间作双对数线性插值。入射双线的线性衰减系数分别为 13.94、13.14 cm⁻¹，相差 0.793 cm⁻¹。此为窄束未相互作用光子透射模型；质量能量吸收系数不能替代这里的总衰减系数。

复现入口为 python -m v722_v731.model 的 v7.23 项。
