# 散射光子穿过哪两层

正入射正返回、固定散射光子能量时，方向 i 的光学厚度为 μ入 dᵢ+μ散(d₁+d₂)。后项在方向交换时精确抵消。假设两层为 10、30 μm，得到交叉比大小方向选为大于一时为 1.00159。若两方向的角度或能量权重不同，抵消未必成立。

复现入口为 python -m v722_v731.model 的 v7.24 项。
