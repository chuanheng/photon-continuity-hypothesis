# 有限能窗如何破坏精确抵消

固定两层总路程 40 μm，在 34.5–36.5 keV 窗内，出射光子的对数透射跨度为 0.0290。任意两个归一谱权重的平均透射比的对数绝对值不超过此跨度。它限制一个两谱比；完整四格交叉比还要考虑四组权重。实际总厚未知。

复现入口为 python -m v722_v731.model 的 v7.28 项。
