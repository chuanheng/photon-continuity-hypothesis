# 反冲电子与入射光子分开建模

取散射光子能量 35.5 keV，原两线对应反冲能量 19.112、20.291 keV。电子在敏感区内产生，不能套用同能 X 射线在死层的衰减系数。以判别阈值 8 keV、高斯触发宽度 0.5 keV 作示例，完全收集时两者触发概率都极接近一。宽度没有独立标定。

复现入口为 python -m v722_v731.model 的 v7.29 项。
