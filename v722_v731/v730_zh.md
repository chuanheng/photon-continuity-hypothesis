# 不完全收集能否放大触发差

假设一个方向全收集、另一个方向仅收集比例 q，触发概率为 Φ((qE−8)/0.5)。数值解 q=0.432 时两线触发概率为 0.697、0.937，比值重现目标大小。代价是两条线分别丢失 10.85、11.52 keV。这是单看触发的反例，未满足完整符合选择。

复现入口为 python -m v722_v731.model 的 v7.30 项。
