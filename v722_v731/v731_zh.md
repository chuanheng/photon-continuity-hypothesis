# 和能窗对该反例的约束

假设无补偿、无读出噪声且和能窗半宽为 0.5 keV，则能通过的反冲损失比例至多为 0.5/E，即 2.62%、2.46%。前轮构造损失约 57%，会被拒绝。真实装置的门宽、响应尾与深度分布仍需测量；事件被拒绝也会改变效率，不能据此排除所有电荷损失机制。

复现入口为 python -m v722_v731.model 的 v7.31 项。
