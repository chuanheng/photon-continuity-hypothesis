# 全覆盖铝片的绝对接受率

**问题与假设**　在 34.5–36.5 keV 使用两条入射线、两只探测器的公开数字化谱，检验全覆盖铝片。0.4 mm 铝，正入射，T=exp(−μd)。

**推导与操作**　对平坦真谱积分 T 并除以带宽；共同绝对损失与相对谱形可有不同量级。

**本轮结果**

~~~json
{
  "flat_acceptance": 0.9215794501154824
}
~~~

**对照与证据**　基线 T=1。结果属于普通仪器模型的条件计算。真实射线有一部分穿孔。 以独立扫描测得 T(E) 后可直接代入复核。

在仓库根目录运行 python -m v752_v761.model，读取 v7.53 项。
