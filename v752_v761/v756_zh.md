# 全覆盖铝片的两线方向迁移

**问题与假设**　在 34.5–36.5 keV 使用两条入射线、两只探测器的公开数字化谱，检验全覆盖铝片。0.4 mm 铝，正入射，T=exp(−μd)。

**推导与操作**　分别计算两条入射线 D2/D1 的变化倍数；两者之比才是总交叉比变化。

**本轮结果**

~~~json
{
  "high_line": 1.0008676479631604,
  "low_line": 1.0001429967326159
}
~~~

**对照与证据**　基线 T=1。结果属于普通仪器模型的条件计算。真实射线有一部分穿孔。 以独立扫描测得 T(E) 后可直接代入复核。

在仓库根目录运行 python -m v752_v761.model，读取 v7.56 项。
