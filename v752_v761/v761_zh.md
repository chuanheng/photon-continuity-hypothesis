# 全覆盖铝片的响应与恒等模型的可区分性

**问题与假设**　在 34.5–36.5 keV 使用两条入射线、两只探测器的公开数字化谱，检验全覆盖铝片。0.4 mm 铝，正入射，T=exp(−μd)。

**推导与操作**　若仅测两端且允许未知共同通量，拟合常数效率。再冻结它，计算带中心对该常数的相对偏差；中心可作为独立参考点。

**本轮结果**

~~~json
{
  "constant_fit": 0.9214282253695079,
  "midpoint_relative_residual": 0.0002461163325482296
}
~~~

**对照与证据**　基线 T=1。结果属于普通仪器模型的条件计算。真实射线有一部分穿孔。 以独立扫描测得 T(E) 后可直接代入复核。

在仓库根目录运行 python -m v752_v761.model，读取 v7.61 项。
