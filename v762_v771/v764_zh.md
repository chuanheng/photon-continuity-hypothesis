# 全覆盖铜片的观测交叉比

**问题与假设**　在 34.5–36.5 keV 使用两条入射线、两只探测器的公开数字化谱，检验全覆盖铜片。0.25 mm 铜，正入射，T=exp(−μd)。

**推导与操作**　四条已发表谱分别乘 T 后积分，比较方向比之比与原始值。属于敏感性扰动。

**本轮结果**

~~~json
{
  "original": 1.3455409924858532,
  "weighted": 1.3240168329563786
}
~~~

**对照与证据**　基线 T=1。结果属于普通仪器模型的条件计算。等厚全覆盖未包含双锥孔。 以独立扫描测得 T(E) 后可直接代入复核。

在仓库根目录运行 python -m v762_v771.model，读取 v7.64 项。
