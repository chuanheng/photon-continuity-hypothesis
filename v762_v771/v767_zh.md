# 全覆盖铜片的连续开启响应

**问题与假设**　在 34.5–36.5 keV 使用两条入射线、两只探测器的公开数字化谱，检验全覆盖铜片。0.25 mm 铜，正入射，T=exp(−μd)。

**推导与操作**　令权重为 T 的 λ 次方；在 λ=0 的对数交叉比导数等于各谱 ln T 均值的带符号和。

**本轮结果**

~~~json
{
  "derivative": -0.015955189906853517,
  "finite_difference": -0.015955189911487366
}
~~~

**对照与证据**　基线 T=1。结果属于普通仪器模型的条件计算。等厚全覆盖未包含双锥孔。 以独立扫描测得 T(E) 后可直接代入复核。

在仓库根目录运行 python -m v762_v771.model，读取 v7.67 项。
