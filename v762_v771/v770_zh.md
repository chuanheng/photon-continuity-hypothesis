# 全覆盖铜片的避开边缘的留出窗

**问题与假设**　在 34.5–36.5 keV 使用两条入射线、两只探测器的公开数字化谱，检验全覆盖铜片。0.25 mm 铜，正入射，T=exp(−μd)。

**推导与操作**　将积分区间收窄到 35–36 keV，沿用原来的 T 函数及原阈值，复核中心区域的响应偏移。

**本轮结果**

~~~json
{
  "narrow_log_shift": -0.00522190015069679,
  "full_log_shift": -0.01612598593232395
}
~~~

**对照与证据**　基线 T=1。结果属于普通仪器模型的条件计算。等厚全覆盖未包含双锥孔。 以独立扫描测得 T(E) 后可直接代入复核。

在仓库根目录运行 python -m v762_v771.model，读取 v7.70 项。
