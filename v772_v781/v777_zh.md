# 串联铝铜的连续开启响应

**问题与假设**　在 34.5–36.5 keV 使用两条入射线、两只探测器的公开数字化谱，检验串联铝铜。0.7 mm 铝与 0.25 mm 铜全覆盖，光学厚度相加。

**推导与操作**　令权重为 T 的 λ 次方；在 λ=0 的对数交叉比导数等于各谱 ln T 均值的带符号和。

**本轮结果**

~~~json
{
  "derivative": -0.01722199888274001,
  "finite_difference": -0.017221998880323497
}
~~~

**对照与证据**　基线 T=1。结果属于普通仪器模型的条件计算。原装置各层厚度不能视为所有事件都经过的厚度。 以独立扫描测得 T(E) 后可直接代入复核。

在仓库根目录运行 python -m v772_v781.model，读取 v7.77 项。
