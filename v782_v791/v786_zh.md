# 带孔铜片的两线方向迁移

**问题与假设**　在 34.5–36.5 keV 使用两条入射线、两只探测器的公开数字化谱，检验带孔铜片。一半射线走开孔，其余穿过 0.25 mm 铜，通量透射按路径比例求和。

**推导与操作**　分别计算两条入射线 D2/D1 的变化倍数；两者之比才是总交叉比变化。

**本轮结果**

~~~json
{
  "high_line": 1.003399398416819,
  "low_line": 1.0005205972779838
}
~~~

**对照与证据**　基线 T=1。结果属于普通仪器模型的条件计算。开孔比例是假定值，需分方向测量。 以独立扫描测得 T(E) 后可直接代入复核。

在仓库根目录运行 python -m v782_v791.model，读取 v7.86 项。
