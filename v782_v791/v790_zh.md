# 带孔铜片的避开边缘的留出窗

**问题与假设**　在 34.5–36.5 keV 使用两条入射线、两只探测器的公开数字化谱，检验带孔铜片。一半射线走开孔，其余穿过 0.25 mm 铜，通量透射按路径比例求和。

**推导与操作**　将积分区间收窄到 35–36 keV，沿用原来的 T 函数及原阈值，复核中心区域的响应偏移。

**本轮结果**

~~~json
{
  "narrow_log_shift": -0.0009323480041416587,
  "full_log_shift": -0.0028731717088721354
}
~~~

**对照与证据**　基线 T=1。结果属于普通仪器模型的条件计算。开孔比例是假定值，需分方向测量。 以独立扫描测得 T(E) 后可直接代入复核。

在仓库根目录运行 python -m v782_v791.model，读取 v7.90 项。
