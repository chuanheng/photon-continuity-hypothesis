# 斜射角积分的反向效率修正

**问题与假设**　在 34.5–36.5 keV 使用两条入射线、两只探测器的公开数字化谱，检验斜射角积分。0.7 mm 铝与 0.25 mm 铜，角度至 atan(7.98/9.91)，以 cos³θ sinθ 为权平均透射。

**推导与操作**　对各条谱乘 1/T，检验把已选谱视作待展开谱时的方向和幅度；极低效率会放大误差。

**本轮结果**

}

**对照与证据**　基线 T=1。结果属于普通仪器模型的条件计算。同层平板模型未重建锥孔、胶和金插片。 以独立扫描测得 T(E) 后可直接代入复核。

在仓库根目录运行 python -m v792_v801.model，读取 v7.95 项。
