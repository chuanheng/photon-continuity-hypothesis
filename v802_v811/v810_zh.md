# 锗表面非活性层的避开边缘的留出窗

**问题与假设**　在 34.5–36.5 keV 使用两条入射线、两只探测器的公开数字化谱，检验锗表面非活性层。取 40 μm 锗的出射总路径，使用总衰减系数。

**推导与操作**　将积分区间收窄到 35–36 keV，沿用原来的 T 函数及原阈值，复核中心区域的响应偏移。

**本轮结果**

~~~json
{
  "narrow_log_shift": -0.0006230843992565127,
  "full_log_shift": -0.0019180548154951182
}
~~~

**对照与证据**　基线 T=1。结果属于普通仪器模型的条件计算。总路径取设计值，未取得逐台死层厚度。 以独立扫描测得 T(E) 后可直接代入复核。

在仓库根目录运行 python -m v802_v811.model，读取 v8.10 项。
