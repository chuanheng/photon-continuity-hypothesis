# 有限敏感厚度的连续开启响应

**问题与假设**　在 34.5–36.5 keV 使用两条入射线、两只探测器的公开数字化谱，检验有限敏感厚度。0.4 mm 有效锗层，采用至少一次相互作用概率 1−exp(−μd)；它只代理全能峰效率。

**推导与操作**　令权重为 T 的 λ 次方；在 λ=0 的对数交叉比导数等于各谱 ln T 均值的带符号和。

**本轮结果**

~~~json
{
  "derivative": 0.003632510553832513,
  "finite_difference": 0.003632510559015145
}
~~~

**对照与证据**　基线 T=1。结果属于普通仪器模型的条件计算。散射逃逸会使全能峰效率低于相互作用概率。 以独立扫描测得 T(E) 后可直接代入复核。

在仓库根目录运行 python -m v812_v821.model，读取 v8.17 项。
