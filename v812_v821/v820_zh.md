# 有限敏感厚度的避开边缘的留出窗

**问题与假设**　在 34.5–36.5 keV 使用两条入射线、两只探测器的公开数字化谱，检验有限敏感厚度。0.4 mm 有效锗层，采用至少一次相互作用概率 1−exp(−μd)；它只代理全能峰效率。

**推导与操作**　将积分区间收窄到 35–36 keV，沿用原来的 T 函数及原阈值，复核中心区域的响应偏移。

**本轮结果**

~~~json
{
  "narrow_log_shift": 0.0011754716725747016,
  "full_log_shift": 0.0036208520154374924
~~~

**对照与证据**　基线 T=1。结果属于普通仪器模型的条件计算。散射逃逸会使全能峰效率低于相互作用概率。 以独立扫描测得 T(E) 后可直接代入复核。

在仓库根目录运行 python -m v812_v821.model，读取 v8.20 项。
