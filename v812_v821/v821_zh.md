# 有限敏感厚度的响应与恒等模型的可区分性

**问题与假设**　在 34.5–36.5 keV 使用两条入射线、两只探测器的公开数字化谱，检验有限敏感厚度。0.4 mm 有效锗层，采用至少一次相互作用概率 1−exp(−μd)；它只代理全能峰效率。

**推导与操作**　若仅测两端且允许未知共同通量，拟合常数效率。再冻结它，计算带中心对该常数的相对偏差；中心可作为独立参考点。

**本轮结果**

~~~json
{
  "constant_fit": 0.8413405372553026,
  "midpoint_relative_residual": 0.0005202819868639352
}
~~~

**对照与证据**　基线 T=1。结果属于普通仪器模型的条件计算。散射逃逸会使全能峰效率低于相互作用概率。 以独立扫描测得 T(E) 后可直接代入复核。

在仓库根目录运行 python -m v812_v821.model，读取 v8.21 项。
