# 近阈值选择的连续开启响应

**问题与假设**　在 34.5–36.5 keV 使用两条入射线、两只探测器的公开数字化谱，检验近阈值选择。以 34.5 keV 为示例离线下阈，σ=0.5 keV，取高斯累积分布作接受率。

**推导与操作**　令权重为 T 的 λ 次方；在 λ=0 的对数交叉比导数等于各谱 ln T 均值的带符号和。

**本轮结果**

~~~json
{
  "derivative": -0.02772987247110989,
  "finite_difference": -0.027729872464909988
}
~~~

**对照与证据**　基线 T=1。结果属于普通仪器模型的条件计算。该阈值是人为压力测试，与论文约 8 keV 硬件阈值不同。 以独立扫描测得 T(E) 后可直接代入复核。

在仓库根目录运行 python -m v822_v831.model，读取 v8.27 项。
