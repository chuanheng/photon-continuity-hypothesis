# 近阈值选择的避开边缘的留出窗

**问题与假设**　在 34.5–36.5 keV 使用两条入射线、两只探测器的公开数字化谱，检验近阈值选择。以 34.5 keV 为示例离线下阈，σ=0.5 keV，取高斯累积分布作接受率。

**推导与操作**　将积分区间收窄到 35–36 keV，沿用原来的 T 函数及原阈值，复核中心区域的响应偏移。

**本轮结果**

~~~json
{
  "narrow_log_shift": -0.00546529930857087,
  "full_log_shift": -0.025938156195480566
}
~~~

**对照与证据**　基线 T=1。结果属于普通仪器模型的条件计算。该阈值是人为压力测试，与论文约 8 keV 硬件阈值不同。 以独立扫描测得 T(E) 后可直接代入复核。

在仓库根目录运行 python -m v822_v831.model，读取 v8.30 项。
