# 近阈值选择的响应与恒等模型的可区分性

**问题与假设**　在 34.5–36.5 keV 使用两条入射线、两只探测器的公开数字化谱，检验近阈值选择。以 34.5 keV 为示例离线下阈，σ=0.5 keV，取高斯累积分布作接受率。

**推导与操作**　若仅测两端且允许未知共同通量，拟合常数效率。再冻结它，计算带中心对该常数的相对偏差；中心可作为独立参考点。

**本轮结果**

~~~json
{
  "constant_fit": 0.7499841643790834,
  "midpoint_relative_residual": 0.3030273363983518
}
~~~

**对照与证据**　基线 T=1。结果属于普通仪器模型的条件计算。该阈值是人为压力测试，与论文约 8 keV 硬件阈值不同。 以独立扫描测得 T(E) 后可直接代入复核。

在仓库根目录运行 python -m v822_v831.model，读取 v8.31 项。
