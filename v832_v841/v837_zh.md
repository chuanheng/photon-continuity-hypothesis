# 有限分辨率能窗的连续开启响应

**问题与假设**　在 34.5–36.5 keV 使用两条入射线、两只探测器的公开数字化谱，检验有限分辨率能窗。对真能量位于带内的事件，以 σ=0.5 keV 计算读数留在 34.5–36.5 keV 的概率，不计窗外迁入。

**推导与操作**　令权重为 T 的 λ 次方；在 λ=0 的对数交叉比导数等于各谱 ln T 均值的带符号和。

**本轮结果**

~~~json
{
  "derivative": 0.01021712588121601,
  "finite_difference": 0.010217125883116296
}
~~~

**对照与证据**　基线 T=1。结果属于普通仪器模型的条件计算。真实响应含窗外迁入及非高斯尾。 以独立扫描测得 T(E) 后可直接代入复核。

在仓库根目录运行 python -m v832_v841.model，读取 v8.37 项。
