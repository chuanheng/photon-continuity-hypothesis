# 复合符合选择的响应与恒等模型的可区分性

**问题与假设**　在 34.5–36.5 keV 使用两条入射线、两只探测器的公开数字化谱，检验复合符合选择。角平均铝铜透射、锗相互作用效率和有限分辨率留窗概率相乘，假设条件独立。

**推导与操作**　若仅测两端且允许未知共同通量，拟合常数效率。再冻结它，计算带中心对该常数的相对偏差；中心可作为独立参考点。

**本轮结果**

~~~json
{
  "constant_fit": 0.06633614525343358,
  "midpoint_relative_residual": 0.9123659882782598
}
~~~

**对照与证据**　基线 T=1。结果属于普通仪器模型的条件计算。各因素在真实探测器内可能相关，乘积模型须另行校准。 以独立扫描测得 T(E) 后可直接代入复核。
