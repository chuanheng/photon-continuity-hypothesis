# v9.43　有限量子参考能否支持经典重发

信号平均光子数 μ=1，参考为同源相干模式，能量 R，整体相位完全未知。联合总数 N 服从 Poisson(1+R)，定数态是归一化三模矢量的 N 次对称积，内积为 [(R+gᵢⱼ)/(R+1)]ᴺ。逐扇区取最小本征值后按泊松权重求和。对 R 解成功率 0.093 的方程。更强参考可先衰减到较弱值。

**数值复现**　从仓库根目录执行 `python -m v942_v951.model`，读取 `ref_threshold`。本次结果为 `0.23268328082914466`。固定输入取自 v9.41 已存档的六相位（生成种子 939940）；本轮为确定性计算。

**可检验范围与反例**　接收器为任意联合量子测量，保存的是经典结果。该交点仅适用于此构造；无任意接收器必要下界。应在信号输入面测量可访问参考能量。

**证据**　上述推导和合成模型的数值对照未引入新的实测数据。Specht 等，Nature 473, 190–193 (2011)，[原文及补充材料](https://arxiv.org/pdf/1103.1528)，[正式刊页](https://doi.org/10.1038/nature09997)。Cao 等，New J. Phys. 17, 053014 (2015)，[离散相位的光子数分块](https://doi.org/10.1088/1367-2630/17/5/053014)。
