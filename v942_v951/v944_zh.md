# v9.44　共同相位漂移和独立漂移能否互换

对所有信号与参考施加同一个随机相位，在定总数块仅产生标量；若参考相位相对信号独立均匀，则它是与标签无关的直积混态，任何联合测量都可通过对该辅态取偏迹化成信号上的测量。无参考取 R=0 计算可行率。

**数值复现**　从仓库根目录执行 `python -m v942_v951.model`，读取 `continuous`。本次结果为 `0.0019889450889499652`。固定输入取自 v9.41 已存档的六相位（生成种子 939940）；本轮为确定性计算。

**可检验范围与反例**　共同漂移保留 R=2 时的成功率，独立均匀漂移消去参考信息。以同源与独立随机调相两种干预测量成功表，不能用孤立信号的边缘相位分布代替联合标定。

**证据**　上述推导和合成模型的数值对照未引入新的实测数据。Specht 等，Nature 473, 190–193 (2011)，[原文及补充材料](https://arxiv.org/pdf/1103.1528)，[正式刊页](https://doi.org/10.1038/nature09997)。Cao 等，New J. Phys. 17, 053014 (2015)，[离散相位的光子数分块](https://doi.org/10.1088/1367-2630/17/5/053014)。
