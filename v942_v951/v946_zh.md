# v9.46　单片波片生成六态是否实现历史相位

使用共用水平输入，快慢轴之一固定相移零，另一轴延迟 d，Jones 算符 J=I+(exp(id)−1)uuᵀ，u=(cos a,sin a)。四个线偏振用半波片，两个圆偏振用四分之一波片，角度在模型中给出。逐态检查射线保真度，再从相干振幅构造 Gram。

**数值复现**　从仓库根目录执行 `python -m v942_v951.model`，读取 `plate_usd`。本次结果为 `0.04989865402302439`。固定输入取自 v9.41 已存档的六相位（生成种子 939940）；本轮为确定性计算。

**可检验范围与反例**　六个射线均吻合，等成功率降到工作效率以下。更换波片时的共同光程以及折射率相位会改变编码。原论文提供反射偏振校验；此处的波片序列是可用干涉仪否证的替代实现。

**证据**　上述推导和合成模型的数值对照未引入新的实测数据。Specht 等，Nature 473, 190–193 (2011)，[原文及补充材料](https://arxiv.org/pdf/1103.1528)，[正式刊页](https://doi.org/10.1038/nature09997)。Cao 等，New J. Phys. 17, 053014 (2015)，[离散相位的光子数分块](https://doi.org/10.1088/1367-2630/17/5/053014)。
