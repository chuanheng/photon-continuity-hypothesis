# v9.48　信号入射损耗与参考损耗是否等价

保持参考能量 2，信号通过真空损耗通道，振幅缩放 √t。定数块内积变成 (2+t g)/(2+t)，块权重均值也变为 2+t。固定效率的分母为损耗前平均一光子，用求根获得传输率。

**数值复现**　从仓库根目录执行 `python -m v942_v951.model`，读取 `signal_transmission_required`。本次结果为 `0.5674467648599331`。固定输入取自 v9.41 已存档的六相位（生成种子 939940）；本轮为确定性计算。

**可检验范围与反例**　独立衰减信号、保持参考功率与工作点分母不动即可检验。若损耗随偏振变化，存活率本身会携带侧信息。

**证据**　上述推导和合成模型的数值对照未引入新的实测数据。Specht 等，Nature 473, 190–193 (2011)，[原文及补充材料](https://arxiv.org/pdf/1103.1528)，[正式刊页](https://doi.org/10.1038/nature09997)。Cao 等，New J. Phys. 17, 053014 (2015)，[离散相位的光子数分块](https://doi.org/10.1088/1367-2630/17/5/053014)。
