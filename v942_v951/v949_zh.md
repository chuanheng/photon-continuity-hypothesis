# v9.49　无关误触发如何限制保真度

最终被接受的事件中比例 b 是独立的混合偏振，其余为正确标签，F=(1−b)+b/2。取 F=0.93 解 b。这里 b 的分母是所有接受事件。

**数值复现**　从仓库根目录执行 `python -m v942_v951.model`，读取 `false_herald_fraction`。本次结果为 `0.1399999999999999`。固定输入取自 v9.41 已存档的六相位（生成种子 939940）；本轮为确定性计算。

**可检验范围与反例**　暗计数与背景光可以实现此混合，仅空白输入概率不足以确定 b。若探测器余脉冲与上一次偏振相关，需按前一输入分层验证条件分布。

**证据**　上述推导和合成模型的数值对照未引入新的实测数据。Specht 等，Nature 473, 190–193 (2011)，[原文及补充材料](https://arxiv.org/pdf/1103.1528)，[正式刊页](https://doi.org/10.1038/nature09997)。Cao 等，New J. Phys. 17, 053014 (2015)，[离散相位的光子数分块](https://doi.org/10.1088/1367-2630/17/5/053014)。
