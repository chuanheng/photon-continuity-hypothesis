# v9.50　一阶可见度能否校准相位分布

比较方差 σ² 的包裹高斯与 ±arccos(c) 的对称双点分布，取 c=exp(−σ²/2)，两者一阶特征函数相同。二阶分别为 exp(−2σ²) 与 2c²−1，直接控制相隔两光子扇区的相干。

**数值复现**　从仓库根目录执行 `python -m v942_v951.model`，读取 `matched_first_harmonic`。本次结果为 `[0.9231163463866358, 0.7261490370736908, 0.7042875779324227]`。固定输入取自 v9.41 已存档的六相位（生成种子 939940）；本轮为确定性计算。

**可检验范围与反例**　σ=0.4 时两种常规噪声在二次谐波可分。必须独立测量高阶矩或给出分布约束，一阶干涉仪不能独自锁定可访问侧信息。

**证据**　上述推导和合成模型的数值对照未引入新的实测数据。Specht 等，Nature 473, 190–193 (2011)，[原文及补充材料](https://arxiv.org/pdf/1103.1528)，[正式刊页](https://doi.org/10.1038/nature09997)。Cao 等，New J. Phys. 17, 053014 (2015)，[离散相位的光子数分块](https://doi.org/10.1088/1367-2630/17/5/053014)。
