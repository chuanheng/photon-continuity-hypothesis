# v10.00　现有得分间距需要怎样的计数精度

沿用等概率 16 格与全试次得分范围 [−2,10]。在每一历史条件下可分均值均不低于下界时，固定样本均值低至少 d 的单侧 Hoeffding 界为 exp(−2Nd²/144)。用独立假设的数值下界减理想点作为 d。

**实际数值**　运行 `python -m v992_v1001.correlation` 查看字段 `finite_trials`：`{"margin": 0.0003909007012846879, "N": 1411570572}`。

**检验及边界**　输出为在恰好观测理想均值时实现 .05 尾界的保守试次数；没有给出功效或停止时刻保证。校准不确定度和系统误差不能靠增加 N 消除。

上述数值是合成验证。已知理论与文献见[批次索引](README.md)。
