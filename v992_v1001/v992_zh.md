# v9.92　同步的本地标志能否达到共享标志松弛界

两端各 3% 的标签泄漏完全同步并独立于输入。只看本地标志已经决定远端标志。没有标志时都不点击，双标志时用 v9.82 的互补二二子集，故分数恰为 −.03/2。分层下界又排除更低值。

**确定性计算**　运行 `OPENBLAS_NUM_THREADS=1 python -m v992_v1001.model`，字段 `sync` 为 `{'rate': 0.03, 'bound': -0.015}`。

**边界及反例**　此紧界需要两端的标志逐试次同步；逐端均为 3% 不能证明同步。同步硬件的可信时间戳可直接反驳该假设。
