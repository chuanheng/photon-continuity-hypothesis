# v9.93　两个互斥的本地标志为何不能同时饱和各扇区

两端各以 e=.03 独占标志，均无标志概率 1−2e。达到共享标志紧界需要两个单泄漏扇区均达 −1/4 且干净扇区得零。由 v9.83 的 16 个谱枚举，单端最优泄漏子集只能是单顶点，另一端的干净效果只能是该顶点的反向纯投影。两端干净效果必须分别选自四个反向顶点，彼此点积最小 −1/3。其乘积得分至少 (1−1/3)/4=1/6，与干净扇区零分矛盾。

**确定性计算**　运行 `OPENBLAS_NUM_THREADS=1 python -m v992_v1001.model`，字段 `exclusive` 为 `{'single_optimal_axes': 4, 'clean_floor_at_saturation': 0.16666666666666663}`。

**边界及反例**　极端局域策略已覆盖一般可分混合，因为要饱和线性下界，每个正权重分量都须饱和。策略空间紧致使不等式严格，但未求此互斥情形精确差距。
