# v9.94　两端独立泄漏能否由一套固定局域器件利用

取左侧的二顶点子集 A，右侧取补集。未泄漏时，左端投影到 A 的 Bloch 向量和的正方向，右端投影反方向。两者乘积得分为零；两个单泄漏扇区均为 (2−√12)/8，双泄漏为 −1/2。按独立标志概率 (1−e)²、e(1−e)、e² 加权，不共享标志。

**确定性计算**　运行 `OPENBLAS_NUM_THREADS=1 python -m v992_v1001.model`，字段 `independent` 为 `{'sectors': [-2.7739901525999894e-17, -0.18301270189221933, -0.18301270189221935, -0.5], 'feasible': -0.011101339250127192, 'relaxation': -0.015, 'gap_to_relaxation': 0.003898660749872808}`。

**边界及反例**　这是可行策略而非必要下界。逐端封闭标签通道、记录点击和标志的四格联合表即可检验分层预言；未监测的共同驱动会改变加权。
