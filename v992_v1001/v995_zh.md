# v9.95　9.3% 均匀保留的理想负分能否由 3% 独立私有标志重拟合

独立、与历史无关的标志使局域响应乘积化。左端泄漏响应枚举 16 个掩码，干净二值效果的极点为 0、I 及 Bloch 球上的投影。固定左端响应后，对右端干净效果取加权态算符的负谱，对右端掩码逐项保留负成本，均精确最小化。左端用 96 个纬度区间及 192 个经度，任意球面点到最近格点的角距离≤π/96；按支撑函数，放大 sec(π/96) 后格点凸包包含整个单位球。内外两次最小化给全局最小值数值包络。

**确定性计算**　运行 `OPENBLAS_NUM_THREADS=1 python -m v992_v1001.model`，字段 `independent_enclosure` 为 `{'lower': -0.011234099298715312, 'upper': -0.011101339250127273, 'rings': 96}`。

**边界及反例**　最小得分位于 [−.01123410,−.01110133]，与理想 −.011625 存在至少约 .0003909 的模型间距。外包几何及有限枚举可复核，双精度未作形式化区间算术。没有任何观测样本支持实际越界；结论依赖在每个可访问历史条件下两端泄漏独立、未泄漏输入确为单份可信态、无通信且无共享纠缠资源。普通材料量子存储仍可实现理想点。
